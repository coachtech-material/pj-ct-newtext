# 模範解答

MVCは、アプリケーションをModel・View・Controllerという3つの役割に分けて作る設計パターンです。Controller（コントローラー）は司令塔で、リクエストを受け取り、Modelにデータの取得・保存を指示し、その結果をViewに渡します。Model（モデル）はデータベースとやり取りし、データの取得・保存を担当します。View（ビュー）は受け取ったデータをもとに画面（HTML）を組み立てます。たとえば「ユーザー一覧」のリクエストでは、まずルーティングが対応するControllerに振り分け、ControllerがModelにユーザーの取得を指示し、Modelが返したデータをViewが一覧画面に整形して、レスポンスとしてブラウザに表示されます。このように役割を分けることで、ある部分を変更しても他に影響しにくく、保守しやすくなります。
