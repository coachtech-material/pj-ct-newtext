# 模範解答

UUIDとULIDは、どちらも世界中で一意（重複しない）であることが保証された識別子で、自動増分ID（1, 2, 3...と順番に振られるID）の代わりに主キーとして使えます。自動増分IDは、URLに`/users/1`のようにIDが露出すると総数を推測されたり他人のデータにアクセスされやすくなったり、複数のサーバーで同時にデータを作る分散システムでは衝突が起きたりする弱点があります。UUIDはランダムに生成されるため予測されにくく、こうした場面で役立ちます。ULIDはUUIDの欠点を補ったもので、生成された順番でソートできて文字数も短いという利点があります。一般的なWebアプリケーションではシンプルでパフォーマンスのよい自動増分IDで十分ですが、セキュリティや分散システムが重要な場面ではUUIDやULIDの利用を検討します。
