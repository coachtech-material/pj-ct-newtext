# 模範解答

トランザクション処理とは、複数のデータベース操作を「1つのまとまり」として扱い、すべて成功するか、すべて失敗するかのどちらかにする仕組みです。たとえば銀行の送金では、「Aさんの口座から1万円引き落とす」「Bさんの口座へ1万円入金する」という2つの処理が必要ですが、引き落としだけ成功して入金が失敗すると、お金が消えてしまいます。これを防ぐのがトランザクションで、途中で1つでも失敗すれば、それまでの変更をすべてなかったことにする（ロールバックする）ことでデータの整合性を保ちます。Laravelでは`DB::transaction()`の中に一連の処理を書くと、途中で例外（エラー）が起きた場合に自動でロールバックされるため、データが中途半端な状態になるのを安全に防げます。
