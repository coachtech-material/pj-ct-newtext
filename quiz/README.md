
# quiz — 概念理解チェック問題集

COACHTECH LMS 上で、各概念Sectionの最後に表示する「確認問題」と、その採点・フィードバックに使う「模範解答」を管理するディレクトリです。

## 🎯 目的

- **受講生**: 学んだ概念を自分の言葉でアウトプットし、知識を定着させる
- **コーチ**: 受講生の回答文をもとにフィードバックする
- **AI**: 模範解答をもとに回答を自動採点する

受講生は各Sectionの最後にある問題文に対し、テキストボックスへ自由記述で解答します。

## 📁 ディレクトリ構成

`curriculums/` と同じ階層構造をミラーしています。各Sectionは `.md` ファイルではなく**ディレクトリ**で表し、その中に2つのファイルを置きます。

```
quiz/
├── README.md
└── tutorial-{N}: {タイトル}/
    └── chapter-{M}: {章タイトル}/
        └── {N}-{M}-{S}_{見出し名}/
            ├── question.md       # 問題文（1文・記述式）
            └── model-answer.md    # 模範解答（AI採点・コーチFB用）
```

- Sectionディレクトリ名は `curriculums/` のSectionファイル名から拡張子 `.md` を除いたものと一致させます。
- LMS / AI は `quiz/{tutorial}/{chapter}/{section}/question.md` のような決まったパスで取得できます。

## 📝 ファイルの中身

### question.md
- **1文の記述式問題**を1問だけ記載します。
- AIが評価しやすいよう、問われている観点が明確な1文にします。
- 例: 「Laravelの『ミドルウェア』とは何か、リクエストとレスポンスの流れに触れながら、あなた自身の言葉で説明してください。」

### model-answer.md
- 問題に対する**模範解答（解答例）**を記載します。
- AI採点とコーチのフィードバックの拠り所になります。

## 🔍 対象Sectionの選定方針

「概念・仕組みの理解」を問えるSectionを対象とします。

**対象に含む**: 「〜とは」「〜の基礎」「設計」「考え方」など、自分の言葉で説明する価値があるSection。

**対象外**:
- ハンズオン / 演習Section（実装課題で別途アウトプットするため）
- インストール・環境構築などの手順Section
- 細かい文法・SQL・実装手順のみのSection（コードで確認する方が適切なため）

対象Sectionの一覧は `biz-agent-data/tasks/概念Sectionへのquiz問題追加.md` で管理しています。

## ➕ 新しい問題を追加するとき

1. 対象Sectionのディレクトリを `curriculums/` と同じパス構成で作成する
2. `question.md` に1文の問題を書く
3. `model-answer.md` に模範解答を書く
