# 模範解答

PHPとは、ユーザーの操作に応じて表示が変わる「動的な」Webページを作ることに特化した、サーバーサイドのスクリプト言語です。サーバーサイドとは、Webサーバー側（裏側）でプログラムが実行されるという意味で、データベースとの連携やユーザー認証、HTMLの生成といった本質的な処理を担当します。これに対してクライアントサイド（JavaScript）は、ユーザーのブラウザ側（表側）で動き、見た目の演出を担当します。レストランに例えると、サーバーサイドは料理を作るキッチン、クライアントサイドは接客するホールのような関係です。PHPはHTMLに直接埋め込んで書ける手軽さを持ち、世界中の多くのWebサイトで使われています。
