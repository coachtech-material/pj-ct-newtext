# 模範解答

関数とは、一連の処理を一つのまとまりとして名前を付けたもので、便利な道具やレシピに例えられます。一度関数を定義しておけば、その名前を呼び出すだけで、いつでもどこでも同じ処理を実行できます。これにより同じコードを何度も書く必要がなくなり（再利用性）、処理を直したいときは関数の中身を一箇所変えるだけで済み（保守性）、わかりやすい名前を付けることでコードが読みやすくなります（可読性）。引数（ひきすう）は関数に外部からデータを渡す仕組みで、これにより同じ関数を様々な値で柔軟に使えます。戻り値（もどりち）は`return`を使って処理結果を呼び出し元に返す仕組みで、その結果を別の変数に入れたり、さらに別の計算に使ったりできます。
