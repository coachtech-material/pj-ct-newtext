# 模範解答

JOINとは、複数のテーブルに分割されたデータを、リレーションシップ（主キーと外部キーの関連）を頼りに、あたかも一つの大きなテーブルであるかのように仮想的に結合してデータを取得する機能です。正規化によってデータは「ユーザー」「投稿」などに分割されているため、例えば投稿一覧に投稿者の名前も一緒に表示したい場合、別々のテーブルから情報を組み合わせる必要があり、そこでJOINが役立ちます。どのカラムを手がかりに結合するかは`ON`句で指定し、これが結合の「接着剤」の役割を果たします。INNER JOIN（内部結合）は、両方のテーブルに結合条件に一致するレコードがある場合だけを取得します。一方LEFT JOIN（左外部結合）は、左側のテーブルの全レコードを基準にし、右側に一致するデータがなくてもその行を残し、対応するカラムはNULLとして表示します。そのため「まだ投稿していないユーザーも含めて全員見たい」といった場合に使います。
