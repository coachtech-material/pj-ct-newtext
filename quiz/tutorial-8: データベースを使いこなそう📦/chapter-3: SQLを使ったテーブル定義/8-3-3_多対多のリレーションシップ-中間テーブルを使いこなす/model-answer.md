多対多のリレーションシップとは、2つのテーブルがお互いに「多」の関係にある状態のことです。例えば投稿とタグの関係では、1つの投稿が複数のタグを持てる一方で、1つのタグも複数の投稿で使われるため、これが多対多にあたります。この関係は、投稿テーブルにタグのIDを1つ持たせるだけでは表現できず、かといってタグ用のカラムを増やしていくのは付けられる数が固定されてしまう柔軟性のない設計になります。そこで、両者をつなぐためだけの第三のテーブルである中間テーブル（ピボットテーブル）を用意します。中間テーブルは「どの投稿（post_id）とどのタグ（tag_id）が関連しているか」というペアだけを記録し、多対多の関係を2つの1対多の関係に分解して表現します。また、同じ組み合わせが重複して登録されないよう、中間テーブルには複合ユニークキー制約を設定することが重要です。
