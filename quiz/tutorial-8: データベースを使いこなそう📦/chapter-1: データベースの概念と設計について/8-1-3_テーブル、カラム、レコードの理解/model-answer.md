# 模範解答

テーブルとは、顧客や商品など特定のテーマに関するデータの集まり全体を指す表で、Excelの「シート」に相当します。カラムとは、その表の縦の列のことで、`id`や`name`といったデータの項目・属性を表し、Excelの「列」に相当します。レコードとは、表の横の行のことで、一人の顧客のデータのような一件分の具体的なデータを指し、Excelの「行」に相当します。つまり、テーブルという表が複数のカラム（項目）で構成され、その中に一件ずつのレコード（データ）が積み重なっているイメージです。また、各カラムには「どんな種類のデータを入れるか」を決めるデータ型（整数や文字列、日付など）を指定します。データ型を正しく設定することで、誤ったデータの混入を防いだり、記憶領域を効率化したり、正確な計算や比較ができるようになります。
