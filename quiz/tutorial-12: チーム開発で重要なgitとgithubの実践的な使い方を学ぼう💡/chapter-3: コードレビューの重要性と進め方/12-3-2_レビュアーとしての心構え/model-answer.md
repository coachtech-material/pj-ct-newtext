レビュアー（レビューする側）の役割は、コードを批判することではなく、コードを改善することです。そのためにいくつかの心構えが大切です。まず、「このコードはひどい」といった批判ではなく、「この関数は長すぎるので、分割することをお勧めします」のような建設的な改善提案を行います。また、相手の人格ではなくコードそのものに対して指摘し、「とても読みやすいですね」といったポジティブなフィードバックも忘れずに伝えます。提案するときは命令形ではなく「こうした方が良いと思いますが、いかがでしょうか」と質問形式にし、なぜそうした方が良いのかという理由もあわせて説明すると、相手が納得しやすくなります。さらに、チェックリストを使って漏れを防いだり、小さな変更を頻繁にレビューしたりすると、レビューの負担が軽くなり、バグの早期発見にもつながります。
