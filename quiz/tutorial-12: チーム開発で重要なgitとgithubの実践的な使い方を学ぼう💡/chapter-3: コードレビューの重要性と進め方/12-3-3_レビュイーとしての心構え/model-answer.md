# 模範解答

レビュイー（レビューされる側）の役割は、フィードバックを受け入れてコードを改善することです。大切な心構えとして、まずフィードバックは批判ではなく改善提案だと捉え、感情的になったり防御的になったりせず、素直に受け入れて「ありがとうございます」と感謝を伝えます。フィードバックは自分の成長のチャンスだからです。また、理由がわからないときは遠慮せずに質問し、納得できない点があれば議論を恐れず、建設的に意見を交わすこともよいことです（最終的にはチームで決定します）。さらに、レビューを効率的に進める工夫として、プルリクエストを出す前に自分でコードを見直す「セルフレビュー」を行ったり、変更内容や理由をプルリクエストの説明に詳しく書いたり、テストを書いたり、もらったフィードバックに迅速に対応したりすると、レビュアーの負担が減り、レビューがスムーズに進みます。
