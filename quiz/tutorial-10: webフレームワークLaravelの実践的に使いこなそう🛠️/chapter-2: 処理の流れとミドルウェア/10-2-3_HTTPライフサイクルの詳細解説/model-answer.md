# 模範解答

HTTPライフサイクルとは、ユーザーがURLにアクセスしてリクエストがLaravelに届いてから、レスポンスがブラウザに返されるまでの一連の流れのことです。すべてのリクエストは、まず入り口であるエントリーポイント（public/index.php）を通り、リクエスト処理の中心であるHTTPカーネルに渡されます。次にミドルウェア（空港のセキュリティチェックのような共通の関所）が認証やCSRF保護などの前処理を行い、ルーターがURLに応じて適切なコントローラーへ振り分けます。コントローラーがデータ取得などの処理（ビジネスロジック）を実行してレスポンスを生成し、その後ミドルウェアを逆順に通ってブラウザへ送信されます。この全体の流れを理解しておくと、エラーが起きたときにどこを調べればよいかや、どこにログを仕込めばよいかが分かりやすくなります。
