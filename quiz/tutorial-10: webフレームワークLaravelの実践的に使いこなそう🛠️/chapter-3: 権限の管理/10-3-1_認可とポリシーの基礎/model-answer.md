# 模範解答

認可（Authorization）とは、「そのユーザーが特定のアクションを実行する権限を持っているか」を判断する仕組みのことです。認証（Authentication）が「あなたは誰ですか？」と本人を識別するのに対し、認可は「あなたはこれをしても良いですか？」と、できることを制御する点が違います。たとえばブログで、ログインしていれば誰でも投稿は作れるが、編集はその投稿を書いた本人だけ、といった制御が認可にあたります。Laravelでは、こうした権限判断のロジックを「ポリシー（Policy）」というクラスにまとめます。ポリシーは、PostモデルならPostPolicyのように特定のモデルに対応し、updateやdeleteといったメソッドが許可ならtrue、拒否ならfalseを返します。コントローラーではauthorizeメソッド、画面側では@canディレクティブを使って、このポリシーの判断結果に基づいた権限チェックを行えます。
