# 模範解答

コンピュータのファイルやディレクトリ（フォルダ）は、一本の木のような階層構造（ツリー構造）で整理されています。すべての出発点となる最上位のディレクトリを「ルートディレクトリ」と呼び、Mac/Linuxでは `/`（スラッシュ）で表され、木の根っこにあたります。そこから枝葉のように、すべてのファイルやディレクトリがぶら下がっています。重要なディレクトリが4つあり、ログインしているユーザー専用の「自分の部屋」が `~` で表すホームディレクトリ、今いる場所が `.` で表すカレントディレクトリ、今いる場所の一つ上の階層が `..` で表す親ディレクトリです。`pwd` で表示される住所は、ルートからの道順をスラッシュで区切って表したものです。これらの位置関係を意識し、`cd` コマンドで移動することで、木の中を自由に行き来できるようになります。
