# 模範解答

パスとは、ファイルやディレクトリの場所を示す「住所」のことで、書き方には絶対パスと相対パスの2種類があります。絶対パスは、ファイルシステムのルートディレクトリ（`/`）から始まる完全な住所で、`pwd` で表示されるものがこれにあたります。「東京都渋谷区…」と住所を完全に指定するのと同じで、今どこにいても常に同じ場所を指すため間違いが起こりにくい反面、長くなりがちです。一方、相対パスは、カレントディレクトリ（今いる場所）を基準にした道順で、「今いるコンビニから2軒隣」のように現在地によって指す場所が変わります。`.`（今いる場所）や `..`（一つ上の階層）といった記号を使って表し、短く書ける反面、自分の現在地を意識する必要があります。少しだけ移動するときは相対パス、システムの設定ファイルなど離れた場所を確実に指したいときは絶対パス、というように使い分けると効率的です。
