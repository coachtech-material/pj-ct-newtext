# 模範解答

本番環境では、開発環境よりも厳しいセキュリティの要件が求められます。まず、デバッグモード（`APP_DEBUG`）は`false`にして、詳細なエラーメッセージが外部に漏れないようにします。エラー内容をそのまま返すとシステムの内部情報が攻撃の手がかりになるため、本番では「サーバーエラーが発生しました」のような簡潔なメッセージに留めます。また、通信を暗号化して盗聴や改ざんを防ぐためにHTTPSを必須とし、APIキーなどの機密情報はコードに直接書かず、環境変数（`.env`ファイル）に保存してGitにはコミットしないようにします。さらに、セキュリティは一度設定して終わりではなく、Laravelや依存パッケージの定期的なアップデートやログの確認など、継続的に改善していくことが大切です。
