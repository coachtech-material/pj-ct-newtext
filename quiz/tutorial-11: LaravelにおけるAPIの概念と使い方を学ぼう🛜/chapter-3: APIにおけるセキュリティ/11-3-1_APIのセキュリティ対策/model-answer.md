WebアプリケーションのAPIは外部からアクセスできるため、悪意のあるユーザーから攻撃を受ける可能性があり、セキュリティ対策が欠かせません。その対策の一つがレート制限（Rate Limiting）で、これは一定時間内にAPIにアクセスできる回数を制限する仕組みです。たとえばLaravelではデフォルトで「1分間に60回まで」のように設定でき、IPアドレスやユーザーごとに回数を数えます。これにより、大量のリクエストを送りつけてサーバーをダウンさせるDoS攻撃を防いだり、サーバーの負荷を軽減したり、特定のユーザーがAPIを独占しないよう公平性を保ったりできます。制限を超えた場合は「429 Too Many Requests」というステータスコードが返されます。
