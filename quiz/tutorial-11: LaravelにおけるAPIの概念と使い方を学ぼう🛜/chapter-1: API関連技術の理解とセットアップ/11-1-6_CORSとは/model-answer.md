# 模範解答

CORS（Cross-Origin Resource Sharing）とは、異なるオリジン間でのリソース共有を制御する仕組みです。オリジンとは「プロトコル＋ドメイン＋ポート」の組み合わせのことで、ブラウザには安全のために、異なるオリジンへのリクエストを制限する「同一オリジンポリシー」というセキュリティ機能が備わっています。そのため、フロントエンド（例：localhost:3000）とバックエンド（例：localhost:8000）が別のオリジンで動いている場合、設定をしないとフロントエンドからAPIにアクセスできません。そこでサーバー側でCORSを設定し、「このオリジンからのアクセスは許可します」と伝えることで、許可されたオリジンからのリクエストだけを受け入れられるようになります。
