# 模範解答

優れたエンジニアには、コードを書く技術に加えて「探究心」「解決力」「協調性」という3つの力が必要です。探究心とは、物事の表面だけでなく、その背景や仕組みに「なぜ？」と興味を持ち、深く理解しようとする姿勢のことです。解決力とは、目の前の問題を分析し、大きな問題を小さく分解して、一つずつ着実に乗り越えていく力のことです。協調性とは、チームの仲間と円滑にやり取りし、人間が読んで理解しやすいコードを書くなど、みんなで協力して一つの目標に向かう力のことです。家を建てる大工さんが金槌の使い方だけでは良い家を建てられないのと同じで、これら3つの力をあわせ持つことで、はじめて優れたエンジニアに近づくことができます。
