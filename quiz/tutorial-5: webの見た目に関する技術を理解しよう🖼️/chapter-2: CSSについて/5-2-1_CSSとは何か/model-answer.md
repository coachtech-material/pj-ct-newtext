# 模範解答

CSSとは、Webページの「見た目（デザイン）」を専門に担当する言語で、文字の色や大きさ、背景色、レイアウトといったスタイルをコントロールします。建物にたとえると、HTMLが柱や壁といった「骨格」を作るのに対し、CSSは壁紙やペンキ、家具の配置といった「内装・外装の装飾」を担当します。Web開発ではこの「構造と見た目の分離」、つまりHTMLが文書の構造や意味に責任を持ち、CSSが見た目に責任を持つ、という役割分担がとても重要です。なぜなら、見た目に関する指定をCSSファイルに一箇所にまとめておけば、色などを変えたいときにそのファイルを書き換えるだけで、サイト全体の同じ要素の見た目が一度に変わり、メンテナンス（修正や保守）がしやすくなるからです。
