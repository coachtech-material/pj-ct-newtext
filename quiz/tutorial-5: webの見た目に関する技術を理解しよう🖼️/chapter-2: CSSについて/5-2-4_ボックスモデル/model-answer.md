# 模範解答

ボックスモデルとは、見出しや段落、画像といったすべてのHTML要素が、目に見えない「箱（ボックス）」に入っているものとして扱われる、というCSSの基本的な考え方です。一つの箱は、中心から外側に向かって4つの領域で構成されています。一番内側のContentは、テキストや画像などの内容が表示される中心の領域です。その外側のPaddingは、内容と枠線の間にある「内側の余白」で、箱の中の緩衝材のようなものです。さらに外側のBorderは箱を囲む「枠線」、一番外側のMarginは「他の要素との間の余白」で、箱と箱の間隔にあたります。CSSのコードで`padding`や`margin`を見かけたら、「内側の余白」「外側の余白」と読み替えると理解しやすくなります。
