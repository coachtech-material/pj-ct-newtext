# 模範解答

HTMLとは、Webページにどのような内容をどのような構造で表示するかを定義する言語で、建物でいえば柱や壁にあたる「骨格」を組み立てる役割を担います。HTMLは計算や条件分岐などの処理を行うプログラミング言語ではなく、文章の各部分に意味の「印」を付ける「マークアップ言語」に分類されます。具体的には、`<h1>`や`<p>`といったタグ（`<`と`>`で囲んだ印）で文章を挟み、「ここは見出しです」「ここは段落です」と、その部分が持つ意味や役割をブラウザに伝えます。ブラウザはその意味を解釈し、見出しなら大きく太く表示するなど、ふさわしい見た目で画面に描画してくれます。なお、文字の色や配置といった具体的なデザインはHTMLではなくCSSが担当します。
