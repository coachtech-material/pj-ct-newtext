クライアントサーバーモデルとは、Webページの表示が「クライアント（サービスを要求する側）」と「サーバー（サービスを提供する側）」のやり取りで成り立つ、という基本的な仕組みのことです。クライアントとは私たちが使うWebブラウザのことで、サーバーに「このページをください」とリクエスト（要求）を送り、受け取ったデータを画面に描画します。サーバーとはWebページのデータが保管されたコンピュータのことで、リクエストを待ち受け、目的のデータを探し出して、レスポンス（応答）として送り返します。これはちょうど、レストランでお客さん（クライアント）が注文し、厨房（サーバー）が料理を作って返すのと同じ流れです。このリクエストとレスポンスの往復が、現代のインターネットの最も基本的な構造になっています。
