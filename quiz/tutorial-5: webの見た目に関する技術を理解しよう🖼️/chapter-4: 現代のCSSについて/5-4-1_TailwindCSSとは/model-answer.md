# 模範解答

Tailwind CSSとは、あらかじめ用意されたクラス名をHTMLに直接書くだけでスタイルを適用できる、「ユーティリティファースト」のCSSフレームワークです。従来のCSSでは、自分でクラス名を考えてCSSファイルにスタイルを書く必要がありましたが、Tailwindでは、たとえば`bg-blue-500`（背景を青に）や`text-white`（文字を白に）のようなクラスをHTMLに並べるだけでデザインが完結し、CSSファイルを書く必要がありません。ユーティリティファーストとは、一つのクラスが一つの機能を持つという設計思想で、クラス名から何をするかが推測できるよう作られています。Bladeテンプレートで`class="bg-blue-500 text-white p-4"`のような記述を見かけたら、「青い背景、白い文字、余白あり」と読み替えられれば十分です。
