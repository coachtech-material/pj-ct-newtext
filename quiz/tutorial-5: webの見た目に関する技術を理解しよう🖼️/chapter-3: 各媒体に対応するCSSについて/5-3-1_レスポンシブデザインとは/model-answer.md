レスポンシブデザインとは、PC・タブレット・スマートフォンなど、画面サイズの異なるさまざまなデバイスに対応するためのWebデザインの手法です。一つのHTMLファイルで、画面サイズに応じてレイアウトや文字サイズを自動的に調整します。これが必要なのは、利用者がいろいろな大きさの端末でページを見るため、どの端末でも快適に閲覧できるようにする必要があるからです。これを実現するのが、CSSの「メディアクエリ」という機能です。メディアクエリは`@media (条件) { ... }`という形で書き、その中のCSSは条件を満たす画面サイズのときだけ適用されます。これにより、「PCでは横並び、スマホでは縦並び」といったレイアウトの切り替えが可能になります。CSSで`@media`を見かけたら、「画面サイズによって表示を切り替えている」と理解すれば大丈夫です。
