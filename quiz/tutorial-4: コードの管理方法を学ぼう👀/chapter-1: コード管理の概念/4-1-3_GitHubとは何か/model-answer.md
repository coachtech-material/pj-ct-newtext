# 模範解答

GitHubとは、Gitのリポジトリ（変更履歴の保管庫）をインターネット上で預かって公開してくれるWebサービスのことです。Gitがバージョン管理を行うための「道具」だとすれば、GitHubはその成果を共有するための「作業場所」にあたり、ちょうど文書を作る「Word」と、それを共有する「Google Drive」のような関係です。GitHubには主要な機能が3つあります。1つ目は「リモートリポジトリ」で、ローカルの変更をアップロードしたり他の人の変更をダウンロードしたりして、チームで同じ最新のコードを共有できる中心的な場所です。2つ目は「プルリクエスト」で、自分の変更を本体に取り込む前に、他のメンバーにコードを一行ずつレビューしてもらえる仕組みです。3つ目は「Issues」で、タスク管理やバグ報告、機能提案を行う掲示板のような機能です。これらにより、GitHubは現代のソフトウェア開発における中心的なハブとなっています。
