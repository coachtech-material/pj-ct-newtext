# 模範解答

イメージとコンテナの関係は、「たい焼きの型」と「たい焼き」の関係にたとえると分かりやすいです。イメージとは、たい焼きの型のような「設計図」で、「どんな環境であるか」を定義したものに過ぎず、それ自体は動きません。一方コンテナは、その型を使って作られた「たい焼き」、つまり実際に動く具体的な実体です。同じ型からあんこ入りやクリーム入りのたい焼きをいくつでも作れるように、一つのイメージ（たとえば`nginx`）から複数のコンテナを作成でき、それぞれが互いに独立して動作します。なお、このイメージはDockerfileという設計図を`docker build`することで作られ、Docker Hubという保管庫から取得することもできます。イメージとコンテナをはっきり分けるこの仕組みが、Dockerの高い再利用性と移植性を支えています。
