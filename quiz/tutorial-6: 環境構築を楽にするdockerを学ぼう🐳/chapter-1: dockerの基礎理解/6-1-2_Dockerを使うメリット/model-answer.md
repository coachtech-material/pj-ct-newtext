# 模範解答

Dockerを使う主なメリットは大きく二つあります。一つ目は「開発環境の爆速セットアップと標準化」です。これまで何時間もかかっていた環境構築が、構成ファイル（`Dockerfile`や`docker-compose.yml`）を使えばコマンド一つで数分で完了します。このファイルをGitでチームに共有すれば、全員が寸分違わぬ同じ開発環境を使えるため、「Aさんでは動くがBさんでは動かない」といったトラブルに時間を取られず、本来の開発に集中できます。二つ目は「移植性の高さ」です。コンテナは自己完結していてどこでも同じように動くため、開発で使ったコンテナをそのまま本番サーバーに持って行け、「開発では動いたのに本番で動かない」というリスクを大幅に減らせます。さらにクラウドサービスを変更する際の移行もスムーズで、インフラの選択肢を柔軟に保てます。
