# 模範解答

Dockerとは、どこでも同じように動く箱である「コンテナ」を作り、その中でアプリケーションを動かすための技術です。これは「自分のPCでは動いたのに、他の人のPCや本番サーバーでは動かない」という、環境差異が引き起こす昔からの問題を解決するために使われます。コンテナとは、アプリケーションを、その実行に必要なOSの一部やライブラリ（部品）、設定ファイルなどとひとまとめにパッケージングしたものです。コンテナはホストOS（自分のPCのOS）から隔離されていて軽量なので、起動や停止も数秒で済みます。さらにDockerは、アプリが動く環境そのものを構成ファイルというコードとして定義し共有できる（Infrastructure as Code）ため、チームの誰もがどこでも全く同じ環境を瞬時に再現でき、環境差異の問題が根本から解決されます。
