# T01: プログラミング学習をはじめる前に（Style I: ジオメトリック）

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。プログラミング初学者向けのモダンで親しみやすいデザインにしてください。

【スタイル: Geometric】
- 背景: 明るいミントグリーン（#81C784）
- 背景に大きめの幾何学模様を配置（丸、三角、四角の組み合わせ）
- 幾何学模様は白色、透明度20-30%で控えめに
- 幾何学模様は画像の隅々に散りばめる
- 画像全体に角丸（24px程度）で柔らかい印象

【テキスト配置】
- 画像中央に、白で大きく「プログラミング学習をはじめる前に」と表示
- フォント: ゴシック体、太めのウェイト
- 文字に薄いドロップシャドウ（透明度25%）で可読性確保

【全体の雰囲気】
- シンプルでモダンな印象
- 幾何学模様でプログラミングの論理的なイメージを演出
- テキストの可読性を最優先
- アスペクト比 3:2（横長）
```
