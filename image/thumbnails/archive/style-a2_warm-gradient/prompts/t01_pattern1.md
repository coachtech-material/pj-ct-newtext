# T01: プログラミング準備（Pattern 1: サブキーワードあり）

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。プログラミング初学者向けの温かく親しみやすいデザインにしてください。

【スタイル: Warm Gradient Card】
- 背景: 緑色の温かみのあるグラデーション（左下 #43A047 → 右上 #A5D6A7）、柔らかいグラデーション
- 背景に控えめな幾何学模様（薄い白の丸・六角形パターン、透明度8%）
- 画像全体に角丸（20px程度）で柔らかい印象
- 右下にかわいいフラットデザインの小さなイラスト: 芽が出た植物の鉢植え（白色、透明度60%、装飾的）

【テキスト配置】
- 画像中央やや上に、白文字で大きく「プログラミング準備」と表示（極太ゴシック体、文字に薄いドロップシャドウ）
- その下に白文字（透明度85%）で「プログラミング学習をはじめる前に」と表示（やや小さめ、通常ウェイト）
- 番号は表示しない

【全体の雰囲気】
- 温かく親しみやすいカード風デザイン
- 初学者が「やってみたい」と思える雰囲気
- テキストの可読性を最優先、太文字+ドロップシャドウで視認性確保
- アスペクト比 3:2（横長）
```
