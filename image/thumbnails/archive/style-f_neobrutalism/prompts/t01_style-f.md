# T01: プログラミング準備（Style F: Neobrutalism）

**スタイル**: Neobrutalism | **アスペクト比**: 3:2

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【スタイル: Neobrutalism（トレンド・ポップ）】
- 背景: 鮮やかな緑色（#4CAF50）のベタ塗り背景

【メインテキストブロック】
- 画像中央に白い長方形ブロック（角丸なし、シャープなエッジ）
- ブロックの外周に太い黒ボーダー（4px）
- ブロックの右下に黒いオフセットドロップシャドウ（8pxずれ、ぼかしなし）
- ブロック内に黒文字で大きく「プログラミング準備」（極太ゴシック体）
- ブロック内、メインテキストの下に小さく「はじめの一歩」（黒文字、通常ウェイト）

【番号バッジ】
- 左上に黒い丸の中に白文字で「01」（太字）
- 丸にも黒ボーダー + オフセットシャドウ

【装飾】
- 背景に散らばる小さな装飾要素（星、丸、三角、×マーク）黒色、ランダム配置

【全体の雰囲気】
- Neobrutalism（ネオブルータリズム）デザイントレンド
- 太いボーダー、オフセットシャドウが特徴
- ポップで親しみやすく、目を引くデザイン
- チャンキーで力強いタイポグラフィ
- アスペクト比 3:2（横長）
```
