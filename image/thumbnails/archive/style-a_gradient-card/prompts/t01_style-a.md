# T01: プログラミング準備（Style A: Gradient Card）

**スタイル**: Gradient Card | **アスペクト比**: 3:2

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【スタイル: Gradient Card（モダン・クリーン）】
- 背景: 緑色のグラデーション（左上 #388E3C ダークグリーン → 右下 #81C784 ライトグリーン）
- 背景に控えめな幾何学模様（薄い白の三角形・六角形パターン、透明度10-15%）
- 左上に白い丸角バッジで「01」と番号を表示（バッジサイズは画像の8%程度）

【テキスト配置】
- 画像中央やや上に、白文字で大きく「プログラミング準備」と表示（太字、サンセリフ体）
- その下に小さめの白文字で「はじめの一歩」と表示（通常ウェイト）
- テキストの周囲に十分な余白を確保

【全体の雰囲気】
- モダンでクリーンなカード風デザイン
- テキストの可読性を最優先
- プログラミング教材のサムネイルとして洗練された印象
- アスペクト比 3:2（横長）
```
