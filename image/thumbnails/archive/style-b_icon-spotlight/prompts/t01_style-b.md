# T01: プログラミング準備（Style B: Icon Spotlight）

**スタイル**: Icon Spotlight | **アスペクト比**: 3:2

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【スタイル: Icon Spotlight（テック・スタートアップ風）】
- 背景: ダークグレー（#1E1E2E）のフラット背景
- 画像中央に大きなフラットデザインのアイコン: ロケット発射台のアイコン（プログラミングの「はじめの一歩」を象徴）
- アイコンの色: 緑色（#4CAF50）、シンプルなフラットスタイル
- アイコンの周囲に緑色の淡いグロー効果（ぼんやりとした発光、透明度20%）

【テキスト配置】
- アイコンの下方に白文字で大きく「プログラミング準備」と表示（太字、サンセリフ体）
- その下に小さめの白文字（透明度70%）で「はじめの一歩」と表示
- 左上に小さく「01」と番号（白文字、透明度50%）

【全体の雰囲気】
- テック系スタートアップ風のダークUIデザイン
- アイコンが主役で、テキストは補助的
- 洗練されたプロフェッショナルな印象
- アスペクト比 3:2（横長）
```
