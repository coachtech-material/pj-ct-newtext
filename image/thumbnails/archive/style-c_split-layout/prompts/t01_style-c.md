# T01: プログラミング準備（Style C: Split Layout）

**スタイル**: Split Layout | **アスペクト比**: 3:2

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【スタイル: Split Layout（マガジン・エディトリアル風）】
- 画像を左右に分割（斜め分割線、左40% / 右60%）
- 左側: 緑色ベタ塗り（#4CAF50）
  - 中央に白文字で大きく「01」と番号表示
  - その下に小さく白文字で「Tutorial」
- 右側: 白背景
  - 中央やや左寄りに、緑色（#4CAF50）の太文字で「プログラミング準備」
  - その下に薄いグレー文字で「はじめの一歩」
  - 右側の背景に薄い抽象的な幾何学イラスト（回路基板パターン、透明度8%、グレー）

【分割線】
- 斜め直線（左上から右下方向、角度約15度）
- シャープなエッジ

【全体の雰囲気】
- マガジン・エディトリアル風のレイアウト
- 太字タイポグラフィを活かしたデザイン
- クリーンで洗練された印象
- アスペクト比 3:2（横長）
```
