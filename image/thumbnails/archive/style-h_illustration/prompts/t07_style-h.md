# T07: PHPを使ってプログラミングをはじめよう（Style H: イラストカード）

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。プログラミング初学者向けの温かく親しみやすいデザインにしてください。

【スタイル: Illustration Card】
- 背景: 明るいラベンダー色のソリッドカラー（#CE93D8）
- 画像全体に角丸（24px程度）で柔らかい印象

【イラスト】
- 画像の右側に、かわいいフラットデザインのイラストを配置
- イラスト内容: コードエディタの画面、または <?php のコードが浮かんでいるイメージ
- イラストスタイル: シンプルなフラットデザイン、パステルカラー、親しみやすい雰囲気
- イラストサイズ: 画像の40%程度

【テキスト配置】
- 画像の左側〜中央に、白で大きく「PHPを使ってプログラミングをはじめよう」と表示
- フォント: 丸ゴシック体、太めのウェイト
- 文字に薄いドロップシャドウ（透明度20%）で立体感と可読性確保

【全体の雰囲気】
- イラストで直感的に内容がわかる
- 初学者が「やってみたい」と思える親しみやすさ
- テキストの可読性を最優先
- アスペクト比 3:2（横長）
```
