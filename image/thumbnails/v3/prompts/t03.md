# T03: コマンドライン入門

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は非常に太く描くこと。細い線は不可。画像の短辺の6%以上の太さを確保すること

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#616161）を配置する。色帯の太さは画像の短辺の6%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル】
- 画像中央にターミナル画面のアイコンを大きく配置
- 角丸の長方形（黒色 #212121 の背景）でターミナルウィンドウを表現
- ウィンドウ上部にタイトルバー（3つの小さな丸: 赤・黄・緑のウィンドウボタン）
- ウィンドウ内に緑色（#4CAF50）で「$_」のプロンプト記号を表示（点滅カーソルを示唆）
- 全体のサイズは高さ約150px相当、画像中央に堂々と大きく配置

【下部テキスト】
- アイコンの下に「コマンドライン入門」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの10%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に3列×5行の小さな円形ドットグリッド（色: #616161、透明度30%）
- 右上にも同じ3列×5行のドットグリッド（色: #616161、透明度30%）
- ドット直径4px、ドット間隔10px

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし
- 最高解像度・高精細で出力すること
```
