# T13: 総合アプリケーション開発

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は非常に太く描くこと。細い線は不可。画像の短辺の6%以上の太さを確保すること

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#FFA726）を配置する。色帯の太さは画像の短辺の6%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル】
- 画像中央にロケット打ち上げアイコンを大きく配置
- ロケット: アンバー色（#FFA726）のソリッドなフラットデザイン、斜め45度右上に向かって飛翔する姿
- ロケット本体はシンプルな流線型、窓が1つ、下部に噴射炎
- ロケットの軌跡として、小さな「</>」コードブラケットと丸いドットが弧を描いて散りばめられている（#FFA726、透明度40%）
- 飛躍・集大成・次のステージへの出発を象徴するデザイン
- 全体のサイズは高さ約150px相当、画像中央に堂々と大きく配置

【下部テキスト】
- アイコンの下に「総合アプリケーション開発」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの10%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に3列×5行の小さな円形ドットグリッド（色: #FFA726、透明度30%）
- 右上にも同じ3列×5行のドットグリッド（色: #FFA726、透明度30%）
- ドット直径4px、ドット間隔10px

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし
- 最高解像度・高精細で出力すること
```
