# T15: 開発の仕組み化

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#7E57C2`

## 設計意図

Tutorial15「AI開発を仕組み化しよう⚙️」用。5つの章（仕組み化という考え方／プロジェクトの記憶 CLAUDE.md／手続きの部品化 Skills と Subagent／ルールの自動執行 権限と Hooks）に対応する4アイコン。

テーマカラーはパープル。既存の薄紫（#9FA8DA、PHP入門）より濃く彩度が高いため混同しない。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一のパープルの色帯（#7E57C2）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル - 4つのアイコンをダイヤモンド型に配置】
- 画像中央エリアに4つのアイコンをダイヤモンド型（上・左・右・下）に配置
- アイコン同士をパープルのの細い接続線（#7E57C2、透明度35%）で結ぶ。4辺に加えて左右を横断する線と上下を縦断する線も引く
- 全体で画像幅の65%程度を使用
- すべてフラットな線画アイコンとし、影・グラデーション・グローは付けない

1. 上（最大）: 歯車（仕組み化）
   - 8つの歯を持つ歯車。中心に穴（塗りつぶしの円）
   - 濃いパープル（#5E35B1）。4つの中で最も大きく

2. 左: ドキュメント（プロジェクトの記憶・CLAUDE.md）
   - 右上の角が折れた書類アイコン
   - 中に3本のテキスト行（1本目は濃く、残り2本は薄く）

3. 右: 部品ブロック（手続きの部品化・Skills と Subagent）
   - 角丸の正方形を2×2で配置
   - 右下の1つだけ塗りつぶし（組み込み済みの部品を表す）

4. 下: 盾（ルールの自動執行・権限と Hooks）
   - 盾の輪郭。中にチェックマーク
   - 「危ない操作を自動で止める」ことを表現

【下部テキスト】
- アイコン群の下に「開発の仕組み化」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの11%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に6列×4行の小さな円形ドットグリッド（色: #7E57C2、透明度32%）
- 右上にも同じ6列×4行のドットグリッド（色: #7E57C2、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし、グローなし
- 最高解像度・高精細で出力すること
```
