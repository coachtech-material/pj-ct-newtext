# T15: 開発の仕組み化

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#7E57C2`

## 設計意図

Tutorial15「AI開発を仕組み化しよう⚙️」用。歯車の中心に Claude を据えることで、「AIを仕組みの中に組み込む」という教材の主題（CLAUDE.md・Skills・Subagent・Hooks）を1つの図で表している。

テーマカラーはパープル。既存の薄紫（#9FA8DA、PHP入門）より濃く彩度が高いため混同しない。中心の Claude だけコーラル（#D97757）にして視線を集める。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#7E57C2）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）
- フラットデザイン。影・グラデーション・グローは一切付けない

【中央ビジュアル - 歯車の中心に Claude】
- 画像の中央やや上に、大きな歯車を1つ配置する（画像高さの約55%）
- 歯車はパープル（#7E57C2）の塗り。歯は12個、均等な間隔で、先端は軽く丸める
- 歯車の中心を大きく丸くくり抜き、白（#FFFFFF）にする
- くり抜いた白い円の中に、Claude（Anthropic）のロゴをコーラル（#D97757）で配置する
  - 中心から放射状に伸びる12本の花弁状のマーク。先端が丸く、根元に向かって細くなる
  - 白い円の内側に余裕を持って収まる大きさにする
- 歯車とロゴ以外の要素は置かない

【下部テキスト】
- 中央ビジュアルの下に「開発の仕組み化」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの11%程度

【ドットグリッド装飾】
- 左下と右上に、6列×4行の小さな円形ドットグリッド（色: #7E57C2、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- 主役を大きく置き、余白を十分に取る
- クリーンでプロフェッショナル
- 最高解像度・高精細で出力すること
```
