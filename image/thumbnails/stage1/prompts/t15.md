# T15: 開発の仕組み化

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2

## コンセプト

- Stage 1 で新設した教材。4章の題材（プロジェクトの記憶 CLAUDE.md / 手続きの部品化 Skills・Subagent / ルールの自動執行 権限・Hooks）をそのままミニアイコンにする
- 中央は設定ファイル。「AIに渡す設定を整えることが仕組み化そのもの」という教材の主題を1枚で表す
- **Claude のロゴは入れない**。T14 が Claude ロゴを主役にしているため、同じロゴを2枚続けると一覧で見分けがつかなくなる。またパープルの枠にコーラルのロゴを載せると配色が濁る
- テーマカラーはパープル。既存の薄紫（#9FA8DA、PHP入門）より濃く彩度が高いため混同しない

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#7E57C2）を配置する。色帯の太さは画像の短辺の6%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル - 設定ファイルと自動化の部品】
- 画像中央に設定ファイルのアイコンを配置（パープル #7E57C2 のフラットなシルエット、右上の角が折れた書類の形、内側は白抜き）
- ファイルの中に、白抜きではなくパープルの短いテキスト行を3本引く（設定が書き込まれている様子）
- ファイルサイズ: 高さ約180px相当

- ファイルの周囲に、仕組み化の部品を表すミニアイコンを4つ、ゆるやかな弧を描くように散りばめる
- 各ミニアイコンサイズ: 高さ約45px相当、シンプルなシルエットで表現

  1. 左上: 部品ブロック（手続きの部品化。角丸の正方形を2×2で並べ、1つだけ塗りつぶす。パープル #7E57C2）
  2. 右上: 分身するエージェント（同じ丸いアイコンが3つ少しずつ重なって並ぶ。パープル #7E57C2）
  3. 右下: 盾にチェックマーク（ルールの自動執行。パープル #7E57C2）
  4. 左下: 鍵（権限。シンプルな鍵のシルエット。アンバー #FFB300）

- ミニアイコンから中央のファイルに向かって、薄い点線（#7E57C2、透明度25%）を引き、「設定に集約される」感を表現

【下部テキスト】
- ビジュアルの下に「開発の仕組み化」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの10%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に3列×5行の小さな円形ドットグリッド（色: #7E57C2、透明度30%）
- 右上にも同じ3列×5行のドットグリッド（色: #7E57C2、透明度30%）
- ドット直径4px、ドット間隔10px

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし
- 「一度整えれば、あとは仕組みが働き続ける」整然とした印象
- 最高解像度・高精細で出力すること
```
