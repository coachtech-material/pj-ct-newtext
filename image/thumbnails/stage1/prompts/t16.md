# T16: 総合アプリケーション開発

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#D4A017`

## 設計意図

Tutorial16「総仕上げ！学んだ技術をフル活用してアプリケーションを作ってみよう🔥」用。

**旧 Tutorial13 と区別できることが必須要件。** 旧 Tutorial13（同名の総仕上げ教材）は LMS 上にアーカイブとして残り、アイキャッチも従来のまま変更しない。そのため新 Tutorial16 には、旧 Tutorial13 のサムネイル（Laravel・Docker・MySQL・GitHub の4ロゴ）に **中心の Claude を加えた構図**を採り、「学んだ技術を AI とともに統合する」という新カリキュラムの主題で差別化している。

ゴールドは既存 v4/t13 から引き継いだ「最終ステージ」の色。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#D4A017）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）
- フラットデザイン。影・グラデーション・グローは一切付けない

【中央ビジュアル - 中心の Claude と4つの技術ロゴ】
- 画像中央に Claude（Anthropic）のロゴをコーラル（#D97757）で配置する。5つの中で最も大きく
  - 中心から放射状に伸びる12本の花弁状のマーク。先端が丸く、根元に向かって細くなる
- その上下左右に、これまで学んだ4つの技術のロゴを配置する

  1. 上: Laravelロゴ（赤 #FF2D20、斜めの「L」を図案化したシンボル）
  2. 左: Dockerロゴ（青 #2496ED、背中にコンテナを載せたクジラ）
  3. 右: データベースの円柱アイコン（青緑 #00758F）。※ロゴタイプ（"MySQL"の文字）は入れない
  4. 下: GitHubロゴ（黒 #181717、丸の中にネコのシルエット）

- 中心の Claude と4つのロゴを、ゴールド（#D4A017、透明度60%）の直線で結ぶ
- 線は各ロゴに触れないよう、手前で止める

【下部テキスト】
- 中央ビジュアルの下に「総合アプリケーション開発」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの9%程度

【ドットグリッド装飾】
- 左下と右上に、6列×4行の小さな円形ドットグリッド（色: #D4A017、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- 主役を大きく置き、余白を十分に取る
- クリーンでプロフェッショナル
- 最高解像度・高精細で出力すること
```
