# T13: システム設計

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#455A64`

## 設計意図

Tutorial13「システム設計を学ぼう📐」用。特定の技術ロゴを持たない教材なので、**設計図そのもの**を主役に据えた。1枚の画面の中に画面設計・データ設計・振る舞いの設計が同居している構図で、8章ぶんの守備範囲の広さを表している。

テーマカラーは既存13枚が使っていないブルーグレー（製図の質感）。単色だと沈むため、オレンジ（#FF7043）を2箇所だけ差し色に使っている。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#455A64）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）
- フラットデザイン。影・グラデーション・グローは一切付けない

【中央ビジュアル - 1枚の大きな設計図】
- 画像の中央に、大きなブラウザウィンドウ風の枠を1つ置く（画像幅の約60%）
- 濃いブルーグレー（#37474F）の太い線画。角は軽く丸める
- 上部にタイトルバーを設け、左側に小さな丸を3つ並べる。うち1つだけオレンジ（#FF7043）にしてアクセントにする
- 枠の中を3つの領域に分けて、設計の成果物を配置する

  1. 左側: 画面設計のワイヤーフレーム
     - 薄いブルーグレーの塗りブロック。中にテキスト行を3本
     - 下部にオレンジ（#FF7043）の塗りボタンを1つ

  2. 右上: データ設計のER図
     - テーブル記号（角丸長方形の上部に横線が1本入った形）を2つ、斜めにずらして配置
     - 2つをオレンジ（#FF7043）の線で結ぶ（リレーション）

  3. 右下: 振る舞いの設計のシーケンス
     - 小さな塗りの長方形を2つ横に並べ、その間に右向きの矢印を1本

【下部テキスト】
- 中央ビジュアルの下に「システム設計」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの11%程度

【ドットグリッド装飾】
- 左下と右上に、6列×4行の小さな円形ドットグリッド（色: #455A64、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- 主役を大きく置き、余白を十分に取る
- クリーンでプロフェッショナル
- 最高解像度・高精細で出力すること
```
