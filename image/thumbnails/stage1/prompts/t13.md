# T13: システム設計

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2

## コンセプト

- Stage 1 で新設した教材。特定の技術ロゴを持たないため、v4/t01 と同じ「中央に主役＋周囲にミニアイコン」の構成を採り、設計図を主役に据える
- 8章ぶんの守備範囲（画面設計・データ設計・API と権限・振る舞い・テスト）をミニアイコンで表現する
- テーマカラーは既存13枚が使っていないブルーグレー。製図・設計図の質感を狙う

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#455A64）を配置する。色帯の太さは画像の短辺の6%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル - 設計図と設計成果物】
- 画像中央に、設計図を表すブラウザウィンドウ風の枠を配置（ブルーグレー #455A64 のフラットな線画、内側は白抜き）
- 枠の上部にタイトルバーを設け、左端に小さな丸を3つ並べる。3つのうち1つだけオレンジ（#FF7043）にする
- 枠の中は、左側に画面レイアウトのワイヤーフレーム（薄いブルーグレーの塗りブロックとテキスト行）、右側に空白を残す
- 設計図サイズ: 高さ約200px相当

- 設計図の周囲に、設計成果物のミニアイコンを4つ、ゆるやかな弧を描くように散りばめる
- 各ミニアイコンサイズ: 高さ約45px相当、シンプルなシルエットで表現

  1. 左上: ER図（角丸長方形の上部に横線が1本入ったテーブル記号を2つ、短い線で結ぶ。ブルーグレー #455A64）
  2. 右上: API（大きな波括弧 { } の間に小さな円を3つ横並び。ブルーグレー #455A64）
  3. 右下: 権限の鍵（シンプルな鍵のシルエット。オレンジ #FF7043）
  4. 左下: シーケンス（2本の短い縦の破線の間に右向きの矢印。ブルーグレー #455A64）

- ミニアイコンから設計図に向かって、薄い点線（#455A64、透明度25%）を引き、「すべてが1枚の設計に集まる」感を表現

【下部テキスト】
- ビジュアルの下に「システム設計」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの10%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に3列×5行の小さな円形ドットグリッド（色: #455A64、透明度30%）
- 右上にも同じ3列×5行のドットグリッド（色: #455A64、透明度30%）
- ドット直径4px、ドット間隔10px

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし
- 「作る前に考える」「設計図から始まる」落ち着いた知的な印象
- 最高解像度・高精細で出力すること
```
