# T13: システム設計

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#455A64`

## 設計意図

Tutorial13「システム設計を学ぼう📐」用。特定の技術ロゴを持たない教材なので、8つの章が扱う設計成果物（画面設計・データ設計・API設計・振る舞いの設計）をアイコン化して4点に配置した。

テーマカラーは既存13枚が使っていないブルーグレー。製図・設計図の質感を狙っている（既存は緑#66BB6A・青#42A5F5・Git橙#F05032・Docker青#2496ED・薄紫#9FA8DA・濃青#0277BD・赤#FF5252・ティール#26A69A・橙#FFA726 を使用済み）。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一のブルーグレーの色帯（#455A64）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル - 4つのアイコンをダイヤモンド型に配置】
- 画像中央エリアに4つのアイコンをダイヤモンド型（上・左・右・下）に配置
- アイコン同士をブルーグレーのの細い接続線（#455A64、透明度35%）で結ぶ。4辺に加えて左右を横断する線と上下を縦断する線も引く
- 全体で画像幅の65%程度を使用
- すべてフラットな線画アイコンとし、影・グラデーション・グローは付けない

1. 上（最大）: 画面ワイヤーフレーム（画面設計）
   - ブラウザウィンドウ風の枠。上部にタイトルバーと2つの小さな丸
   - 中に左のサイドブロックと右のテキスト行を配置したレイアウト
   - 濃いブルーグレー（#37474F）の線画。4つの中で最も大きく

2. 左: ER図（データ設計）
   - 2つのテーブル記号（角丸の長方形の上部に横線が1本入った形）を斜めにずらして配置
   - 2つを短い線で結ぶ（リレーション）

3. 右: API（APIと権限の設計）
   - 大きな波括弧 { } を左右に配置し、その間に3つの小さな円を横並びに置く（JSONを象徴）

4. 下: シーケンス図（振る舞いの設計）
   - 2本の縦の破線（ライフライン）。それぞれの上端に小さな塗りつぶしの長方形
   - ライフライン間に右向きの矢印を1本

【下部テキスト】
- アイコン群の下に「システム設計」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの11%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に6列×4行の小さな円形ドットグリッド（色: #455A64、透明度32%）
- 右上にも同じ6列×4行のドットグリッド（色: #455A64、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし、グローなし
- 最高解像度・高精細で出力すること
```
