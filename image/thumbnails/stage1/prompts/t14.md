# T14: AI駆動開発

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2

## コンセプト

- Stage 1 で新設した教材。主役が Claude Code そのものなので、Claude のロゴを大きく中央に据える
- 既存で最も映えている t09（Laravel基礎）と同じ「巨大なロゴ1つ」の潔さを狙いつつ、周囲に開発サイクル（意図を伝える → 計画 → 検証 → 回し続ける）のミニアイコンを添える
- テーマカラーは Claude のブランドカラーに合わせたコーラル。既存の赤（#FF5252 / #EF5350）とは色相・彩度が異なるため一覧で識別できる

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#D97757）を配置する。色帯の太さは画像の短辺の6%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル - Claude のロゴと開発サイクル】
- 画像中央に Claude（Anthropic の AI アシスタント）の公式ロゴマークを大きく配置する
  - 中心から放射状に外へ伸びる、花弁のような細長い形が12本ぐるりと並んだシンボル
  - 各花弁は先端が丸く、根元に向かってすぼまる。長さは不揃いで、手描きのような有機的なリズムがある
  - 色はコーラル（#D97757）の単色。グローや光の輪は付けない。ロゴそのものを大きく堂々と配置する
  - サイズ: 高さ約230px相当、画像の主役として最も大きく目立つように

- Claude ロゴの周囲に、AIと進める開発サイクルのミニアイコンを4つ、ゆるやかな弧を描くように散りばめる
- 各ミニアイコンサイズ: 高さ約45px相当、シンプルなシルエットで表現

  1. 左上: 吹き出し（意図を伝える。角丸の吹き出しに短いテキスト行が2本。コーラル #D97757）
  2. 右上: チェックリスト（計画。角丸の枠にチェックマークと行が2つ。コーラル #D97757）
  3. 右下: 虫めがね（検証と受け取り。コーラル #D97757）
  4. 左下: 循環矢印（回し続ける。ほぼ一周する円弧の先に三角の矢じり。コーラル #D97757）

- ミニアイコンから中央のロゴに向かって、薄い点線（#D97757、透明度25%）を引く

【下部テキスト】
- ビジュアルの下に「AI駆動開発」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの10%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に3列×5行の小さな円形ドットグリッド（色: #D97757、透明度30%）
- 右上にも同じ3列×5行のドットグリッド（色: #D97757、透明度30%）
- ドット直径4px、ドット間隔10px

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし
- 「AIを相棒にして開発が加速する」前向きで軽快な印象
- 最高解像度・高精細で出力すること
```
