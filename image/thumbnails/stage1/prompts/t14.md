# T14: AI駆動開発

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#D97757`

## 設計意図

Tutorial14「AIを率いて開発しよう🤖」用。既存の t09（Laravel基礎）と同じ「巨大なロゴ1枚」の構図。教材の主役が Claude Code そのものなので、余計な要素を足さずロゴだけで見せている。

テーマカラーは Claude のブランドカラーに合わせたコーラル。既存13枚の赤（#FF5252 / #EF5350）とは色相・彩度が異なるため一覧で識別できる。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一の色帯（#D97757）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）
- フラットデザイン。影・グラデーション・グローは一切付けない

【中央ビジュアル - Claude のロゴ1つ】
- 画像の中央やや上に、Claude（Anthropic）のロゴを1つだけ、大きく配置する
- 中心から放射状に伸びる12本の花弁状のマーク。各花弁は先端が丸く、根元に向かって細くなる
- 色はコーラル（#D97757）の単色塗り。輪郭線・影・グローは付けない
- 大きさは画像高さの約50%。他の要素は一切置かず、ロゴだけで主役を張らせる

【下部テキスト】
- 中央ビジュアルの下に「AI駆動開発」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの11%程度

【ドットグリッド装飾】
- 左下と右上に、6列×4行の小さな円形ドットグリッド（色: #D97757、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- 主役を大きく置き、余白を十分に取る
- クリーンでプロフェッショナル
- 最高解像度・高精細で出力すること
```
