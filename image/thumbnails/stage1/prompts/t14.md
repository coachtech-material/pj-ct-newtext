# T14: AI駆動開発

**スタイル**: Tech Blog Card | **アスペクト比**: 3:2 | **テーマカラー**: `#D97757`

## 設計意図

Tutorial14「AIを率いて開発しよう🤖」用。5つの章（立ち上げ／意図を伝える／計画／検証と受け取り／回し続ける技術）に対応する4アイコン。

テーマカラーは Claude のブランドカラーに合わせたコーラル。既存13枚の赤（#FF5252 / #EF5350）とは彩度・色相が異なるため一覧で識別できる。

## プロンプト本文

```
LMS教材一覧のサムネイル画像を作成してください。

【厳守事項 ※以下を必ず守ること】
- 画像の四隅は完全な直角90度にすること。角丸は一切付けない
- 色付きの枠線は画像の一番外側のピクセルから始めること。枠線の外側に白い隙間や余白は絶対に入れない。画像の端＝枠線の外端にすること
- 枠線（色帯）は極太に描くこと。細い線は絶対に不可。画像の短辺の10%以上の太さを確保すること。太すぎるくらいでちょうどよい。参考: 1024px高なら上下左右それぞれ100px以上の帯

【スタイル: Tech Blog Card】
- 白背景（#FFFFFF）の長方形レイアウト
- 画像の上下左右の辺に沿って、太さ均一のコーラルの色帯（#D97757）を配置する。色帯の太さは画像の短辺の10%とし、すべての辺で同じ太さにすること
- アスペクト比 3:2（横長）

【中央ビジュアル - 4つのアイコンをダイヤモンド型に配置】
- 画像中央エリアに4つのアイコンをダイヤモンド型（上・左・右・下）に配置
- アイコン同士をコーラルのの細い接続線（#D97757、透明度35%）で結ぶ。4辺に加えて左右を横断する線と上下を縦断する線も引く
- 全体で画像幅の65%程度を使用
- すべてフラットな線画アイコンとし、影・グラデーション・グローは付けない

1. 上（最大）: ターミナルウィンドウ（AIと対話しながら作る）
   - 角丸の長方形にタイトルバーと2つの小さな丸
   - 中に大きなプロンプト記号「>」とカーソルを表す塗りつぶしの短い長方形
   - 濃いコーラル（#B85C3E）の線画。4つの中で最も大きく

2. 左: 吹き出し（意図を伝える）
   - 左下にしっぽの付いた角丸の吹き出し
   - 中に3本のテキスト行（1本目は濃く、残り2本は薄く）

3. 右: チェックリスト（計画）
   - 角丸の長方形の中に、チェックマーク2つとテキスト行を並べる
   - 3行目はチェックなしの薄いテキスト行（未着手を表す）

4. 下: 循環矢印（回し続ける技術）
   - ほぼ一周する太い円弧。終端に進行方向を向いた三角の矢印
   - 「検証して次の一手へ回す」ループを表現

【下部テキスト】
- アイコン群の下に「AI駆動開発」と表示
- 黒色（#212121）、太字、ゴシック体（サンセリフ）、中央揃え
- フォントサイズは画像高さの11%程度、大きく目立つように

【ドットグリッド装飾】
- 左下に6列×4行の小さな円形ドットグリッド（色: #D97757、透明度32%）
- 右上にも同じ6列×4行のドットグリッド（色: #D97757、透明度32%）
- ドット直径は画像幅の1.3%程度、ドット間隔はドット直径の2.4倍程度

【全体の雰囲気】
- 日本の技術ブログのアイキャッチ画像風
- クリーンでプロフェッショナル
- 余白を十分に取り、すっきりとした印象
- フラットデザイン、影なし、グローなし
- 最高解像度・高精細で出力すること
```
