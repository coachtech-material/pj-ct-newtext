# Stage 1 追加教材のサムネイル

Stage 1 で新設した Tutorial 13〜16 のカリキュラム一覧用サムネイル。既存 v2〜v4 と同じ **画像生成モデルで出力する**ワークフローで、規格も同じ 1264×848（3:2）。

## 使い方

`prompts/*.md` の「プロンプト本文」のコードブロックを画像生成モデルにそのまま渡し、出力を `output/t1{3,4,5,6}.png` として保存する。**現時点で `output/` は未生成。**

プロンプトは v4 の書式（`【厳守事項】`／`【スタイル: Tech Blog Card】`／`【中央ビジュアル】`／`【下部テキスト】`／`【ドットグリッド装飾】`／`【全体の雰囲気】`）に厳密に揃えてある。色帯の太さ・ドットグリッドの列数・フォントサイズ比も既存と同じ値にしているので、一覧に並べたときにトーンが揃う。

### 生成時に確認すること

既存プロンプトの冒頭に厳守事項が並んでいるのは、生成モデルがこれらを崩しやすいため。出力を採用する前に次を確認する。

- 四隅が直角か（角丸になっていないか）
- 色帯が画像の最外周から始まっているか（外側に白い隙間ができていないか）
- 色帯が十分に太いか
- 下部テキストが左右の色帯にかかっていないか（特に T16 は文字数が多い）
- T14 / T16 の Claude ロゴが、放射状の花弁が並んだ形になっているか（星形や太陽のような単純な形に化けやすい）

## Tutorial16 と旧 Tutorial13 の区別

新 Tutorial16 は旧 Tutorial13 と**同名の総仕上げ教材**で、LMS 上では旧 Tutorial13 がアーカイブとして残り続けるため一覧に2つ並ぶ。

**旧 Tutorial13 のアイキャッチは変更しない方針**なので、区別は新 Tutorial16 側で作る。旧 Tutorial13 は「中央に Laravel、周囲に Docker・MySQL・GitHub」（`../v4/output/t13.png`）なので、新 Tutorial16 は**中央を Claude に差し替え、Laravel を周囲に降ろした**構図にした。

## T14 と T15 で Claude ロゴを重複させない

T14 は Claude ロゴを主役に据えている。T15 も Claude Code の教材だが、**同じロゴを2枚続けると一覧で見分けがつかない**ため、T15 には Claude ロゴを入れず設定ファイルを主役にしている。パープルの枠にコーラルのロゴを載せると配色が濁る問題も避けられる。

## LMS への反映

同期（`POST /deploy/sections/upsert`）は**アイキャッチを空で登録し、既存レコードのアイキャッチは上書きしない**。よって生成した画像は**管理画面から手動でアップロードする**。公開オペレーション（アイキャッチ設定 → 表示順 → 章の一括公開 → 教材の公開）の最初のステップに当たる。
