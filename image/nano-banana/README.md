# ナノバナナ概念図 — バージョン管理

教材の概念図解（ナノバナナ画像）を管理するディレクトリです。

---

## ディレクトリ構成

```
image/nano-banana/
├── README.md              ← このファイル
├── v1/                    ← 初回量産（55件）
│   ├── gem-settings.md    ← Gem設定（v4.1）
│   └── prompts/           ← プロンプトファイル
│       ├── 9-1-3_mvc.md
│       └── ...
├── v2/                    ← （今後）一括修正・追加生成時に作成
└── ...
```

---

## バージョン管理ルール

| ルール | 説明 |
|:-------|:-----|
| `v1/` | 初回の概念図量産（55件） |
| `v2/`, `v3/`... | 一括修正やスタイル変更時に新ディレクトリを作成 |
| 各バージョンに `gem-settings.md` を含める | その時点のGem設定を記録し、再現性を確保 |
| 過去バージョンは削除しない | いつでも同じ設定で再生成できるようにする |

### 新バージョンの作り方

1. `vN/` ディレクトリを新規作成
2. その時点の `gem-settings.md` を配置（変更がなくても前バージョンからコピー）
3. `prompts/` に対象プロンプトを配置
4. 変更理由をコミットメッセージに記載

## ファイル命名規則

| 種類 | 命名パターン | 例 |
|:-----|:-------------|:---|
| 概念図 | `{N}-{M}-{S}_c{連番}.png` | `9-1-3_c1.png` |
| スクリーンショット | `{N}-{M}-{S}_{連番}.png` | `9-1-3_1.png`（既存のまま） |
| プロンプトファイル | `{N}-{M}-{S}_{概念名}.md` | `9-1-3_mvc.md` |

- `_c` は concept の略。スクリーンショットと区別するために使用
- 1つのSectionで複数の概念図がある場合: `_c1.png`, `_c2.png` と連番
