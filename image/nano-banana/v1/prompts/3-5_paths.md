# 3-5: パスの概念（A2: 比較図）

**Gem**: v4.1 | **テンプレート**: A2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の比較図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: 絶対パス vs 相対パス — ファイルの「住所」の2つの書き方

【構成】
左右2列の比較構成。上部に共通のディレクトリ構造を配置し、下部で絶対パスと相対パスの違いを対比する。

■ 上部（共通）: ディレクトリ構造
- ルート（/）から以下の階層を描く:
  - / (ルート)
    └── Users
        └── YourName
            ├── Desktop
            │   └── hello-world
            │       └── index.html ★ 目的地
            └── Documents
                └── report.pdf
- カレントディレクトリ（現在地）を「Desktop」に設定し、オレンジ色の枠で強調
- 目的地の「index.html」を青色で強調

■ 左列: 絶対パス（Absolute Path）
- タイトル: 「絶対パス」（青系の背景）
- 比喩: 「完全な住所」「東京都渋谷区○○...」
- アイコン: 地図のピンまたは住所カード
- パスの例: `/Users/YourName/Desktop/hello-world/index.html`
- パスをルートから矢印で辿る様子を図示
- 特徴（箇条書き）:
  - 「必ず / から始まる」
  - 「どこからでも同じ場所を指す」
  - 「長くなりがち」
- メリット: 「迷わない、確実」
- デメリット: 「毎回長い住所を書く必要がある」

■ 右列: 相対パス（Relative Path）
- タイトル: 「相対パス」（オレンジ系の背景）
- 比喩: 「道順の説明」「この道を渡って2軒隣」
- アイコン: 足跡または矢印の連なり
- パスの例: `hello-world/index.html`
- カレントディレクトリ（Desktop）から矢印で辿る様子を図示
- 特徴（箇条書き）:
  - 「/ から始まらない」
  - 「現在地によって変わる」
  - 「短く書ける」
- メリット: 「近くのファイルを手軽に指定」
- デメリット: 「現在地を把握していないと迷う」

■ 追加要素: 相対パスの特殊記号
- 右下に小さなボックスで説明:
  - `.` = カレントディレクトリ（今いる場所）
  - `..` = 親ディレクトリ（一つ上の階層）
- 例: `../Documents/report.pdf`（Desktopから一つ上に戻り、Documentsへ）

■ 下部: 使い分けのまとめ
- 絶対パス: 「設定ファイル、遠くのファイル」
- 相対パス: 「同じプロジェクト内、近くのファイル」
- `~`（チルダ）: 「ホームディレクトリへのショートカット」

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- 絶対パスは青系、相対パスはオレンジ系で色分け
- カレントディレクトリはオレンジ色の枠で強調
- 目的地のファイルは青色でハイライト
- テキストは日本語、読みやすいゴシック体風
- 左右の対比が一目で分かるレイアウト
- 装飾は最小限
- アスペクト比 16:9
```
