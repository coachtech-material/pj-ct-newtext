# 5-1-1: クライアントサーバーモデル（A1: 比喩フロー）

**Gem**: v4.1 | **テンプレート**: A1 | **ステータス**: テスト中

## プロンプト本文

```
Webページが表示される仕組み（クライアント・サーバーモデル）を、「レストランでの注文」の比喩で図解してください。

## 内容
教材ではクライアント・サーバーモデルをレストランに例えている:
- Client（ブラウザ）= お客さん（注文する人）
- Internet = ホールスタッフ（注文を届ける人）
- Server = シェフ（料理を作る人。HTML/CSS/JSなどのデータを持っている）

## 描いてほしいもの
レストランを描き、3人のキャラクターを左から右に配置:

流れ（番号付き）:
① お客さんが注文する（リクエスト）
② ホールスタッフがシェフに注文を伝える
③ シェフが料理を作り、ホールスタッフ経由でお客さんに届ける（レスポンス = HTML）

各キャラクターの近くに技術用語を併記。

タイトル: 「Webページが表示される仕組み」

## 概念の強調
- 「Client」「Server」の2つの技術用語を最も大きく太い文字で描く
- 「リクエスト」「レスポンス」の矢印ラベルも大きく目立たせる
- 比喩名（お客さん、シェフ等）はその下に小さく添える
- この図で伝えたいのは「Client → リクエスト → Server → レスポンス → Client」というシンプルな往復構造
```
