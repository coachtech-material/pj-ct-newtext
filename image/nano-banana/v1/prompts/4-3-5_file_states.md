# 4-3-5: Gitファイルの4つの状態（B1: 技術フロー）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: テスト中

## プロンプト本文

```
Gitで管理されるファイルの4つの状態と、状態間の遷移を示す図解を描いてください。

## 内容
Gitのファイルには4つの状態がある:
- Untracked（未追跡）— Gitがまだ管理していないファイル
- Staged（ステージ済み）— 次のコミットに含める準備ができたファイル
- Unmodified（変更なし）— コミット済みで変更されていないファイル
- Modified（変更あり）— コミット後に編集されたファイル

## 描いてほしいもの
4つの状態をボックスで描き、状態間の遷移を矢印で示す循環図:

遷移:
① Untracked → Staged（git add）
② Staged → Unmodified（git commit）
③ Unmodified → Modified（ファイルを編集）
④ Modified → Staged（git add）

各矢印の上にGitコマンドや操作名を書く。

タイトル: 「Gitファイルの4つの状態」

## 概念の強調
- 「Untracked」「Staged」「Unmodified」「Modified」の4つの状態名を最も大きく太い文字で描く
- 「git add」「git commit」のコマンド名も矢印上に目立つように描く
- 4つの状態が循環する構造が一目で分かるレイアウトにする
- 日本語の説明（未追跡、ステージ済み等）は状態名の下に小さく添える
```
