# 3-3: ファイルシステムのツリー構造（B2 構成図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の構成図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: ファイルシステムのツリー構造 — コンピュータ内のファイル・フォルダの階層

【構成】
上から下へ広がるツリー構造（木の根を上にした逆さの木）。

- 最上位（根）: ルートディレクトリ
  - ラベル: 「/ (ルートディレクトリ)」
  - 補足: 「全ての出発点」
  - アイコン: フォルダアイコン（特別な色で強調）

- 第2階層（ルート直下）:
  - 「Users」フォルダ
  - 「Applications」フォルダ
  - 「System」フォルダ（薄くグレーアウトして省略感を出す）

- 第3階層（Users配下）:
  - 「YourName」フォルダ
  - ラベル: 「~ (ホームディレクトリ)」
  - 補足: 「自分の部屋」
  - 特別な色（青系）で強調

- 第4階層（YourName配下）:
  - 「Desktop」フォルダ
  - 「Documents」フォルダ
  - 「Downloads」フォルダ（薄く表示）

- 第5階層（Desktop配下）:
  - 「hello-world」フォルダ
  - ラベル: 「. (カレントディレクトリ)」
  - 補足: 「今いる場所」
  - ハイライト表示（オレンジ系の枠線）

- パスの表示:
  - ツリーの横に、対応するパスを表示: `/Users/YourName/Desktop/hello-world`
  - スラッシュが階層の区切りを意味することを矢印で示す

- 追加ラベル:
  - 「Desktop」から「YourName」への上向き矢印に「.. (親ディレクトリ)」のラベル

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- フォルダアイコンは黄色系（一般的なフォルダの色）
- ルートディレクトリは赤系、ホームディレクトリは青系、カレントディレクトリはオレンジ系で色分け
- 接続線は薄いグレー
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```

## 構図イメージ（ASCIIアート）

```
         / (ルートディレクトリ)  ← 全ての出発点
         |
    +----+----+--------+
    |         |        |
  Users   Applications System
    |
  YourName  ← ~ (ホームディレクトリ)「自分の部屋」
    |
  +---------+---------+
  |         |         |
Desktop  Documents  Downloads
  |  ↑
  |  .. (親ディレクトリ)
  |
hello-world  ← . (カレントディレクトリ)「今いる場所」

パス: /Users/YourName/Desktop/hello-world
      ↑    ↑        ↑       ↑
      区切り 区切り    区切り   区切り
```
