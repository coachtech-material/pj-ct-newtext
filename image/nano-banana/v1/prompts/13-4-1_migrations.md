# 13-4-1: マイグレーション作成順序（B1: 依存関係フロー）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: テスト用

## プロンプト本文

```
マイグレーションにおけるテーブル作成順序と外部キー依存関係を、「積み木の土台作り」の比喩でコミックエッセイ風に図解してください。

## コンセプト
「テーブルを作る順番なんて気にしたことなかった」という初学者が、「外部キーがあるから順番が大事なんだ！」と理解できる図解を目指します。

## 世界観: 積み木を積む工事現場
テーブルを「積み木」として、土台から順番に積み上げていくイメージ。参照されるテーブルが土台、参照するテーブルが上に乗る。

## 登場キャラクター

1. 【開発者くん】
   - 外見: ヘルメットをかぶった工事現場の作業員風
   - 全体を通して登場し、各ステップでセリフを言う
   - 最後に「完成！」と喜ぶ

2. 【先輩エンジニア】
   - 吹き出しでアドバイスをくれる
   - 「参照されるテーブルは土台だから先に作るんだ！」

## ストーリー展開（3段階の積み木）

### 【STEP 1】土台① users テーブル（青系の積み木）

開発者くんのセリフ: 「まずは土台から！usersテーブルを作るぞ！」😤

積み木カード（青色、最下段）:
```
┌─────────────────┐
│  users 👤       │
│  ─────────────  │
│  id (PK) 🔑    │
│  name          │
│  email         │
│  password      │
│  timestamps    │
└─────────────────┘
```

吹き出し注釈: 「tasksから参照される（user_id）」
矢印: 上から点線の矢印が降りてくる予告

漫符: ヨイショ！の効果線

### 【STEP 2】土台② categories テーブル（緑系の積み木）

開発者くんのセリフ: 「次はcategoriesテーブル！これも土台だ！」💪

積み木カード（緑色、usersの横に並ぶ）:
```
┌─────────────────┐
│  categories 🏷️ │
│  ─────────────  │
│  id (PK) 🔑    │
│  name          │
│  timestamps    │
└─────────────────┘
```

吹き出し注釈: 「tasksから参照される（category_id）」

先輩エンジニアの吹き出し:
「参照されるテーブルは土台だから、先に作らないとダメなんだ！」

### 【STEP 3】上に乗せる tasks テーブル（オレンジ系の積み木）

開発者くんのセリフ: 「土台が揃った！これでtasksを乗せられる！」😆✨

積み木カード（オレンジ色、users と categories の上に乗る）:
```
┌──────────────────────┐
│  tasks 📝             │
│  ───────────────────  │
│  id (PK) 🔑          │
│  user_id (FK) ─────▶ users.id      │
│  category_id (FK) ─▶ categories.id │
│  title               │
│  description         │
│  priority            │
│  timestamps          │
└──────────────────────┘
```

外部キーの矢印:
- user_id から users テーブルへ点線矢印（青）
- category_id から categories テーブルへ点線矢印（緑）

コードブロック（オシャレな枠で）:
```php
foreignId('user_id')
  ->constrained()
  ->cascadeOnDelete();
```

### 【完成図】

開発者くんのセリフ: 「やった！きれいに積み上がった！」🎉

先輩エンジニアの吹き出し:
「この順番を間違えると『参照先がないよ』エラーになるから注意！」⚠️

## レイアウト: ピラミッド型

```
          ┌──────────┐
          │  tasks   │  ← 最後に作成（上に乗る）
          └────┬─────┘
         ╱     │     ╲
   ┌─────┴─┐       ┌┴──────┐
   │ users │       │categories│  ← 先に作成（土台）
   └───────┘       └─────────┘
```

## タイトル
リーフバナーで装飾: 「マイグレーション作成順序 〜土台から積み上げる〜」

## 絶対に守ること
- 3つのテーブルを「土台 → 上に乗せる」の関係で描く
- 外部キー（FK）から主キー（PK）への参照矢印を明示
- 「参照されるテーブル = 先に作成」のルールを強調
- キャラクターの感情表現と吹き出し
- 各ステップに番号（① ② ③）を大きく表示
- 最後に「完成！」の達成感を演出
```
