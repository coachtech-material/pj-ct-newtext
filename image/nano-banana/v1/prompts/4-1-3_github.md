# 4-1-3: GitとGitHubの関係（B2 関係図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の関係図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: GitとGitHubの関係 — 「道具」と「作業場所」の違い

【構成】
左右に分けて、GitとGitHubの関係性を示す。上段に比喩、下段に実際の概念を配置。

■ 左側: Git
- アイコン: Gitのロゴ風（またはツール/レンチのアイコン）
- ラベル: 「Git」
- 分類: 「ソフトウェア（道具）」
- 役割: 「バージョン管理を行う」
- 比喩アイコン: Wordのアイコン風
- 比喩ラベル: 「Word（文書作成ソフト）」
- 補足: 「自分のPCにインストールして使う」「ローカルで動作する」

■ 右側: GitHub
- アイコン: GitHubのOctocatロゴ風（またはクラウド+共有のアイコン）
- ラベル: 「GitHub」
- 分類: 「Webサービス（場所）」
- 役割: 「Gitリポジトリをホスティングする」
- 比喩アイコン: Google Driveのアイコン風
- 比喩ラベル: 「Google Drive（共有ストレージ）」
- 補足: 「インターネット上のサービス」「チームで共有する場所」

■ 接続:
- Git → GitHub: 太い矢印「git push（アップロード）」
- GitHub → Git: 太い矢印「git pull（ダウンロード）」
- 中央に「連携」の双方向矢印

■ 下部の注釈:
- 「GitHubはGitなしでは成り立たないが、GitはGitHubなしでも単体で利用可能」

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- Git側はオレンジ/赤系（Gitブランドカラー寄り）
- GitHub側は紫/黒系（GitHubブランドカラー寄り）
- 比喩部分はパステルカラーで柔らかく
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```
