# 4-4-4: git pull = fetch + merge（B1 フローチャート）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: ドラフト

## プロンプト本文

```
教育用のフローチャートを描いてください。プログラミング初学者向けの教材に使用します。

テーマ: git pull の内部動作 — fetch + merge の2ステップ

【構成】
上から下（または左から右）への3段階フロー。「git pull」が実は2つの操作の組み合わせであることを視覚的に示す。

■ 全体の枠:
- 大きな枠で「git pull origin main」を囲む
- 枠の上部にラベル: 「git pull = git fetch + git merge」

■ ステップ1: git fetch
- アイコン: 下向き矢印 + ダウンロードのアイコン
- 上部: 「リモートリポジトリ（GitHub）」— クラウドアイコン
- 下部: 「ローカルのリモート追跡ブランチ（origin/main）」— 一時保管庫のアイコン
- 矢印: リモート → ローカルの追跡ブランチ
- ラベル: 「git fetch」「最新の履歴情報をダウンロード」
- 補足: 「この段階では、手元のファイルは変わらない」（吹き出し）

■ ステップ2: git merge
- アイコン: 合流の矢印アイコン
- 上部: 「ローカルのリモート追跡ブランチ（origin/main）」
- 下部: 「ローカルのmainブランチ（あなたの作業ファイル）」— フォルダアイコン
- 矢印: 追跡ブランチ → ローカルのmain
- ラベル: 「git merge」「ダウンロードした変更を手元に統合」
- 補足: 「ここで初めて、手元のファイルが更新される」（吹き出し）

■ 結果:
- 最下部に「ローカルが最新の状態に！」というラベル
- チェックマークのアイコン

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- リモートリポジトリは紫系、fetchの矢印は青系、mergeの矢印は緑系
- 「git pull」全体の枠は薄いグレーの破線
- ステップ番号（①②）を大きく表示
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```
