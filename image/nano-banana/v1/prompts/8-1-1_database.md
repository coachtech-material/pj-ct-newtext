# 8-1-1: データベースの概念（A1: 比喩イラスト）

**Gem**: v4.1 | **テンプレート**: A1 | **ステータス**: ドラフト

## プロンプト本文

```
データベースの概念を、「高機能なExcelシート」と「優秀な執事（DBMS）」の比喩で図解してください。

## 内容
教材ではデータベースをこう例えている:
- データベース = 巨大な、高機能なExcelシート（表形式のテーブルにデータを整理）
- DBMS = 優秀な執事（命令を受けて、巨大なデータ倉庫から一瞬でデータを探し出す）
- SQL = 命令書（執事への依頼内容を書く専門言語）
- Excelとの違い:
  - データ量: 数百万〜数億行でも高速
  - 検索: SQLで複雑な条件でも高速検索
  - データの一貫性: 制約で重複や矛盾を防ぐ
  - 同時アクセス: トランザクションで安全
  - セキュリティ: 細かいアクセス権限

## 描いてほしいもの

### 上段: Excel vs データベースの比較
左右の対比で描く:

【左: Excelくん】（小さく、汗をかいている）
- 普通のExcelシートのキャラクター（少し疲れた顔）
- 吹き出し: 「数万行で重くなっちゃう...同時編集も苦手...」
- 上に小さなテーブル（数行のデータ）

【右: データベースさん】（大きく、頼もしい）
- 巨大で堂々としたテーブルのキャラクター（自信満々の顔）
- 吹き出し: 「数億行でも余裕！同時アクセスも安全！」
- 上に大きなテーブル（たくさんの行が描かれている）

### 下段: DBMS（執事）とSQLの関係
- 中央に執事キャラクター（DBMS/MySQL）: タキシード姿、鍵を持つ
- 左側から開発者キャラクターが「SQL（命令書）」を渡す
  - 命令書に「SELECT * FROM customers WHERE ...」
  - 開発者の吹き出し: 「東京在住の30代女性をリストアップして！」
- 右側に巨大なデータ倉庫（たくさんの棚にテーブルが並んでいる）
- 執事が一瞬でデータを探し出して結果を返す
  - 執事の吹き出し: 「かしこまりました。こちらでございます！」
- ラベル: 「DBMS（執事）」「SQL（命令書）」「Database（データ倉庫）」

タイトル: 「データベースとは」

## 概念の強調
- 「Database（データベース）」「DBMS」「SQL」の3つの技術用語を大きく太い文字で描く
- 「Excelの超強力版」というイメージが一目でわかること
- DBMS（執事）が中核にいて、SQL（命令書）を受け取ってデータを操作する構図
- 比喩名（高機能Excelシート、執事、命令書）は技術用語の下に小さく添える
```
