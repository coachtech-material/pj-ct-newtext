# 7-1-1: サーバーサイドとクライアントサイドの役割（B2: 構成/比較図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
サーバーサイド言語（PHP）とクライアントサイド言語（JavaScript）の役割の違いを、「レストランのキッチンとホール」の比喩で図解してください。

## 内容
教材ではサーバーサイドとクライアントサイドをこう例えている:
- サーバーサイド（PHP）= レストランのキッチン（調理担当）
  - データベースとの連携、ユーザー認証、HTMLの動的生成、ビジネスロジックの実行
  - ユーザーの目に見えない「裏側」で本質的な処理を担当
- クライアントサイド（JavaScript）= レストランのホール（接客・配膳担当）
  - HTML/CSSの操作（アニメーション）、ユーザー入力の検証、非同期通信
  - ユーザーが直接触れる「表側」で演出を担当

## 描いてほしいもの
レストランを舞台に、キッチンとホールの2つのエリアを描く:

### 左半分: キッチン（サーバーサイド = PHP）
- 「キッチン」の看板、壁やカウンターで仕切られた裏側のエリア
- シェフキャラクター（PHP）がコック帽を被って料理中
  - 食材棚に「Database（データベース）」のラベル
  - 調理台に「ユーザー認証」「HTML生成」のラベル付き食材
  - 💬「裏側で、データの処理を担当するよ！」
- 看板: 「Server Side: PHP（キッチン = 裏側の処理）」

### 右半分: ホール（クライアントサイド = JavaScript）
- テーブルやお客さんが見えるホールのエリア
- ウェイターキャラクター（JavaScript）が接客中
  - お皿に盛り付けた料理（完成HTML）をお客さんに配膳
  - テーブルに「アニメーション」「入力チェック」のラベル付き装飾
  - 💬「表側で、見た目を華やかにするよ！」
- 看板: 「Client Side: JavaScript（ホール = 表側の演出）」

### 中央の仕切り
- キッチンとホールの間に「料理（HTML）を渡す」矢印
- 仕切りに「見えない壁」のラベル（ユーザーからはキッチンの中が見えない）

タイトル: 「サーバーサイドとクライアントサイド」

## 概念の強調
- 「Server Side: PHP」「Client Side: JavaScript」の2つの技術用語を最も大きく太い文字で描く
- 「裏側の処理」vs「表側の演出」という対比を明確にする
- キッチン（裏側）はお客さんから見えない、ということを視覚的に表現する
- PHPがHTMLを「生成」してブラウザに渡すという流れが伝わること
```
