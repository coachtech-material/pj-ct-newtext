# 5-3-1: レスポンシブデザイン（B2: 比較図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
レスポンシブデザインの概念を、PC画面とスマートフォン画面のレイアウト変化で図解してください。

## 内容
教材ではレスポンシブデザインをこう説明している:
- 1つのHTMLファイルで、画面サイズに応じてレイアウトや文字サイズを自動的に調整する手法
- CSSの「メディアクエリ（@media）」で実現する
- PCでは横並び、スマホでは縦並びに切り替わる

## 描いてほしいもの
左側にPC画面、右側にスマートフォン画面を並べて、同じWebページが画面サイズに応じて変化する様子を描く:

【左: PC画面】
- 大きなモニターの中に、header / main+sidebar横並び / footer のレイアウト
- キャラクター（PCくん）が「広いから横並びで表示するよ！」とセリフ

【中央: 変換の矢印】
- 太い双方向矢印に「@media (max-width: 768px)」のラベル
- 矢印の上に「画面サイズで自動切り替え！」と注釈
- キラキラや星の漫符で魔法っぽさを演出

【右: スマートフォン画面】
- 小さなスマホの中に、header / main / sidebar / footer が縦一列に並ぶレイアウト
- キャラクター（スマホちゃん）が「狭いから縦並びに変えるね！」とセリフ

各画面内のレイアウトブロック（header, main, sidebar, footer）にはラベルを付ける。

タイトル: 「レスポンシブデザイン」

## 概念の強調
- 「Responsive Design（レスポンシブデザイン）」をタイトルとして最も大きく太い文字で描く
- 「@media」のコードをコードブロック風に目立たせる
- PC画面とスマホ画面の「同じHTML、違うレイアウト」という対比を明確にする
- 「1つのHTMLで対応」というポイントを吹き出しやラベルで強調
```
