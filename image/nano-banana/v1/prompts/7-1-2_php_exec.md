# 7-1-2: PHPコードの実行フロー（B1: フローチャート）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: ドラフト

## プロンプト本文

```
PHPコードが実行されてブラウザに表示されるまでの一連のフロー（リクエスト→PHP実行→HTML生成→レスポンス）を図解してください。

## 内容
教材ではPHPの実行フローをこう説明している:
1. リクエスト: ブラウザが「index.phpのページをください」とWebサーバーにリクエスト送信
2. PHPの実行: Webサーバーが.phpファイルを認識し、PHP実行環境に処理を依頼。PHPが上から順に解釈・実行
3. HTMLの生成: PHPコードの実行結果（echoで出力した文字列など）がHTMLに変換される
4. レスポンス: 生成されたHTMLがブラウザに送信される
5. 表示: ブラウザがHTMLを解釈して画面に表示。元がPHPだったかHTMLだったか区別がつかない

## 描いてほしいもの
左から右への5ステップのフローを、キャラクターのやり取りとして描く:

①【ブラウザ】（左端）
- PCの画面のキャラクター（ブラウザくん）
- 吹き出し: 「index.phpのページをください！」
- 矢印ラベル: 「①リクエスト」（青色の矢印）

②【Webサーバー（Nginx）】（左寄り中央）
- 受付係キャラクター
- 吹き出し: 「.phpファイルだな。PHPに頼もう！」
- 矢印ラベル: 「②処理を依頼」

③【PHP実行環境】（中央）
- 工場の作業員キャラクター（歯車や工具を持つ）
- index.phpファイルを読んでいるイラスト
- 吹き出し: 「コードを上から順に実行！echoの結果をHTMLに変換！」
- 作業台に「<?php echo date(...); ?>」→「2024年1月15日」の変換イメージ
- 矢印ラベル: 「③HTML生成」

④【生成されたHTML】（右寄り中央）
- 完成した書類のイラスト（<?php...?>が消えて、純粋なHTMLになっている）
- 注釈: 「PHPコードは消えて、実行結果だけが残る」
- 矢印ラベル: 「④レスポンス」（赤色の矢印）

⑤【ブラウザに表示】（右端）
- ブラウザくんが完成ページを表示
- 画面に「こんにちは！現在の日時は 2024年1月15日 です。」
- 吹き出し: 「普通のHTMLに見える！PHPだったなんてわからない！」

タイトル: 「PHPの実行フロー」

## 概念の強調
- 「Request（リクエスト）」と「Response（レスポンス）」を大きく太い文字で描く
- 「PHP実行環境」が中央で最も大きく描かれ、PHPコード→HTML変換が核心であることを示す
- 番号付きフロー矢印（①〜⑤）を太く明確に描く
- 「ブラウザからはPHPコードが見えない」というポイントを強調
```
