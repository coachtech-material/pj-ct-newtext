## c1: Fast-forwardマージ（ポインタ移動のみ）

### プロンプト本文

```
GitのFast-forwardマージの仕組みを、コミットグラフで図解してください。

## 内容
教材では以下のように説明している:
- Fast-forwardマージとは、マージ先のブランチに新しいコミットがない場合に行われるマージ
- mainブランチのポインタがfeatureブランチの先頭に移動するだけ
- マージコミットは作成されない
- 例: main(A-B) + feature(C-D) → main(A-B-C-D)

## 描いてほしいもの
上段に「マージ前」、下段に「マージ後」の2つのコミットグラフを描く:

【上段 — マージ前】
- mainブランチ（青）: コミット A → B で止まっている
- featureブランチ（緑）: B から分岐して C → D まで進んでいる
- mainの指すポインタはBにある
- 「mainには新しいコミットがない！」という吹き出し

【下段 — マージ後（git merge feature）】
- mainブランチ（青）: A → B → C → D の一直線になる
- mainのポインタがDに移動している（矢印で「ポインタ移動！」と強調）
- マージコミットはない
- 「ポインタが進んだだけ！マージコミットは作られない」という吹き出し

各コミットは●で表現し、コミット名（A, B, C, D）を大きく描く。

タイトル: 「Fast-forwardマージ」

## 概念の強調
- 「Fast-forward」を最も大きく太い文字で描く
- 「ポインタ移動」がこのマージの本質。ポインタが B → D に移動する矢印を太く目立たせる
- マージコミットが作成されないことを「×マージコミット」として明示する
- この図で伝えたいのは「mainに新しいコミットがなければ、ポインタを進めるだけでマージが完了する」ということ
```

### 構図イメージ（ASCIIアート）

```
┌──────────────────────────────────────────────────────────────┐
│                「Fast-forwardマージ」                          │
│                                                               │
│  【マージ前】                                                  │
│                                                               │
│  main     ●A ─── ●B                                          │
│                    \                                          │
│  feature            ●C ─── ●D                                │
│                                                               │
│           main▲ここ   💬「mainには新しいコミットがない！」      │
│                                                               │
│  ─────── git merge feature ─────────────                      │
│                                                               │
│  【マージ後】                                                  │
│                                                               │
│  main     ●A ─── ●B ─── ●C ─── ●D                           │
│                                  ▲                            │
│                          main ここに移動！                     │
│                                                               │
│           💬「ポインタが進んだだけ！                            │
│              マージコミットは作られない」                       │
│           ×マージコミット                                      │
└──────────────────────────────────────────────────────────────┘
```

## c2: Non-fast-forwardマージ（マージコミット作成）

### プロンプト本文

```
GitのNon-fast-forwardマージの仕組みを、コミットグラフで図解してください。

## 内容
教材では以下のように説明している:
- Non-fast-forwardマージとは、マージ先のブランチに新しいコミットがある場合に行われるマージ
- マージコミットが作成される
- 例: main(A-B-E) + feature(C-D) → main(A-B-E-M) with feature(C-D) merged

## 描いてほしいもの
上段に「マージ前」、下段に「マージ後」の2つのコミットグラフを描く:

【上段 — マージ前】
- mainブランチ（青）: A → B → E まで進んでいる
- featureブランチ（緑）: B から分岐して C → D まで進んでいる
- mainにもfeatureにもそれぞれ新しいコミットがある
- 「両方にコミットがある！」という吹き出し

【下段 — マージ後（git merge feature）】
- mainブランチ: A → B → E → M（マージコミット）
- featureブランチ: B → C → D → M に合流
- M（マージコミット）を特別に大きく、星印やキラキラで強調
- 「マージコミットMが作られた！2つの流れが合流！」という吹き出し

各コミットは●で表現し、マージコミットMは★や大きな●で表現する。

タイトル: 「Non-fast-forwardマージ」

## 概念の強調
- 「Non-fast-forward」「マージコミット」を最も大きく太い文字で描く
- マージコミットM が2つの親（EとD）を持つことを、2本の矢印が合流する形で描く
- Fast-forwardとの違い（mainにも新しいコミットがある）を明確にする
- この図で伝えたいのは「mainにもコミットがある場合、2つの流れを統合するマージコミットが作成される」ということ
```

```

│              「Non-fast-forwardマージ」                        │
│                                                               │
│  【マージ前】                                                  │

│  main     ●A ─── ●B ─── ●E                                   │
│                    \                                          │
│  feature            ●C ─── ●D                                │
│                                                               │
│           💬「両方にコミットがある！」                          │
│                                                               │
│  ─────── git merge feature ─────────────                      │
│                                                               │
│  【マージ後】                                                  │
│                                                               │
│  main     ●A ─── ●B ─── ●E ─── ★M（マージコミット）         │
│                    \            /                              │
│  feature            ●C ─── ●D                                │
│                                                               │
│           💬「マージコミットMが作られた！                       │
│              2つの流れが合流！」                                │
└──────────────────────────────────────────────────────────────┘
```
