## 画像1: Git 3エリア + 引っ越し比喩

### プロンプト本文

```
教育用のイラスト付きフロー図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: Gitの3つのエリア — 「引っ越しの荷造り」比喩と実際のGit概念の対応

【構成】
上下2段構成にする。上段に比喩（引っ越し）、下段に実際のGit概念を配置し、対応関係を点線で結ぶ。

■ 上段（比喩の世界）: 「引っ越しの荷造り」
- 左: 「作業部屋」— 散らかった部屋のイラスト。荷物が床に散らばっている
- 中央: 「段ボール箱」— 開いた段ボール箱のイラスト。選んだ荷物を入れている
- 右: 「倉庫」— 整理された棚がある倉庫のイラスト。段ボール箱が整然と並ぶ
- 矢印: 作業部屋 → 段ボール箱（「荷物を選んで箱に入れる」）→ 倉庫（「箱を倉庫に送る」）

■ 下段（Git の世界）:
- 左: 「ワーキングツリー」— フォルダアイコンとファイル群
  - 補足: 「プロジェクトフォルダ（my-project/）」「ファイルを自由に編集する場所」
- 中央: 「ステージ（インデックス）」— チェックリストまたは選別のアイコン
  - 補足: 「.git/index」「コミットする変更を選ぶ場所」
- 右: 「リポジトリ」— 金庫または保管庫のアイコン
  - 補足: 「.git/ フォルダ」「変更履歴を永久に保管する場所」
- 矢印: ワーキングツリー →「git add」→ ステージ →「git commit」→ リポジトリ

■ 対応関係（上下を点線で接続）:
- 作業部屋 ⟷ ワーキングツリー
- 段ボール箱 ⟷ ステージ
- 倉庫 ⟷ リポジトリ

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- 上段（比喩）はパステルカラーで柔らかい印象
- 下段（Git）はやや濃い色で技術的な印象
- ワーキングツリーはオレンジ系、ステージは黄色系、リポジトリは緑系で色分け
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```

## 画像2: ローカル→リモートの全体フロー

### プロンプト本文

```
教育用のフロー図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: Gitのローカル環境からリモート環境への全体フロー

【構成】
左から右へ、4つのエリアを横一列に配置する。左3つを「ローカル環境」、右1つを「リモート環境」として区切り線で分ける。

■ ローカル環境（あなたのパソコン）— 背景を薄い青で囲む:
1. 「ワーキングツリー」— フォルダアイコン
   - 「ファイルを編集」
2. 「ステージ」— チェックリストアイコン
   - 「変更を選択」
3. 「ローカルリポジトリ」— 保管庫アイコン
   - 「コミットして記録」

■ リモート環境（GitHub等）— 背景を薄い緑で囲む:
4. 「リモートリポジトリ」— クラウドアイコン + GitHubロゴ風
   - 「チームで共有」

■ 矢印:
- ワーキングツリー →「git add」→ ステージ
- ステージ →「git commit」→ ローカルリポジトリ
- ローカルリポジトリ →「git push」→ リモートリポジトリ（この矢印を太く・目立たせる）

■ 区切り:
- ローカル3エリアとリモート1エリアの間に、破線の区切り線
- 区切り線の上に「インターネット」のラベル

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- ローカル環境の背景は薄い青、リモート環境の背景は薄い緑
- 各エリアのアイコンは前の画像（4-1-2_c1）と同じ色分け（オレンジ・黄色・緑）、リモートは紫系
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```
