# 8-1-5: 正規化プロセスとER図（B1: 技術フロー）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: ドラフト

## プロンプト本文

```
データベース設計の基礎である「正規化プロセス（1NF→2NF→3NF）」を、段階的なお掃除の比喩でフローチャート形式に図解してください。

## 内容
教材では正規化を「散らかった部屋をルールに従って整理整頓する作業」に例えている:
- 正規化 = テーブルのお掃除手順
- 第1正規形（1NF）= 「一つのマスには一つの値」ルール
- 第2正規形（2NF）= 「主キーの一部だけに依存するカラムを別テーブルに切り出す」
- 第3正規形（3NF）= 「主キー以外のカラムに依存するカラムを別テーブルに切り出す」

## 描いてほしいもの
左から右（または上から下）に、正規化の3段階を「ビフォー→アフター」のフローとして描く:

ステップ①【非正規形→第1正規形】
- ビフォー: 1つのセルに「りんご, みかん」とカンマ区切りで入っている散らかったテーブル
- キャラクターが「1つのマスに1つだけ！」と整理する
- アフター: レコードが分割されてきれいになったテーブル

ステップ②【第1正規形→第2正規形】
- ビフォー: 複合主キー（注文ID, 商品ID）のテーブルに、注文日や商品名が混在
- キャラクターが「主キーの一部にしか依存してないカラムは別テーブルへ！」と仕分ける
- アフター: 注文テーブル、商品テーブル、注文明細テーブルに分割

ステップ③【第2正規形→第3正規形】
- ビフォー: 社員テーブルに所属部署IDと所属部署名が同居
- キャラクターが「主キー以外への依存も分離！」と最後のお掃除
- アフター: 社員テーブルと部署テーブルに分割

各ステップに番号付き矢印（①→②→③）を付けて、段階的に整理されていく流れを示す。

タイトル: 「正規化プロセス〜テーブルのお掃除3ステップ〜」

## 概念の強調
- 「1NF（第1正規形）」「2NF（第2正規形）」「3NF（第3正規形）」の技術用語を最も大きく太い文字で描く
- 各段階のルールを吹き出しで端的に表現する
- ビフォー（散らかった状態）とアフター（整理された状態）の対比を色分けで明確にする（ビフォーは赤系、アフターは緑系）
- 最終的に「きれいに整理されたテーブル群」が達成感を感じさせるよう描く
- お掃除キャラクターが各段階で活躍する様子を描き、楽しい雰囲気にする
```

```
│       「正規化プロセス〜テーブルのお掃除3ステップ〜」              │
│                                                                 │

│  ┌─ ビフォー ──────┐    🧹     ┌─ アフター ──────┐              │
│  │ りんご,みかん    │  ──▶    │ りんご          │              │
│  │ （1セル複数値）   │ 「1マスに │ みかん          │              │
│  └────────────────┘  1つ！」  └────────────────┘              │
│          │                                                      │
│          ▼                                                      │
│  ② 2NF（第2正規形）                                             │
│  ┌─ ビフォー ──────┐    🧹     ┌─ アフター ──────────────┐     │
│  │ 注文+商品+日付   │  ──▶    │ 注文T ／ 商品T ／ 明細T │     │
│  │ が全部混在       │ 「部分   │ （役割ごとに分割）      │     │
│  └────────────────┘ 依存を    └──────────────────────┘     │
│          │            分離！」                                   │
│          ▼                                                      │
│  ③ 3NF（第3正規形）                                             │
│  ┌─ ビフォー ──────┐    🧹     ┌─ アフター ──────────┐        │
│  │ 社員+部署ID      │  ──▶    │ 社員T ／ 部署T      │        │
│  │ +部署名が同居    │ 「推移   │ （すっきり分離！）   │        │
│  └────────────────┘ 依存も    └───────────────────┘        │
│                      分離！」                                    │
│                                              ✨ 完成！           │
└────────────────────────────────────────────────────────────────┘
```
