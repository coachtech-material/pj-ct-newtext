# 9-1-3: MVCアーキテクチャ（A1: 比喩フロー）

**Gem**: v4.1 | **テンプレート**: A1 | **ステータス**: テスト中

## プロンプト本文

```
LaravelのMVCアーキテクチャを、「高級レストラン」の比喩で図解してください。

## 内容
教材ではMVCをレストランに例えている:
- ブラウザ = お客さん
- Routing = ホールスタッフ（注文を聞いて厨房に伝える）
- Controller = 厨房リーダー（指示を出す司令塔。自分では料理しない）
- Model = シェフ（データベースから食材を取って調理する）
- Database = 冷蔵庫（食材の保管場所）
- View = 盛り付け担当（きれいにお皿に盛る＝HTML生成）

## 描いてほしいもの
レストランの厨房を描き、各登場人物をキャラクターとして配置:

流れ（番号付き）:
① お客さんが注文する（リクエスト）
② ホールスタッフが厨房リーダーに伝える（ルーティング）
③ 厨房リーダーがシェフに「この食材を取ってきて」と指示（コントローラー）
④ シェフが冷蔵庫から食材を取り出す（モデル↔DB）
⑤ シェフが厨房リーダーに調理済みデータを返す
⑥ 厨房リーダーが盛り付け担当に「このデータで盛り付けて」と指示
⑦ 盛り付け担当が美しく盛り付ける（HTML生成）
⑧ ホールスタッフがお客さんに料理を運ぶ（レスポンス）

各キャラクターのラベルは、技術用語を大きく1行目に、比喩を小さく2行目に書く:
- 1行目（大きく太く）: 「Routing」
- 2行目（小さく）: ホールスタッフ
このように、技術用語が主役、比喩名が補足になるようにする。

全体をレストランの空間として描き、処理の流れを番号付き矢印で示す。

タイトル: 「Laravel MVCアーキテクチャ〜レストランで理解する〜」

## 概念の強調（最も重要）
この図で伝えたいのは「M・V・C + R」の4つの役割構造です。

ラベルの書き方:
- 各キャラクターの近くに、技術用語を最も大きく太い文字で1行目に書く
- 比喩名（ホールスタッフ等）は2行目に小さく添える
- 例: 大きく「Controller」、その下に小さく「厨房リーダー」

4つの核心ラベルの強調:
- 「Routing」「Controller」「Model」「View」の4つを図の中で最も目立つ要素にしてください
- この4つのラベルは他のテキストより明らかに大きく、太く、色付きで描いてください
- 特にControllerは図の中央に最も大きく配置し、司令塔であることを示してください
- 人物のイラストはあくまで概念を伝えるための補助です
- 矢印と番号のフロー（データの流れ）が図の骨格になるように描いてください

## 前回からの修正点（必ず守ること）
- 「Model（シェフ）」のラベルを必ず表示すること。前回はModelラベルが欠落していた
- 冷蔵庫（Database）は画面内に1つだけ描くこと。2つ描かない
- 番号（①〜⑧）は全て大きく、はっきり見える場所に描くこと。特に③④が見つけにくかったので改善する
```
