# 9-1-3: MVCアーキテクチャ

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: テスト中

## プロンプト本文

```
MVCアーキテクチャ（Model-View-Controller）の役割分担を図解してください。

## 内容
教材ではMVC+Routingをレストランに例えている:
- Routing = 案内係（ホールスタッフ）。URLを見てControllerに振り分け
- Controller = 厨房リーダー。指示を出す司令塔（中心的存在）
- Model = シェフ＆食材庫。データの管理担当
- View = 盛り付け担当。見た目を作る

## 描いてほしいもの
4つの役割を色分けボックスで描き、左から右へフローを示す:

【左端】ブラウザ（ユーザー）
- 🌐 パソコンのアイコン

【Routing】オレンジ色ボックス
- 🪧道路標識のイラスト
- 「案内係」
- 例: web.php

【Controller】青色ボックス（中央・大きめ）
- 👨‍🍳シェフ帽の厨房リーダー
- 「指示を出す司令塔」
- 例: UserController

【Model】緑色ボックス（右上）
- 🗄️冷蔵庫のイラスト
- 「データの管理」
- 例: User::all()
- 隣にDatabase（💾）

【View】ピンク色ボックス（右下）
- 🍽️お皿に盛り付けのイラスト
- 「見た目を作る」
- 例: index.blade.php

フロー（番号付き矢印）:
① User → Routing
② Routing → Controller
③ Controller → Model
④ Model → Controller
⑤ Controller → View
⑥ View → Routing
⑦ Routing → User（レスポンス）

「Controllerは司令塔！Routingで振り分け、ModelとViewに指示を出す」と注釈。

タイトル: 「MVCアーキテクチャ」
サブタイトル: 〜レストランの役割分担で理解しよう〜

## 概念の強調
- 「Routing」「Controller」「Model」「View」の技術用語を大きく太い文字で描く
- Controllerは中央に最も大きく配置（これが図の核心）
- フロー矢印は太く色付きで番号付き（①〜⑦）
- 比喩（案内係、厨房リーダー、冷蔵庫、盛り付け）はイラストの補助として添える
```
