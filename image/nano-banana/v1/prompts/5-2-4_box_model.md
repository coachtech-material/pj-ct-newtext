# 5-2-4: CSSボックスモデル（B2 構成図/入れ子構造）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の構成図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: CSSボックスモデル — Content, Padding, Border, Marginの4層構造

【構成】
中心から外側へ広がる、4つの入れ子の四角形（同心の矩形）で表現する。ブラウザのDevToolsに表示されるボックスモデル図を参考にしつつ、より教育的に仕上げる。

■ 最内層（中心）: Content
- ラベル: 「Content（コンテンツ）」
- 補足: 「テキストや画像など、要素の中身」
- 比喩: 「箱の中身」
- 色: 薄い青系の背景
- 中央にテキストアイコンまたは「Hello!」のサンプルテキスト

■ 第2層: Padding
- ラベル: 「Padding（パディング）」
- 補足: 「コンテンツと枠線の間の内側の余白」
- 比喩: 「箱の中の緩衝材」
- 色: 薄い緑系の背景
- Contentの周りを均等に囲む

■ 第3層: Border
- ラベル: 「Border（ボーダー）」
- 補足: 「パディングの外側にある枠線」
- 比喩: 「箱の外枠」
- 色: 濃いめの線（黒〜ダークグレー）で、はっきりした枠線として描画
- 実際の枠線らしく、線の太さを持たせる

■ 最外層: Margin
- ラベル: 「Margin（マージン）」
- 補足: 「他の要素との間の外側の余白」
- 比喩: 「箱と箱の間隔」
- 色: 薄いオレンジ系の背景
- Borderの外側を均等に囲む

■ 各層のサイズ表示（右側または下部）:
- 各層の幅を数値で表示する例:
  - Content: 「width: 300px / height: 200px」
  - Padding: 「padding: 20px」
  - Border: 「border: 2px」
  - Margin: 「margin: 30px」

■ 右側に補足テーブル:
| 領域 | 役割 | 比喩 |
| Content | 要素の中身 | 箱の中身 |
| Padding | 内側の余白 | 緩衝材 |
| Border | 枠線 | 箱の外枠 |
| Margin | 外側の余白 | 箱と箱の間隔 |

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- 4つの層がそれぞれ異なる色で明確に区別される
  - Margin: オレンジ系
  - Border: ダークグレー/黒
  - Padding: 緑系
  - Content: 青系
- この配色はChrome DevToolsのボックスモデル表示を意識
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```
