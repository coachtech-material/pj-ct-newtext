## c1: 1対多リレーションシップの概念図

### プロンプト本文

```
Laravelにおける1対多リレーションシップ（hasMany / belongsTo）の概念を、ユーザーと投稿の具体例で図解してください。

## 内容
教材ではTutorial 8で学んだ1対多リレーションをLaravelで実装する方法を説明している:
- 1人のユーザーが複数の投稿を持つ
- 1つの投稿は1人のユーザーに属する
- 外部キー（user_id）で関係を管理する
- hasMany()とbelongsTo()で双方向のリレーションを定義

具体例:
- users: 山田太郎（id=1）、佐藤花子（id=2）
- posts: 記事1（id=1, user_id=1）、記事2（id=2, user_id=1）、記事3（id=3, user_id=2）
- 山田太郎は記事1と記事2を持つ（1対多）
- 佐藤花子は記事3を持つ

## 描いてほしいもの
2つのテーブルと、Laravelのモデル定義を組み合わせた関係図:

【上段: テーブルとデータの関係】
usersテーブル（左）:
| id | name |
| 1 | 山田太郎 |
| 2 | 佐藤花子 |

postsテーブル（右）:
| id | title | user_id |
| 1 | 記事1 | 1 |
| 2 | 記事2 | 1 |
| 3 | 記事3 | 2 |

色付きの線でデータの関連を結ぶ:
- 山田太郎 → 記事1（赤線）
- 山田太郎 → 記事2（赤線）
- 佐藤花子 → 記事3（青線）

「1」側から「多」側へ向かう矢印で、1対多の関係を視覚化する。

【下段: Laravelのモデル定義】
Userモデル: hasMany(Post::class) → 「1人が複数の投稿を持つ」
Postモデル: belongsTo(User::class) → 「1つの投稿は1人に属する」
双方向の矢印で関係を示す。

キャラクター（山田太郎）が「僕は記事1と記事2の2つの投稿を持ってるよ！」
キャラクター（記事1）が「僕は山田さんに属してる！」

タイトル: 「hasMany / belongsTo〜1対多リレーションシップ〜」

## 概念の強調
- 「hasMany()」と「belongsTo()」の技術用語を大きく太い文字で描く
- 外部キー（user_id）が橋渡し役であることを視覚的に強調
- 「1」対「多」の関係が一目で分かるよう、矢印の太さや数で表現
- 色付き線でデータの関連を結び、どのユーザーがどの投稿を持つか直感的に分かるようにする
- 双方向のリレーション定義（User→posts, Post→user）を示す
- メソッド名の命名規則（複数形:posts、単数形:user）に小さく触れる
```
