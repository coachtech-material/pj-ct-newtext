# 1-2: エンジニアに必要な3つの力（A1: 比喩フロー）

**Gem**: v4.1 | **テンプレート**: A1 | **ステータス**: ドラフト

## プロンプト本文

```
エンジニアに必要な「3つの力」を、「家を建てる大工さん」の比喩で図解してください。

## 内容
教材では優れたエンジニアに必要な力を大工さんに例えている:
- 基本スキル = 金槌の使い方（コードを書く技術）
- 探究心 = 木材の特性を調べる力（なぜこの木材を使うのか？）
- 解決力 = 傾いた柱を直す力（問題をどう修正するか？）
- 協調性 = 他の職人と連携する力（電気屋・水道屋との協力）

## 描いてほしいもの
建設中の家を中心に、大工さんが3つの力を発揮している様子を描く:

構成（3つのエリアに分けて配置）:
- 中央: 建設中の家と大工さん（基本スキル = 金槌を持っている）
- 左側: 木材を調べている大工さん（探究心のエリア）
- 右側: 傾いた柱を修正している大工さん（解決力のエリア）
- 下部: 電気屋・水道屋と話し合っている大工さん（協調性のエリア）

各エリアのラベルは、技術用語を大きく1行目に、比喩を小さく2行目に書く:
- 1行目（大きく太く）: 「探究心」
- 2行目（小さく）: 木材の特性を調べる
このように、エンジニアスキルが主役、大工作業が補足になるようにする。

全体を建設現場の空間として描き、3つの力が「基本スキル」を土台として成り立っていることを示す。

タイトル: 「エンジニアに必要な3つの力〜大工さんで理解する〜」

## 概念の強調（最も重要）
この図で伝えたいのは「探究心・解決力・協調性」の3つの力の重要性です。

ラベルの書き方:
- 各エリアの近くに、エンジニアスキル名を最も大きく太い文字で1行目に書く
- 大工作業の説明は2行目に小さく添える
- 例: 大きく「探究心」、その下に小さく「なぜ？を突き詰める」

3つの核心ラベルの強調:
- 「探究心」「解決力」「協調性」の3つを図の中で最も目立つ要素にしてください
- この3つのラベルは他のテキストより明らかに大きく、太く、色付きで描いてください
- 「探究心」は青系、「解決力」は緑系、「協調性」は橙系など、色分けして区別しやすくする
- 中央に「基本スキル（コードを書く力）」を配置し、3つの力の土台であることを示す
- 大工さんのイラストはあくまで概念を伝えるための補助です

## スタイル
- フラットデザイン、クリーンで教育的な印象
- 背景は白または薄いグレー
- アスペクト比 16:9
- 日本語テキスト、読みやすいゴシック体風
```
