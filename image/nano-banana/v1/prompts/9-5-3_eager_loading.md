# 9-5-3: Lazy Loading vs Eager Loading（B1: 比較図）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: ドラフト

## プロンプト本文

```
LaravelのLazy LoadingとEager Loadingの違い（N+1問題）を比較する図解を作ってください。

## 内容
教材では、リレーションシップのデータ取得方法を2つ解説している:
- Lazy Loading（遅延読み込み）: 必要になったときにSQLを実行。投稿が100件あれば101回SQLが走る（N+1問題）
- Eager Loading（事前読み込み）: with()で最初にまとめて読み込む。SQLはたった2回で済む

## 描いてほしいもの
上下（または左右）に分けた比較レイアウト:

【上側（赤系・NG）— Lazy Loading】
- タイトル: 「Lazy Loading（遅延読み込み）」
- Post::all() でまず全投稿を取得するキャラクター
- foreachループ内で、1件ずつ「ユーザー情報ちょうだい！」とDBに問い合わせるキャラクター
- DBキャラクターが疲れ果てている（汗、疲労マーク）
- SQLが大量に飛んでいる様子（吹き出しに「SELECT * FROM users WHERE id=1」「SELECT * FROM users WHERE id=2」...）
- 大きく「101回のSQL！」と警告表示
- キャラクターのセリフ: 「1件ずつ聞いてたら大変だ...！」

【下側（青系・OK）— Eager Loading】
- タイトル: 「Eager Loading（事前読み込み）」
- Post::with('user')->get() でまとめて取得するキャラクター
- DBキャラクターが余裕の表情で「まとめて渡すよ！」
- SQLが2本だけ（「SELECT * FROM posts」「SELECT * FROM users WHERE id IN (1,2,3...)」）
- 大きく「たった2回のSQL！」と表示
- キャラクターのセリフ: 「最初にまとめて取ればOK！」

中央に「N+1問題」を大きく描き、上から下への矢印で「with()で解決！」と示す。

タイトル: 「N+1問題 〜Lazy Loading vs Eager Loading〜」

## 概念の強調
- 「N+1問題」を図の中央に最も大きく太い文字で描く
- 「Lazy Loading」「Eager Loading」の技術用語を大きく太い文字で各エリアの見出しにする
- SQLの実行回数（101回 vs 2回）の対比を数字で大きく強調する
- 「with()」メソッドが解決策であることを目立たせる
- 上側は赤・警告系の色調、下側は青・安心系の色調で明確に色分けする
```
