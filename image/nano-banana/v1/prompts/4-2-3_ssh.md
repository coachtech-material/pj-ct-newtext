# 4-2-3: SSH公開鍵・秘密鍵の仕組み（B2 関係図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の関係図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: SSH公開鍵・秘密鍵の仕組み — パスワードなしで安全に通信する方法

【構成】
左右に分けて、「あなたのPC」と「GitHub」を配置し、公開鍵と秘密鍵の関係を示す。

■ 左側: あなたのPC（ローカル環境）
- PCのアイコン
- ラベル: 「あなたのパソコン」
- 内部に2つの鍵を表示:
  1. 「秘密鍵（Private Key）」— 鍵のアイコン（金色）
     - 場所: `~/.ssh/id_ed25519`
     - 補足: 「家の鍵」「絶対に他人に見せない」
     - 赤い枠線で「秘密！」と強調
  2. 「公開鍵（Public Key）」— 鍵穴のアイコン（銀色）
     - 場所: `~/.ssh/id_ed25519.pub`
     - 補足: 「鍵穴」「GitHubに登録する」
     - 矢印で右側のGitHubへコピーされることを示す

■ 右側: GitHub（リモート環境）
- GitHubのアイコン（サーバーまたはクラウド）
- ラベル: 「GitHub」
- 内部に:
  - 登録された「公開鍵（Public Key）」のコピー — 鍵穴アイコン
  - 「Settings → SSH and GPG keys に登録」

■ 中央の通信フロー:
- あなたのPC → GitHub: 「接続を要求」
- 秘密鍵と公開鍵のペアがマッチ → 「認証成功！」の吹き出し
- ラベル: 「SSH接続（暗号化された安全な通信）」
- 鍵のペアが一致することを、鍵と鍵穴が噛み合うイメージで表現

■ 下部の注釈:
- 「秘密鍵（家の鍵）で証明 → 公開鍵（鍵穴）と一致 → パスワードなしで認証完了」

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- あなたのPC側は青系、GitHub側は紫/黒系
- 秘密鍵は金色で「秘密」感を演出、公開鍵は銀色
- SSH接続のラインは緑色（安全・暗号化を表現）
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限
- アスペクト比 16:9
```
