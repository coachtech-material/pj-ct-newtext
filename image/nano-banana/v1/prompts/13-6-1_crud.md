# 13-6-1: RESTful CRUD操作（B1: HTTPメソッド対応表）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: ドラフト

## プロンプト本文

```
LaravelのリソースコントローラにおけるHTTPメソッドとCRUD操作の対応を、視覚的にわかりやすく図解してください。

## 内容
教材ではリソースコントローラの7つのメソッドを以下のように説明している:
- index: GET /categories → 一覧表示（Read）
- create: GET /categories/create → 作成フォーム表示
- store: POST /categories → 新規作成処理（Create）
- show: GET /categories/{id} → 詳細表示（Read）
- edit: GET /categories/{id}/edit → 編集フォーム表示
- update: PUT/PATCH /categories/{id} → 更新処理（Update）
- destroy: DELETE /categories/{id} → 削除処理（Delete）

## 描いてほしいもの
HTTPメソッド（GET/POST/PUT/DELETE）とCRUD操作の対応関係を示す図:

左側: HTTPメソッドを色分けしたボックスで配置
- GET（青系）: データを取得する
- POST（緑系）: 新しいデータを作成する
- PUT/PATCH（黄/オレンジ系）: 既存データを更新する
- DELETE（赤系）: データを削除する

右側: CRUD操作を示すアイコン付きラベル
- Create（作成）: ＋マーク
- Read（読み取り）: 目のアイコン
- Update（更新）: 鉛筆アイコン
- Delete（削除）: ゴミ箱アイコン

中央: HTTPメソッドとCRUD操作を矢印で接続
- GET → Read（index, show, create, edit）
- POST → Create（store）
- PUT/PATCH → Update（update）
- DELETE → Delete（destroy）

下部に補足テキスト:
「Route::resource() で7つのルートを一括登録」

タイトル: 「HTTPメソッドとCRUD操作の対応」

## 概念の強調（最も重要）
この図で伝えたいのは「HTTPメソッドとCRUD操作の対応関係」です。

ラベルの書き方:
- HTTPメソッド（GET, POST, PUT/PATCH, DELETE）は最も大きく目立つように表示
- CRUD（Create, Read, Update, Delete）も同様に大きく表示
- 各メソッド名（index, store等）は補足として小さめに表示

4つのHTTPメソッドの強調:
- 「GET」「POST」「PUT/PATCH」「DELETE」の4つを図の中で最も目立つ要素にする
- 各HTTPメソッドは異なる色で明確に区別する
- 矢印でCRUD操作との対応を視覚的に示す

## レイアウト要件
- 横長の構図（16:9程度）
- 左から右へ流れるレイアウト
- 背景はシンプルに、HTTPメソッドとCRUD操作が主役
- 各要素は十分な余白を取って配置
```
