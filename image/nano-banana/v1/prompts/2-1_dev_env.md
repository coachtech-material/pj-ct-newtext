# 2-1: クライアント-サーバーモデル（B2 構成図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の構成図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: クライアントサーバモデル — Webアプリケーションが動く基本的な仕組み

【構成】
左側に「クライアント（あなたのPC）」、右側に「サーバ」を配置し、両者の間を矢印で接続する。

- 左側: クライアント
  - ノートPCのアイコン（またはシンプルなPC図）
  - ラベル: 「クライアント（Client）」
  - 補足: 「サービスを利用する側」「あなたのPCやスマートフォン」
  - 下部に小さくブラウザアイコンを添える

- 右側: サーバ
  - サーバーラックのアイコン（またはシンプルなサーバー図）
  - ラベル: 「サーバ（Server）」
  - 補足: 「サービスを提供する側」「24時間稼働の高性能コンピュータ」
  - 下部に小さくデータベースアイコンを添える

- 中央の矢印（双方向）:
  - 上向き矢印（クライアント→サーバ）: 「リクエスト（要求）」「このページを見せてください」
  - 下向き矢印（サーバ→クライアント）: 「レスポンス（応答）」「はい、どうぞ」
  - 矢印の間に「インターネット」の雲アイコンまたはラベルを配置

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- クライアント側は青系、サーバ側は緑系の配色
- リクエスト矢印はオレンジ系、レスポンス矢印は青系
- テキストは日本語、読みやすいゴシック体風
- 装飾は最小限。シンプルで直感的に理解できること
- アスペクト比 16:9
```
