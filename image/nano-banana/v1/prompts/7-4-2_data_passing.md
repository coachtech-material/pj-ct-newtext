# 7-4-2: PHPファイル間のデータ受け渡しフロー（B1: フローチャート）

**Gem**: v4.1 | **テンプレート**: B1 | **ステータス**: ドラフト

## プロンプト本文

```
複数のPHPファイル間でデータが受け渡される流れを、ユーザー登録フォームの例で図解してください。

## 内容
教材ではファイル間のデータ受け渡しをこう説明している:
- Webアプリは1つのPHPファイルだけで完結しない。複数ファイルが連携して1つの機能を実現
- 例: ユーザー登録の流れ
  1. 入力画面（form.php）: ユーザーが情報を入力
  2. 確認画面（confirm.php）: 入力内容を確認
  3. 完了画面（complete.php）: 登録完了を表示
- データ受け渡しの方法:
  - フォーム送信（POST）: $_POST で受け取る。データがURLに表示されない
  - URLパラメータ（GET）: $_GET で受け取る。データがURLに表示される
  - リダイレクト: header("Location: ...") で自動ページ遷移

## 描いてほしいもの
ユーザー登録フローを左から右へのストーリーとして描く:

①【入力画面: form.php】（左）
- フォーム画面のイラスト（名前・メール入力欄、送信ボタン）
- ユーザーキャラクターが入力中
- 吹き出し: 「名前とメールを入力して...送信！」
- ラベル: 「form.php（入力画面）」
- フォームの `action="confirm.php"` `method="post"` を小さく表示

②【データの移動】form.php → confirm.php
- 太い矢印に「POST送信」のラベル
- 封筒のイラスト（中にname=太郎, email=taro@...のデータ）
- 矢印の下に「$_POST["name"]」「$_POST["email"]」のコード

③【確認画面: confirm.php】（中央）
- 受け取ったデータを表示している画面
- キャラクターが「内容を確認してね！」とセリフ
- ラベル: 「confirm.php（確認画面）」

④【処理・リダイレクト】confirm.php → complete.php
- 太い矢印に「header("Location: complete.php")」のラベル
- 「処理完了後、自動でページ移動！」と注釈

⑤【完了画面: complete.php】（右）
- 「登録完了！」の画面
- ユーザーキャラクターが喜んでいる
- ラベル: 「complete.php（完了画面）」

### 下部: POSTとGETの比較ミニ表
- POST: 💬「データはURLに見えないよ（安全）」封筒のアイコン
- GET: 💬「データがURLに見える（共有しやすい）」ハガキのアイコン

タイトル: 「PHPファイル間のデータ受け渡し」

## 概念の強調
- 「$_POST」「$_GET」の変数名を大きく太い文字で描く
- ファイル名（form.php, confirm.php, complete.php）を各画面のラベルとして目立たせる
- データが「封筒に入って運ばれる」イメージで、ファイル間の受け渡しを視覚化
- 「POST送信」と「リダイレクト」の2種類の画面遷移方法が区別できること
```
