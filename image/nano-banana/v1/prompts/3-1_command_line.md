# 3-1: ターミナル・シェル・カーネルの関係（B2 構成図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: ドラフト

## プロンプト本文

```
教育用の構成図を描いてください。プログラミング初学者向けの教材に使用します。

テーマ: ターミナル・シェル・カーネルの関係 — コマンドライン操作の全体像

【構成】
左から右へ（または外側から内側へ）、3つの層を順番に配置する。ユーザーの操作がどのように伝わるかを示すフロー。

- 左端: ユーザー（人のアイコン）
  - ラベル: 「ユーザー（あなた）」
  - 「コマンドを入力する」

- 第1層: ターミナル
  - 黒い画面のアイコン（ターミナルウィンドウ）
  - ラベル: 「ターミナル（Terminal）」
  - 補足: 「コマンドを入力する窓口」「結果を表示する画面」
  - 比喩ラベル: 「マイクとスピーカー」
  - 具体例: 「Mac: ターミナル.app」「VSCode: 統合ターミナル」

- 第2層: シェル
  - 歯車または翻訳者のアイコン
  - ラベル: 「シェル（Shell）」
  - 補足: 「コマンドを解釈して伝える」
  - 比喩ラベル: 「シェフ（指示を理解して調理する人）」
  - 具体例: 「bash, zsh, fish」

- 第3層: カーネル
  - CPUまたはコンピュータの心臓部のアイコン
  - ラベル: 「カーネル（Kernel）」
  - 補足: 「コンピュータの心臓部」「実際にハードウェアを動かす」
  - 比喩ラベル: 「厨房の設備そのもの」

- 矢印:
  - ユーザー→ターミナル: 「コマンドを入力」
  - ターミナル→シェル: 「コマンドを渡す」
  - シェル→カーネル: 「命令に変換して伝える」
  - カーネル→シェル→ターミナル→ユーザー（戻りの流れ）: 「結果を返す」

【スタイル】
- フラットデザイン、クリーンで教育的な印象
- 背景は白
- ターミナルは暗いグレー/黒系、シェルはオレンジ系、カーネルは青系の配色で層を区別
- テキストは日本語、読みやすいゴシック体風
- 各層が入れ子になっている構造を視覚的に表現する（同心円または左から右への階段状）
- 装飾は最小限
- アスペクト比 16:9
```
