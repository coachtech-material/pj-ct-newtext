# 3-1: ターミナル・シェル・カーネルの関係（B2 構成図）

**Gem**: v4.1 | **テンプレート**: B2 | **ステータス**: テスト用

## プロンプト本文

```
ターミナル・シェル・カーネルの関係を、「レストランでの注文」の比喩でコミックエッセイ風に図解してください。

## コンセプト
「黒い画面に文字を打ち込む」という漠然としたイメージから、「自分の言葉がどうやってコンピュータに届くのか」を理解できる図解を目指します。

## 世界観: レストランの注文シーン
ユーザーのコマンド入力が、レストランでの注文→調理→提供の流れに例えられる。

## 登場キャラクターと感情表現

1. 【ユーザー（あなた）】
   - 外見: パソコンの前に座っている人
   - 表情: ワクワクした期待の顔
   - セリフ: 「ls って打ってみよう！」
   - アクション: キーボードをタイプする動作
   - 漫符: 💡ひらめきマーク

2. 【ターミナル（Terminal）】
   - 外見: 黒い画面のキャラクター化（目と口がある）
   - 比喩: 「マイク🎤とスピーカー🔊」
   - 表情: 優しく受け止める顔
   - セリフ①: 「はい、聞こえましたよ！」（入力時）
   - セリフ②: 「結果をお伝えしますね！」（出力時）
   - 色: 暗いグレー/黒系
   - 補足吹き出し: 「Mac: ターミナル.app」「VSCode: 統合ターミナル」

3. 【シェル（Shell）】
   - 外見: 翻訳者・通訳のキャラクター（メガネをかけている）
   - 比喩: 「通訳さん🗣️」
   - 表情: 賢そうで真剣な顔
   - セリフ①: 「なるほど、lsね...」
   - セリフ②: 「カーネルさん、ファイル一覧を見せて！」
   - 色: オレンジ系
   - 補足吹き出し: 「bash, zsh, fish」

4. 【カーネル（Kernel）】
   - 外見: 強そうなロボット、または心臓のアイコンをキャラクター化
   - 比喩: 「コンピュータの心臓❤️」
   - 表情: 頼もしく力強い顔
   - セリフ①: 「了解！ファイルシステムにアクセスするよ！」
   - セリフ②: 「はい、これがファイル一覧だよ！」
   - 色: 青系
   - 漫符: 歯車が回る、電気が走る⚡

## フロー（番号付き矢印）

① ユーザー → ターミナル
   ラベル: 「コマンドを入力」
   例: 「ls」とタイプ

② ターミナル → シェル
   ラベル: 「コマンドを渡す」
   シェルが受け取る動作

③ シェル → カーネル
   ラベル: 「命令に変換して伝える」
   翻訳されたコマンド

④ カーネル → シェル → ターミナル → ユーザー
   ラベル: 「結果を返す」
   ファイル一覧が画面に表示される
   ユーザーのセリフ: 「おお！ファイルが見えた！」😆

## レイアウト: 入れ子構造（玉ねぎ型）
外側から内側へ、同心円状に3つの層が重なっているイメージ:
- 最外層（グレー）: ターミナル
- 中層（オレンジ）: シェル
- 最内層（青）: カーネル
- 左側にユーザーが立っている

## タイトル
リーフバナーで装飾: 「コマンドが届くまで 〜ターミナル・シェル・カーネル〜」

## 絶対に守ること
- 3つの層（ターミナル、シェル、カーネル）の役割の違いが明確
- 各層に技術用語（大）+ 比喩（小）のラベル
- フローの矢印に番号①②③④
- キャラクターに表情と吹き出し
- 背景は明るく温かみのある白
```
