# 9-4-7: 論理削除の仕組み

## プロンプト本文

```
物理削除と論理削除の違いを、シンプルな教育インフォグラフィックとして図解してください。

## デザインスタイル
- 明るいクリーム色の背景
- カラフルな紙吹雪風の装飾枠（四隅に星・丸・リボン）

- 太い枠線で区切り

## タイトル（上部中央・大きく）
「物理削除 vs 論理削除」
サブタイトル: 「削除にも種類がある！」

## 左右2分割構成

【左側】物理削除（DELETE）- 赤/オレンジ系ボックス
- アイコン: シュレッダー
- 説明: 「データを完全に消す」
- イメージ: 書類が粉々に
- 結果: 復元不可
- テーブル例:
  | id | name |
  | 1  | 田中 |
  | 2  | 鈴木 |
  ← id:5 が消滅

【右側】論理削除（SoftDelete）- 緑/青系ボックス
- アイコン: 保管庫
- 説明: 「削除フラグを立てる」
- イメージ: 書類を保管庫へ
- 結果: 復元可能
- テーブル例:
  | id | name | deleted_at |
  | 1  | 田中 | NULL |
  | 5  | 山田 | 2024-01-15 | ← 削除済み

## 下部に比較表（シンプルに）
| 項目 | 物理削除 | 論理削除 |
| 復元 | 不可 | 可能 |
| 用途 | 完全削除 | 一時削除 |

## キャラクター（右下に小さく1人）
- シンプルなイラスト調の開発者
- 吹き出し:「deleted_atで管理！」
```
