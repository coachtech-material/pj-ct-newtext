# 6-1-1: Dockerコンテナの概念（A1+B2: 比喩+構成図）

**Gem**: v4.1 | **テンプレート**: A1+B2 | **ステータス**: ドラフト

## プロンプト本文

```
Dockerの「コンテナ」の概念を、「海外引越し用の特殊コンテナ」の比喩と、技術的な構成図の両方で図解してください。

## 内容
教材ではDockerをこう例えている:
- Dockerコンテナ = 海外引越し用の特殊コンテナ（中に日本の電圧環境を丸ごと再現する機能付き）
- 電化製品 = アプリケーション
- 日本の電圧環境 = 実行環境（OS、PHP、Nginxなどのバージョン）
- どの国に持って行っても、コンテナを開けば同じように動く = 環境差異の解消

## 描いてほしいもの

### 上段: 比喩パート（引越しコンテナ）
左から右へのストーリー:

①【日本の部屋】
- 電化製品（アプリ）が日本のコンセント（環境）で動いている
- キャラクター「開発者くん」が「この環境ごと持って行きたい！」とセリフ

②【梱包シーン】
- 大きな輸送コンテナ（Dockerコンテナ）の中に、電化製品＋日本のコンセント＋変圧器などを丸ごとパッケージング
- コンテナに「Docker」のロゴ（🐳クジラ）
- 「環境ごと箱詰め！」のセリフ

③【海外到着】
- アメリカやヨーロッパの国旗がある場所で、同じコンテナを開いて中の電化製品が完璧に動作
- 「どこでも同じように動く！」とキャラクターが喜ぶ

### 下段: 技術パート（構成図）
コンテナの中身を技術用語で図示:
- コンテナ内: Linux + PHP 8.1 + Nginx + アプリケーションコード
- ホストOS（Mac / Windows / Linux）の上にDockerエンジン、その上にコンテナが載っている構成

タイトル: 「Dockerコンテナ: 環境をまるごとパッケージング」

## 概念の強調
- 「Container（コンテナ）」を最も大きく太い文字で描く
- 「環境差異の解消」がこの図の核心メッセージ
- 比喩パートと技術パートの対応関係（電化製品=アプリ、日本の電圧=PHP/Nginx等）を点線や注釈で結ぶ
- 「どこでも同じように動く」を強調する漫符（キラキラ、ビックリマーク）
```
