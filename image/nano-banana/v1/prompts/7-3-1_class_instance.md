# 7-3-1: クラスとインスタンス（A1: 比喩イラスト）

**Gem**: v4.1 | **テンプレート**: A1 | **ステータス**: ドラフト

## プロンプト本文

```
クラス（設計図/たい焼きの型）とインスタンス（実体/たい焼き）の関係を、たい焼き屋の比喩で図解してください。

## 内容
教材ではクラスとインスタンスをこう例えている:
- クラス（Class）= 設計図、たい焼きの型
  - 「たい焼きは、あんこを持っていて、頭から食べられる」といった共通の性質と振る舞いを定義
  - クラス自体はまだ具体的なたい焼きではなく、あくまで設計情報
- インスタンス（Instance）= 設計図から作られた実体、個々のたい焼き
  - クラスに基づいて作られるが、それぞれ独立した存在
  - 例: あるたい焼きは「つぶあん」、別のたい焼きは「こしあん」
- `new`キーワードで型（クラス）からたい焼き（インスタンス）を生成する

## 描いてほしいもの

### 左側: クラス（たい焼きの型）
- たい焼きの金型（鉄の型）のイラスト
- 型には設計情報が書き込まれている:
  - 「プロパティ: $name（名前）, $filling（中身）」
  - 「メソッド: introduce()（自己紹介する）」
- ラベル: 「Class（クラス = 設計図/型）」
- 型キャラクターのセリフ: 「私は設計図！ここから何個でも作れるよ！」
- コードスニペット: `class User { ... }`

### 中央: new キーワードの矢印
- 「new User()」と書かれた太い矢印
- キラキラや星の漫符で「生成」を演出
- 矢印の上に「①型にあんこを入れて...」「②ギュッと押して...」「③完成！」のミニストーリー

### 右側: インスタンス（個々のたい焼き）
- 3つの異なるたい焼きキャラクター:
  - たい焼きA: つぶあん、笑顔 → ラベル「$user1」
    - 吹き出し: 「僕はつぶあん！名前は太郎！」
  - たい焼きB: こしあん、ウインク → ラベル「$user2」
    - 吹き出し: 「私はこしあん！名前は花子！」
  - たい焼きC: カスタード、驚き顔 → ラベル「$user3」
    - 吹き出し: 「俺はカスタード！名前は次郎！」
- ラベル: 「Instance（インスタンス = 実体）」
- 注釈: 「同じ型から作られたけど、中身はそれぞれ違う！」

タイトル: 「クラスとインスタンス」

## 概念の強調
- 「Class（クラス）」「Instance（インスタンス）」の技術用語を最も大きく太い文字で描く
- 「new」キーワードを矢印上に大きく目立たせる（クラスからインスタンスを生成する唯一の手段）
- 「1つの型から複数の異なるインスタンスが作れる」ことが図の核心
- 比喩名（設計図、たい焼きの型、たい焼き）は技術用語の下に小さく添える
- 各インスタンスが独立した状態（異なる中身）を持つことを視覚的に表現
```
