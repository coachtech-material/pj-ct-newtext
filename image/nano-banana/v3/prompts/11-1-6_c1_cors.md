# 11-1-6_c1: CORSとは

## 対象Section
- Tutorial 11-1-6: CORSとは
- 説明: 異なるオリジン間のリソース共有（CORS）の概念図

## リサーチメモ
- CORS = Cross-Origin Resource Sharing
- オリジン = プロトコル + ドメイン + ポート
- ブラウザはデフォルトで異なるオリジンへのリクエストをブロック（セキュリティ）
- CORSヘッダーがあれば許可される
