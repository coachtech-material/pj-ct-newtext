# 10-6-1_c1: CSRF攻撃

## 対象Section
- Tutorial 10-6-1: CSRF保護
- 説明: CSRF攻撃のシナリオを示す概念図

## リサーチメモ
- 一般的な図解パターン: 3者（攻撃者、被害者、正規サイト）の三角形構図
- 4ステップ: 攻撃者が偽造リクエスト作成 → 被害者に送付 → 被害者がクリック → 正規サイトが実行
- 教材のシナリオ: SNSにログイン中 → 悪意あるサイト訪問 → 投稿削除リクエストが送信される
- Sources: [PortSwigger](https://portswigger.net/web-security/csrf), [OWASP](https://owasp.org/www-community/attacks/csrf), [Cloudflare](https://www.cloudflare.com/learning/security/threats/cross-site-request-forgery/)

- Colors: 3-color palette (red for attacker/evil site, blue for victim, green for legitimate site)

## Title

## Layout
Triangle layout showing 3 actors:
- Top: Victim (被害者)
- Bottom left: Attacker's site (evil.com)
- Bottom right: Legitimate site (example.com)

## Attack Flow (numbered steps)
1. Victim logs into legitimate site (session cookie saved)
2. Victim visits attacker's malicious site
3. Malicious site contains hidden form targeting legitimate site
4. Victim unknowingly submits request to legitimate site
5. Legitimate site accepts request (victim is authenticated via cookie)
6. Malicious action executed (e.g., post deleted)
