# 10-6-3_c1: XSS対策

## 対象Section
- Tutorial 10-6-3: XSS対策
- 説明: XSS攻撃の仕組みとエスケープによる対策の概念図

## リサーチメモ
- XSS = クロスサイトスクリプティング（悪意のあるスクリプトを埋め込む攻撃）
- Webでよく使われる構図: 攻撃の流れを4ステップで図解
  1. 攻撃者が罠（スクリプト）を仕掛ける
  2. ユーザーがアクセス
  3. スクリプトが実行される
  4. 被害発生（Cookie盗難、セッションハイジャック）
- 対策: エスケープ（特殊文字をHTMLエンティティに変換）
- Laravel: {{ }} で自動エスケープ、{!! !!} はエスケープ無効（危険）
