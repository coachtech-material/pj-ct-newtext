# 13-5-1_c1: Fortify認証

## 対象Section
- Tutorial 13-5-1: 認証機能の実装（Fortify）
- 説明: Laravel認証パッケージの比較図

## リサーチメモ
- Laravel認証パッケージ3種類:
  - Fortify: UIなし（ヘッドレス）、カスタマイズ自由
  - Breeze: シンプルなUI付き、Tailwind CSS
  - Jetstream: 高機能（チーム管理、2FA）
- Fortifyの特徴: 自分でビューを作成、認証ロジックのみ提供
- 教材では独自デザインの認証画面を作りたいのでFortifyを使用
