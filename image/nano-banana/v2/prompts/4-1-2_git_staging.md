# 4-1-2: Gitステージングエリア

## リサーチ結果

**検索キーワード**: Git staging area 図解 ワーキングツリー インデックス

**標準的な構図パターン**:
- 3つの領域が左から右へ並ぶ: 作業ディレクトリ → ステージ → リポジトリ
- git add で右へ、git checkout で左へ
- git commit で右へ、git reset で左へ

**参考**: [図解 Git](https://marklodato.github.io/visual-git-guide/index-ja.html)

---

## プロンプト

```
Gitのステージングエリア（インデックス）の図解を作成してください。

## 構成要素（左から右へ3つの箱）
1. 作業ディレクトリ (Working Directory)
   - フォルダアイコン
   - 「ファイルを編集する場所」

2. ステージングエリア (Staging Area / Index)
   - クリップボードまたはカメラアイコン
   - 「コミット前の準備エリア」

3. リポジトリ (Repository / History)
   - データベースまたは履歴アイコン
   - 「確定した履歴」

## 矢印とコマンド
- 作業ディレクトリ → ステージ: 上矢印「git add」
- ステージ → リポジトリ: 上矢印「git commit」
- リポジトリ → ステージ: 下矢印「git reset」
- ステージ → 作業ディレクトリ: 下矢印「git checkout」

## スタイル
- シンプルな技術図解
- 背景は白または薄いグレー
- 3つの箱は同じサイズで横並び
- 右方向の矢印（add, commit）は緑または青
- 左方向の矢印（reset, checkout）は赤またはオレンジ
- 各領域のラベルは英語と日本語併記
```

## 構図イメージ

```
              git add                git commit
         ─────────────→         ─────────────→
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  Working        │    │  Staging        │    │  Repository     │
│  Directory      │    │  Area           │    │  (History)      │
│                 │    │                 │    │                 │
│  📁 ファイル編集 │    │  📋 コミット準備 │    │  🗄️ 確定した履歴 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         ←─────────────         ←─────────────
           git checkout           git reset
```
