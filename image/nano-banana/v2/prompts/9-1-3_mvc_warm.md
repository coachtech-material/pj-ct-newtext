# 9-1-3: MVCアーキテクチャ（温かみ版）

## プロンプト本文

```
プログラミング教材向けの技術図解「MVCアーキテクチャ」を作成してください。
標準的なMVC図解をベースに、温かみと分かりやすさを加えてください。

## スタイル指定
- アスペクト比: 16:9 横長
- 解像度: 4K
- 背景: 淡いクリーム色または温かみのあるオフホワイト
- デザイン: シンプルな技術図解 + 温かみ
  - 楕円形のボックス（柔らかい印象）
  - パステル調の色使い（彩度を抑えめに）
  - 線は少し丸みを帯びた優しい印象
  - 矢印には日本語ラベルを添える

## タイトル（上部中央）
「MVCアーキテクチャ」大きな文字
サブタイトル: 「データの流れを理解しよう」

## 構成要素

1. User（左端）
   - パソコンのシンプルなアイコン
   - ラベル: 「ユーザー」

2. Controller（上部中央、最も目立つ）
   - 淡い青色（パステルブルー）の楕円
   - ラベル: 「Controller」
   - サブラベル: 「制御・司令塔」
   - 図の中心的存在として大きめに

3. View（左下）
   - 淡い緑色（パステルグリーン）の楕円
   - ラベル: 「View」
   - サブラベル: 「表示」

4. Model（右下）
   - 淡いオレンジ色（パステルオレンジ）の楕円
   - ラベル: 「Model」
   - サブラベル: 「データ処理」

5. Database（右端）
   - グレーの円筒形
   - ラベル: 「Database」

## データフロー（矢印とラベル）
黒い太めの矢印、日本語ラベル付き:
- User → Controller:「リクエスト」
- Controller ↔ View:「制御」「データ渡し」（双方向）
- Controller ↔ Model:「制御」「データ渡し」（双方向）
- Model ↔ Database:「データ取得/保存」（双方向）
- View → User:「画面表示」

## 重要な制約
- ViewとModelは直接接続しない（必ずController経由）
- Controllerが中央上部のハブとして機能することを視覚的に強調
- シンプルで見やすい構成
- パステル調の優しい色使い
- 余計な装飾は不要
```
