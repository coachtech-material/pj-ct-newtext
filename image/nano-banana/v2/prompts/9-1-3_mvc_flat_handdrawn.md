## プロンプト本文

```
プログラミング教材向けの技術図解「MVCアーキテクチャ」をフラットな手書き風イラストで作成してください。

## スタイル
- アスペクト比: 16:9
- 背景: クリーンな白（純白、テクスチャなし）
- デザイン: フラットデザイン + 手書き風の線
- 線: 手書き風だが整った線、適度な太さ
- 色: パステル調のフラットカラー

## タイトル（上部中央）
「MVCアーキテクチャ」手書き風フォント

## 配置と要素

【左端】ブラウザ
- シンプルなパソコンアイコン（フラット）
- ラベル: 「ブラウザ」

【左上】Router（オレンジ）
- 角丸四角形
- ラベル: 「Router」

【上部中央】Controller（青、最も大きく）
- 楕円形
- ラベル: 「Controller」

【左下】View（緑）
- 楕円形
- ラベル: 「View」

【右下】Model（赤/ピンク）
- 楕円形
- ラベル: 「Model」

【右端】Database
- シンプルな円筒形アイコン（フラット）
- ラベル: 「DB」

## 矢印
- シンプルな手書き風の矢印
- ブラウザ → Router → Controller
- Controller ↔ View（双方向）
- Controller ↔ Model（双方向）
- Model ↔ Database（双方向）
- View → ブラウザ

## 重要
- ViewとModelは直接接続しない
- 背景は純白でクリーン（テクスチャや汚れなし）
- フラットデザインだが手書き風の温かみ
```
