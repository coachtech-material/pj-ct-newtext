# 9-1-3: MVCアーキテクチャ（イラスト風版）

## プロンプト本文

```
プログラミング教材向けの技術図解「MVCアーキテクチャ」を温かみのあるイラスト風で作成してください。
概念の理解を優先し、装飾は控えめにしてください。

## スタイル指定
- アスペクト比: 16:9 横長
- 解像度: 4K
- 背景: 淡いクリーム色または白
- デザイン: 手描き風イラスト、温かみのあるタッチ
  - 線は少し揺れのある手描き風
  - パステル調の柔らかい色使い
  - キャラクターやアイコンはシンプルに
- 概念図解として分かりやすさを最優先

## タイトル（上部中央）
「MVCアーキテクチャ」手書き風の大きな文字
サブタイトル: 「データの流れを見てみよう」

## 構成要素（シンプルなアイコンとラベル）

1. ユーザー（左端）
   - パソコンを使う人のシンプルなイラスト
   - ラベル: 「ユーザー」
   - 吹き出し: 「リクエスト送信！」

2. Router（上部）
   - 道路標識または矢印のアイコン
   - 淡いオレンジ色の丸または四角
   - ラベル: 「Router」（振り分け）

3. Controller（中央、最も目立つ）
   - 指揮者または司令官のシンプルなアイコン
   - 淡い青色の大きめの円または四角
   - ラベル: 「Controller」（司令塔）
   - 吹き出し: 「指示を出すよ！」

4. Model（下部）
   - データベースまたは書類棚のアイコン
   - 淡い緑色の丸または四角
   - ラベル: 「Model」（データ管理）

5. View（右側）
   - 画面または絵を描く道具のアイコン
   - 淡いピンク色の丸または四角
   - ラベル: 「View」（表示担当）

6. Database（右下）
   - シンプルな円筒形のデータベースアイコン
   - ラベル: 「DB」

## データフロー
手描き風の曲線矢印、番号付き（①〜⑦）:
① ユーザー → Router「リクエスト」
② Router → Controller「振り分け」
③ Controller → Model「データちょうだい」
④ Model ↔ Database「取得/保存」
⑤ Model → Controller「はいどうぞ」
⑥ Controller → View「これ表示して」
⑦ View → ユーザー「レスポンス」

## 重要な制約
- 概念の理解しやすさを最優先
- 装飾的な要素は最小限に
- ViewとModelは直接接続しない
- Controllerが中央のハブであることを明確に
- キャラクターは入れても1-2個程度、主役は構造図
- 番号①〜⑦は重複なし
```
