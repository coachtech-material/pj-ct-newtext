# 9-1-3: MVCアーキテクチャ

## リサーチ結果

**検索キーワード**: MVC アーキテクチャ 図解 / MVC diagram standard layout

**標準的な構図パターン**:
- Controller が中央上部（ハブ役・司令塔）
- View（左下）と Model（右下）は Controller 経由でやり取り
- User/Browser は左端
- Database は右端（Model と接続）
- View ↔ Model は直接やり取りしない

**参考**: [freeCodeCamp](https://www.freecodecamp.org/news/model-view-architecture/), [Wikipedia](https://en.wikipedia.org/wiki/Model%E2%80%93view%E2%80%93controller)

---

## プロンプト

```
MVCアーキテクチャの図解を作成してください。

## 構成要素
- User（ブラウザ）: 左端にパソコンアイコン
- Controller: 中央上部、青色の楕円、「制御」担当
- View: 左下、緑色の楕円、「表示」担当
- Model: 右下、オレンジ色の楕円、「データ処理」担当
- Database: 右端にDB円筒アイコン

## 矢印（データフロー）
- User → Controller: 「リクエスト」
- Controller ↔ View: 「制御」「データ渡し」（双方向）
- Controller ↔ Model: 「制御」「データ渡し」（双方向）
- Model ↔ Database: 「データ取得/保存」（双方向）
- View → User: 「画面表示」

## 重要ポイント
- View と Model は直接やり取りしない（必ず Controller 経由）
- Controller が中心的存在であることを視覚的に強調
- 各要素のラベルは英語（Controller, View, Model）で大きく表示

## スタイル
- シンプルで見やすい技術図解
- 背景は白または薄いグレー
- 矢印は太めで方向が明確
- 色分け: Controller=青, View=緑, Model=オレンジ
```

## 構図イメージ

```
        ┌─────────┐
        │  User   │
        │   🖥️    │
        └────┬────┘
             │ リクエスト
             ↓
        ┌─────────────┐
        │ Controller  │  ← 青色・中央
        │   (制御)    │
        └──┬─────┬────┘
           │     │
     制御  ↓     ↓ 制御
    ┌──────────┐   ┌──────────┐
    │   View   │   │  Model   │──→ 🗄️ DB
    │  (表示)  │   │ (データ) │←──
    └────┬─────┘   └──────────┘
         │
         ↓ 画面表示
    ┌─────────┐
    │  User   │
    └─────────┘
```
