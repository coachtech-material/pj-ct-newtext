# 9-1-3: MVCアーキテクチャ（ネオブルータリズム版）

## プロンプト本文

```
プログラミング教材向けの技術図解「MVCアーキテクチャ」をネオブルータリズムスタイルで作成してください。

## スタイル指定
- アスペクト比: 16:9 横長
- 解像度: 4K
- 背景: クリーム色または薄い黄色（#FFF8E1）
- デザイン: ネオブルータリズム（Neobrutalism）
  - 太い黒の枠線（4-6px）
  - 大胆でビビッドな塗りつぶし色
  - シャドウは右下にオフセット（黒い影）
  - シンプルで力強いタイポグラフィ
- 余計な装飾は不要

## タイトル（上部）
「MVCアーキテクチャ」大きく太い黒文字
サブタイトル: 「リクエストからレスポンスまでの流れ」

## 構成要素（左から右へ配置）

1. ユーザー（左端）
   - 黄色（#FFEB3B）の四角形、太い黒枠
   - パソコンアイコン
   - ラベル: 「ユーザー」

2. Router（左上）
   - オレンジ色（#FF9800）の四角形、太い黒枠、黒シャドウ
   - ラベル: 「Router」太字
   - サブラベル: 「振り分け」

3. Controller（中央、最大）
   - 青色（#2196F3）の四角形、太い黒枠、黒シャドウ
   - ラベル: 「Controller」最も大きく太く
   - サブラベル: 「司令塔」
   - この図の視覚的な中心

4. Model（右下）
   - 緑色（#4CAF50）の四角形、太い黒枠、黒シャドウ
   - ラベル: 「Model」
   - サブラベル: 「データ処理」

5. View（右上）
   - ピンク色（#E91E63）の四角形、太い黒枠、黒シャドウ
   - ラベル: 「View」
   - サブラベル: 「表示」

6. Database（右端）
   - グレー（#607D8B）の円筒形、太い黒枠
   - ラベル: 「DB」

## データフロー（番号付き矢印）
太い黒矢印（3-4px）、丸で囲んだ番号:
① ユーザー → Router
② Router → Controller
③ Controller → Model
④ Model ↔ Database
⑤ Model → Controller
⑥ Controller → View
⑦ View → ユーザー

矢印はシンプルで直線的、方向が明確。

## 重要な制約
- ViewとModelを直接接続しない
- Controllerを中央に最も大きく配置
- ネオブルータリズムの特徴（太い枠、影、大胆な色）を強調
- ごちゃごちゃした装飾は避ける
- 番号は①〜⑦の7つのみ、重複なし
```
