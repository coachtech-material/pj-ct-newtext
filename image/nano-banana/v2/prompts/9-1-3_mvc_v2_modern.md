# 9-1-3: MVCアーキテクチャ（v2モダン版）

## プロンプト本文

```
プログラミング教材向けの技術図解を作成してください。テーマは「MVCアーキテクチャ」です。

## スタイル
- アスペクト比: 16:9 横長
- 解像度: 4K
- 背景: 淡いグラデーション（白からごく薄いブルーグレー）
- デザイン: グラスモーフィズム風のモダンUI、フロスティガラス効果
- フォント: ゴシック体、太字の見出し
- 余計な装飾、透かし、凡例ボックスは不要

## タイトル（上部中央）
「MVCアーキテクチャ」大きく太い日本語テキスト
サブタイトル: 「Webアプリケーションの基本構造」小さめのテキスト

## 構成要素（5つの角丸カード、グラスモーフィズム風に半透明）

1. ユーザー（左側）
   - 薄い水色の半透明カード、フロスティ効果
   - パソコン/ブラウザのアイコン
   - ラベル: 「ユーザー」太字

2. ルーティング（上部）
   - オレンジ色のグラデーションカード
   - ラベル: 「Routing」太字、白文字
   - サブラベル: 「振り分け」小さく
   - 「web.php」モノスペースフォント

3. コントローラー（中央、最も大きく目立つ）
   - 青色のグラデーションカード、1.5倍の大きさ
   - ラベル: 「Controller」太字、白文字、この図の主役
   - サブラベル: 「司令塔」
   - 「UserController」モノスペースフォント

4. モデル（右下）
   - 緑色のグラデーションカード
   - ラベル: 「Model」太字、白文字
   - サブラベル: 「データ処理」
   - 「User::all()」
   - 隣にデータベース（円筒形、グレー）

5. ビュー（右側）
   - ピンク/マゼンタのグラデーションカード
   - ラベル: 「View」太字、白文字
   - サブラベル: 「表示」
   - 「index.blade.php」

## データフロー（番号付き矢印）
滑らかな曲線矢印、丸で囲まれた番号（①②③④⑤⑥⑦）:
① ユーザー → Routing
② Routing → Controller
③ Controller → Model
④ Model ↔ Database（双方向）
⑤ Model → Controller（データ返却）
⑥ Controller → View
⑦ View → ユーザー（曲線で戻る）

矢印は太め、ダークグレー、方向が明確。

## 重要な制約
- ViewとModelを直接接続しない（必ずController経由）
- Controllerを視覚的に最も目立たせる（中央、最大サイズ）
- 要素間に適切な余白
- モダンでプロフェッショナルな外観
- 凡例ボックスや説明テキストは下部に配置しない
- 番号の重複なし（①〜⑦は各1回のみ使用）
```
