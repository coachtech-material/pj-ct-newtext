# 9-1-3: MVCアーキテクチャ（ハイブリッド最終版）

## プロンプト本文

```
プログラミング教材向けの技術図解「MVCアーキテクチャ」を作成してください。
ネオブルータリズムの力強さとイラスト風の温かみを組み合わせたスタイルです。

## スタイル指定
- アスペクト比: 16:9 横長
- 解像度: 4K
- 背景: 淡いクリーム色（#FFF8E1）
- デザイン: ネオブルータリズム + イラスト風のハイブリッド
  - 太い黒枠（3-4px）でボックスを囲む
  - 右下に軽いシャドウ
  - パステル調の柔らかい色使い
  - シンプルで親しみやすいアイコン
  - 矢印にはラベルを添える

## タイトル（上部中央）
「MVCアーキテクチャ」大きく太い黒文字
サブタイトル: 「データの流れを見てみよう」

## 構成要素（角丸四角形、太い黒枠）

1. ユーザー（左端）
   - 淡い黄色の角丸四角形、太い黒枠
   - パソコンを使う人のシンプルなアイコン
   - ラベル: 「ユーザー」

2. Router（上部左）
   - 淡いオレンジ色の角丸四角形、太い黒枠、シャドウ
   - 道路標識のシンプルなアイコン
   - ラベル: 「Router」
   - サブラベル: 「振り分け」

3. Controller（中央、最も大きく目立つ）
   - 淡い青色の角丸四角形、太い黒枠、シャドウ
   - 指揮者または司令官のシンプルなアイコン
   - ラベル: 「Controller」
   - サブラベル: 「司令塔」
   - 吹き出し: 「指示を出すよ！」

4. Model（下部）
   - 淡い緑色の角丸四角形、太い黒枠、シャドウ
   - ファイルボックスまたは書類棚のアイコン
   - ラベル: 「Model」
   - サブラベル: 「データ管理」

5. View（右側）
   - 淡いピンク色の角丸四角形、太い黒枠、シャドウ
   - 画面または絵筆のシンプルなアイコン
   - ラベル: 「View」
   - サブラベル: 「表示担当」

6. Database（右下）
   - グレーの円筒形、太い黒枠
   - ラベル: 「DB」

## データフロー（番号付き矢印）
太い黒矢印（2-3px）、丸で囲んだ番号、ラベル付き:
① ユーザー → Router「リクエスト」
② Router → Controller「振り分け」
③ Controller → Model「データちょうだい」
④ Model ↔ Database「取得/保存」
⑤ Model → Controller「はいどうぞ」
⑥ Controller → View「これ表示して」
⑦ View → ユーザー「レスポンス」

## 重要な制約
- ViewとModelを直接接続しない（必ずController経由）
- Controllerを中央に最も大きく配置（司令塔として強調）
- 太い黒枠でネオブルータリズムの力強さを出す
- パステルカラーとアイコンで温かみを出す
- 吹き出しは1-2個のみ（Controllerに「指示を出すよ！」）
- 番号①〜⑦は重複なし
- 右下に凡例や説明テキストは不要
```
