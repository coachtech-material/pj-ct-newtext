## 1. リサーチ結果

**検索キーワード**: MVC architecture diagram / MVC pattern flow chart / Laravel MVC

**標準的な構図パターン**:
- Controller が中央（ハブ役・司令塔）として最も目立つ位置
- User/Browser は左端、Database は右端に配置
- View と Model は Controller を中心に左右または上下に配置
- View ↔ Model は直接接続しない（必ず Controller 経由）
- フローは番号付き矢印で明確に

**参考にした良い点**:
- C4モデルのようなシンプルなネストボックス構造
- 色分けは4色以内で統一感を持たせる
- 技術用語を大きく、説明を小さく配置

## 3. プロンプト本文

```
プログラミング教材向けの技術図解を作成してください。テーマは「MVCアーキテクチャ」です。

## 全体構成

タイトル: MVCアーキテクチャ
サブタイトル: Webアプリケーションの基本構造

配置: 左から右への横長レイアウト（16:9）
背景: 白または非常に薄いグレー
スタイル: プロフェッショナルな技術図解、シンプルで見やすい

## 構成要素（5つのボックス）

1. User（左端）
   - 形状: 四角形、水色の背景
   - ラベル: 「User」（大きく）
   - アイコン: パソコン/ブラウザ（🌐）
   - 配置: 左端中央

2. Routing（上部）
   - 形状: 角丸四角形、オレンジ色の背景
   - ラベル: 「ROUTING」（大きく太く）
   - サブラベル: 「振り分け」（小さく）
   - コード例: 「web.php」（モノスペースフォント）
   - 配置: User の右上

3. Controller（中央・最も大きく）
   - 形状: 角丸四角形、青色の背景
   - ラベル: 「CONTROLLER」（最も大きく太く、この図の主役）
   - サブラベル: 「司令塔」（小さく）
   - コード例: 「UserController」（モノスペースフォント）
   - 配置: 図の中央、他より大きいサイズ

4. Model（右下）
   - 形状: 角丸四角形、緑色の背景
   - ラベル: 「MODEL」（大きく太く）
   - サブラベル: 「データ処理」（小さく）
   - コード例: 「User::all()」（モノスペースフォント）
   - 配置: Controller の右下
   - 隣にDatabase（円筒形、グレー）を配置

5. View（右）
   - 形状: 角丸四角形、ピンク/マゼンタ色の背景
   - ラベル: 「VIEW」（大きく太く）
   - サブラベル: 「表示」（小さく）
   - コード例: 「index.blade.php」（モノスペースフォント）
   - 配置: Controller の右

## データフロー（番号付き矢印）

太い矢印で番号を付けて描く。矢印には短いラベルを添える。

① User → Routing:「リクエスト」
② Routing → Controller:「振り分け」
③ Controller → Model:「データ要求」
④ Model → Database:「クエリ」
⑤ Database → Model → Controller:「データ返却」
⑥ Controller → View:「データ渡し」
⑦ View → User:「画面表示」

## 重要な制約

- View と Model を直接接続しない（必ず Controller 経由）
- Controller を最も大きく、中央に配置して強調
- 各ボックスの技術用語（ROUTING, CONTROLLER, MODEL, VIEW）は大きく太い英字
- 色は4色のみ使用（オレンジ、青、緑、ピンク）
- 番号付き矢印（①〜⑦）は全て見えるように

## 凡例（右下または下部）

- 色の意味を簡潔に表示
- 「矢印はデータの流れを示す」と記載

## 避けるべき要素

- 複雑な装飾や影
- 不要なテキストや説明文
- ごちゃごちゃした背景
- View と Model の直接接続
```
