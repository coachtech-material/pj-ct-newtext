## プロンプト本文

```
プログラミング教材向けの技術図解「MVCアーキテクチャ」をホワイトボードに描いたようなスタイルで作成してください。

## スタイル
- アスペクト比: 16:9 横長
- 背景: 白いホワイトボード
- デザイン: マーカーで描いた手書き風
- 線: 太めのマーカー線、少しラフな感じ
- 色: カラフルなマーカー色

## タイトル（上部中央）
「MVCアーキテクチャ」青マーカーで大きく

## 配置と要素

【左端】ブラウザ
- パソコンの簡単なイラスト
- ラベル: 「ブラウザ」

【左上】Router（オレンジ色マーカー）
- 四角形
- ラベル: 「Router」「振り分け」

【上部中央】Controller（青色マーカー、最も大きく）
- 楕円または四角形
- ラベル: 「Controller」「司令塔」

【左下】View（緑色マーカー）
- 楕円または四角形
- ラベル: 「View」「表示」

【右下】Model（赤またはピンク色マーカー）
- 楕円または四角形
- ラベル: 「Model」「データ処理」

【右端】Database
- 円筒形
- ラベル: 「DB」または「データベース」

## 矢印（黒または黄色マーカー）
- ブラウザ → Router → Controller
- Controller ↔ View（双方向）
- Controller ↔ Model（双方向）
- Model ↔ Database（双方向）
- View → ブラウザ（レスポンス）

## 重要
- ViewとModelは直接接続しない
- Controllerが中央のハブ
- ホワイトボードに実際に描いたような自然な手書き感
- シンプルで見やすく
```
