# ハンズオンSection検証スキル

## 目的

ハンズオンSectionが実際に動作するか、事前チェックを行う。

## 必読ファイル

1. `guides/handson-structure.md` - ハンズオン構成ガイド
2. `guides/verification.md` - 検証ガイド

## 検証ワークフロー

```
1. 対象Sectionを読む
2. チェックリストに沿って検証
3. 問題点を洗い出し
4. ユーザーに報告
5. 問題があればGitHub Issueとして記録
```

## チェックリスト

### 1. 要件・前提

- [ ] 作業ディレクトリが明記されているか
- [ ] 新規/既存プロジェクトが明記されているか
- [ ] 必要なファイル（モデル、コントローラー等）が明記されているか
- [ ] 完成イメージが明記されているか

### 2. 手順

- [ ] ステップが順番に並んでいるか
- [ ] 各ステップの内容が明確か
- [ ] ファイル作成コマンドがあるか
- [ ] コード例が完全か（省略しすぎていないか）
- [ ] import文や依存関係が記載されているか

### 3. 動作確認

- [ ] 確認方法が記載されているか
- [ ] 期待する結果が明記されているか

### 4. 構成の整合性

- [ ] 「✏️ 実装タスク」「🧠 思考プロセス」「📝 ステップバイステップ」のステップが一致しているか
- [ ] 各ステップの文言が統一されているか
- [ ] コードの一貫性（ステップ・模範解答・Blade）が保たれているか

## 報告フォーマット

```markdown
## [Section番号] 検証結果

### 結果
- [ ] 問題なし
- [ ] 軽微な問題あり
- [ ] 重大な問題あり

### 発見した問題

| No | 問題 | 重要度 | 修正案 |
|:---|:-----|:-------|:-------|
| 1 | ... | 高/中/低 | ... |

### 備考
...
```

## 注意

- **修正は検証後、ユーザー承認を得てから行うこと**
- 問題を発見した場合はGitHub Issueとして記録する
- 致命的な問題はユーザーに即座に報告する
