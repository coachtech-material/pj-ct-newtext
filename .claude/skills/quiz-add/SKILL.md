# 確認問題の追加 (quiz-add)

`quiz/` は、各概念Sectionの最後に LMS で表示する「確認問題」と、AI採点・コーチのフィードバックに使う「模範解答」を管理するディレクトリです。受講生は問題文に対して自由記述で解答します。

**作業前に `quiz/README.md` を読んでください**（この規約の一次情報です）。

## ディレクトリ構成（curriculums/ をミラー）

各Sectionは `.md` ファイルではなく**ディレクトリ**で表し、中に2ファイルを置きます。

```
quiz/
└── {tutorial}/
    └── {chapter}/
        └── {N}-{M}-{S}_{見出し名}/
            ├── question.md      # 問題文（1文・記述式）
            └── model-answer.md  # 模範解答（AI採点・コーチFB用）
```

- ディレクトリ名は `curriculums/` のSectionファイル名から拡張子 `.md` を除いたものと**完全一致**させる。
- LMS / AI は `quiz/{tutorial}/{chapter}/{section}/question.md` の固定パスで取得する。

## ファイルの中身の規約

- **question.md**: 1文の記述式問題を1問だけ書く。AIが評価しやすいよう、問われている観点が明確な1文にする。**見出し行（`#`）は付けず、本文のみ**にする。
  - 例: `Laravelの「ミドルウェア」とは何か、リクエストとレスポンスの流れに触れながら、あなた自身の言葉で説明してください。`
- **model-answer.md**: 問題に対する模範解答（解答例）を書く。AI採点とコーチのフィードバックの拠り所になる。**見出し行は付けず、本文のみ**にする。

## 対象Sectionの選定方針

「概念・仕組みの理解」を自分の言葉で説明する価値があるSectionが対象です。

- **対象に含む**: 「〜とは」「〜の基礎」「設計」「考え方」など。
- **対象外**:
  - ハンズオン / 演習Section（実装課題で別途アウトプットするため）
  - インストール・環境構築などの手順Section
  - 細かい文法・SQL・実装手順のみのSection（コードで確認する方が適切なため）

## 追加手順

1. 対象Sectionのディレクトリを `curriculums/` と同じパス構成で作成する。
2. 対応する `curriculums/` のSection本文を読み、**そのSectionで実際に説明されている内容**に基づいて出題する（教材にない知識を問わない）。
3. `question.md` に1文の問題を書く（本文のみ）。
4. `model-answer.md` に模範解答を書く（本文のみ）。
