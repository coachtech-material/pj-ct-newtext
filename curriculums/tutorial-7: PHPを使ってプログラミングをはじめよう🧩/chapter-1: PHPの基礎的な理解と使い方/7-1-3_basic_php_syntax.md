# Tutorial 7-1-3: PHPの基本文法

## 🎯 このセクションで学ぶこと

*   PHPコードを記述するための基本的なルール（構文）を理解する。
*   コメントの書き方とその重要性を学ぶ。
*   画面に文字を出力するための`echo`の使い方をマスターする。
*   文の終わりを示すセミコロン（`;`）の役割を理解する。

## 導入

プログラミング言語を学ぶことは外国語を学ぶこととよく似ています。単語（関数や変数）を覚えるだけでなく、それらをどのように並べれば正しい文章（プログラム）になるのかという文法（Syntax）を理解する必要があります。

文法を間違えると、コンピュータは私たちの意図を全く理解してくれません。幸いなことに、PHPの基本的な文法は非常にシンプルで直感的です。

このセクションでは、PHPのプログラムを構成する最も基本的な3つの要素「コメント」「`echo`による出力」「セミコロン」について学んでいきましょう。これらはこれからあなたが書く全てのPHPコードの基礎となる重要なルールです。

## 詳細解説

### 🧱 PHPコードの基本構造

PHPのコードは、`<?php` という開始タグで始まり、`?>` という終了タグで終わるブロックの中に記述します。ただし、ファイルの末尾がPHPコードで終わる場合は、終了タグ `?>` は**省略することが推奨**されています。これはファイルの末尾に意図しない空白などが含まれることを防ぐためです。

```php
<?php

// ここにPHPのコードを記述します

// ファイルの最後なので、終了タグは省略します
```

### 🗣️ コメント (Comments)

コメントはプログラムの動作には一切影響を与えない**人間向けのメモ書き**です。コードが何をしているのかを説明したり、後で修正するべき箇所をメモしたりするために使用します。

複雑なコードや他人が書いたコードを理解するためにはコメントが非常に重要な手がかりとなります。良いコメントを書くことは良いコードを書くことと同じくらい大切なスキルです。

PHPでは、2種類のコメントの書き方があります。

1.  **一行コメント**: `//` から行末までがコメントになります。短い説明や一行単位のメモに適しています。

    ```php
    // これは一行コメントです。
    echo "Hello, World!"; // この行は、画面に文字を出力します。
    ```

2.  **複数行コメント**: `/*` で始まり、`*/` で終わる範囲が全てコメントになります。複数行にわたる長い説明や、一時的にコードのブロックを丸ごと無効化したい場合（コメントアウト）に便利です。

    ```php
    /*
     * これは複数行コメントです。
     * 関数の説明などを、詳しく書くときに使います。
     * @param string $name 名前
     * @return string 挨拶文
     */
    function greet($name)
    {
        return "こんにちは、" . $name . "さん！";
    }

    /*
    // 一時的に、このコードを無効にしたい
    echo "この部分は実行されません";
    */
    ```

> **💡 なぜコメントは重要か？**
> 未来の自分は、他人です。数週間後に自分の書いたコードを見返したとき、「なぜ、こんな書き方をしたんだっけ？」と頭を抱えることは日常茶飯事です。コメントは未来の自分やチームの他のメンバーへの親切な「道しるべ」なのです。

### 📺 画面への出力 (echo)

`echo`は指定した文字列や変数の内容を画面（HTML）に出力するための最も基本的な命令です。PHPでは`echo`は言語構造（language construct）と呼ばれる特別な命令であり、関数ではありませんが、最初は「画面に文字を出すための命令」と覚えておけば問題ありません。

文字列はシングルクォーテーション（`'`）またはダブルクォーテーション（`"`）で囲みます。

```php
<?php

// 文字列を直接出力
echo "Hello, PHP!";

echo '<p>HTMLタグも、そのまま出力できます。</p>';

// 数値や計算結果も出力可能
echo 123;
echo 10 + 5; // 結果の「15」が出力される
```

> **シングルクォーテーション vs ダブルクォーテーション**
> 2つの違いは、**変数展開**と**エスケープシーケンス**の扱いです。今の時点では、難しく考えず、「**基本はシングルクォーテーションを使い、変数展開が必要なときだけ、ダブルクォーテーションを使う**」と覚えておくと良いでしょう。詳細は、変数のセクションで、詳しく学びます。

### 🔚 文の終わり (Semicolon)

PHPでは原則として**各命令（文）の終わり**にセミコロン（`;`）を付ける必要があります。これはコンピュータに対して「ここで一つの命令が終わりですよ」と明確に伝えるための区切り記号です。

```php
<?php

echo "最初の文";
echo "次の文"; // セミコロンを忘れると、エラーになる！

$today = "Monday";
echo $today;
```

プログラミング初学者が最も遭遇しやすいエラーの一つがこのセミコロンの付け忘れです。エラーメッセージで`syntax error, unexpected ...` のような文法エラーを指摘された場合は、まず直前の行のセミコロンを確認する癖をつけましょう。

## ✨ まとめ

このセクションでは、PHPのプログラムを記述するための基本的な文法ルールを学びました。

*   **PHPブロック**: コードは、`<?php ... ?>` の中に記述する。ファイルの最後では、`?>` は省略する。
*   **コメント**: 人間向けのメモ。`//` で一行コメント、`/* ... */` で複数行コメント。
*   **`echo`**: 画面に文字列や変数の内容を出力する命令。
*   **セミコロン (`;`)**: 各命令の終わりに必ず付ける区切り記号。

これらのルールは非常にシンプルですが、PHPプログラミングの根幹をなすものです。特に、コメントを書く習慣とセミコロンを忘れない意識は今のうちからしっかりと身につけておきましょう。
