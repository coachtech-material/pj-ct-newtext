# 7-3-1: クラスとインスタンスの基礎

## 🎯 このセクションで学ぶこと

*   オブジェクト指向プログラミング（OOP）の基本的な考え方を理解する。
*   クラスとは何か（設計図）、インスタンスとは何か（実体）を、比喩を使って理解する。
*   PHPで`class`キーワードを使ってクラスを定義する方法を学ぶ。
*   `new`キーワードを使ってクラスからインスタンスを生成する方法を学ぶ。

---

## 導入

これまではデータ（変数）と処理（関数）を別々に扱ってきました。しかし、プログラムが複雑になってくると、「このデータとこの処理は密接に関連しているのに、なぜバラバラに管理しなければならないのだろう？」という疑問が湧いてきます。

例えば「ユーザー」という概念を考えてみましょう。「ユーザー」には名前や年齢といった**データ**があります。そして、「自己紹介する」という処理（振る舞い）があります。これらは明らかに一つのまとまりとして扱えると便利そうです。

この「**データとそれを操作する処理を一つのまとまり（オブジェクト）としてカプセル化する**」という考え方が、**オブジェクト指向プログラミング (Object-Oriented Programming, OOP)** の基本的なアイデアです。OOPは大規模で複雑なソフトウェアを整理整頓し、見通し良く開発するための強力な設計思想です。

このチャプターでは、Laravelを使いこなす上で最低限必要なOOPのエッセンスである「クラス」と「インスタンス」について学んでいきます。

---

## 詳細解説

### 🏛️ クラスとインスタンス: 設計図と実体

オブジェクト指向の最も中核となる概念が**クラス (Class)** と**インスタンス (Instance)** です。この2つの関係はよく**「たい焼きの型」と「たい焼き」**に例えられます。

*   **クラス (Class)**: **設計図**や**型**に相当します。たい焼きの例で言えば「たい焼きの型」そのものです。クラスは「たい焼きはあんこを持っていて、頭から食べられる」といった共通の性質（データ）と振る舞い（処理）を定義します。クラス自体はまだ具体的なたい焼きではなく、あくまで設計情報です。

*   **インスタンス (Instance)**: **設計図から作られた実体**です。たい焼きの例で言えば「たい焼きの型から作られた個々のたい焼き」です。インスタンスはクラスという設計図に基づいて作られますが、それぞれが独立した存在です。例えば、あるたい焼きはつぶあん、別のたい焼きはこしあんといったように、個別の状態を持つことができます。

オブジェクト指向プログラミングでは、まず**クラスという設計図を定義**し、次にその**クラスからインスタンス（オブジェクトとも呼ばれる）を生成して利用する**という手順でプログラムを構築していきます。

### ✍️ クラスの定義

PHPでクラスを定義するには`class`キーワードを使います。クラス名の最初の文字は大文字にするのが慣習です（アッパーキャメルケース）。

```php
// Userという名前のクラスを定義する
class User
{
    // この中に、プロパティ（データ）と、メソッド（処理）を定義していく
}
```

この時点ではクラスはまだ空っぽの設計図です。中身は次のセクションで定義していきます。

### 🆕 インスタンスの生成

クラスからインスタンスを生成するには`new`キーワードを使います。

```php
// Userクラスの設計図から、2つのインスタンス（実体）を生成する
$user1 = new User();
$user2 = new User();

// var_dump()で、インスタンスの中身を見てみる
var_dump($user1);
// object(User)#1 (0) {}

var_dump($user2);
// object(User)#2 (0) {}
```

*   `$user1 = new User();` というコードは「`User`クラスの新しいインスタンスを生成し、それを変数`$user1`に代入せよ」という意味です。
*   `var_dump()`の結果を見ると、`$user1`と`$user2`はどちらも`User`クラスのオブジェクト（インスタンス）ですが、`#1`と`#2`のように別々の実体として認識されていることがわかります。

これで`User`という概念をプログラムの世界に持ち込むことができました。しかし、まだこのユーザーは名前もなければ何もできません。次のセクションではこの`User`クラスに具体的なデータ（プロパティ）と処理（メソッド）を追加していきます。

## ✨ まとめ

このセクションでは、オブジェクト指向プログラミングの入り口であるクラスとインスタンスについて学びました。

*   **オブジェクト指向 (OOP)**: データとそれを操作する処理を一つのまとまり（オブジェクト）として扱うプログラミングの考え方。
*   **クラス (Class)**: オブジェクトの**設計図**。共通の性質と振る舞いを定義する。
*   **インスタンス (Instance)**: クラスから作られた**実体**。オブジェクトとも呼ばれる。
*   **クラスの定義**: `class クラス名 { ... }` の形式で定義する。
*   **インスタンスの生成**: `new クラス名()` の形式で生成する。

「クラスは設計図、インスタンスは実体」というこの関係性をしっかりとイメージできるようになることが、オブジェクト指向を理解するための第一歩です。Laravelの内部では数多くのクラスが定義されており、私たちはそれらのクラスからインスタンスを生成し、利用することでアプリケーションを構築していくことになります。
