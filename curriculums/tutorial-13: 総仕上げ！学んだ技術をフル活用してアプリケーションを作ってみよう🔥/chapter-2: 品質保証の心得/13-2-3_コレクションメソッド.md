## 🧠 先輩エンジニアの思考プロセス

### 「なぜ命名の次にコレクションメソッドなのか？」

命名規則を学んだら、次は**コレクションメソッド**でコードを簡潔にします。

### 理由1: foreachは長くなりがち

```php
// ❌ foreachで書くと長い
$highPriorityTitles = [];
foreach ($tasks as $task) {
    if ($task->priority === 3) {
        $highPriorityTitles[] = $task->title;
    }
}

// ✅ コレクションメソッドで1行
$highPriorityTitles = $tasks->filter(fn($t) => $t->priority === 3)->pluck('title');
```

### 理由2: メソッドチェーンの練習

コレクションメソッドはメソッドチェーンの宝庫です。`->`の理解が深まります。

### 理由3: 宣言的なコード

コレクションメソッドを使うと、「何をしたいか」が明確になります。

```php
// ❌ 手続き的（どうやるかを書いている）
$result = [];
foreach ($tasks as $task) {
    if ($task->priority === 3) {
        $result[] = $task;
    }
}

// ✅ 宣言的（何をしたいかを書いている）
$result = $tasks->filter(fn($t) => $t->priority === 3);
```

## コレクションとは

### コレクションの取得

Eloquentでデータを取得すると、**Collection**オブジェクトが返されます。

```php
$tasks = Task::all();  // Illuminate\Database\Eloquent\Collection

$tasks = Task::where('priority', 3)->get();  // Collection
```

### 配列との違い

| 配列 | コレクション |
|:---|:---|
| PHPの組み込み機能 | Laravelのクラス |
| `array_map`, `array_filter`など | `map`, `filter`などのメソッド |
| メソッドチェーン不可 | メソッドチェーン可能 |

```php
// 配列の場合（メソッドチェーン不可）
$filtered = array_filter($tasks, fn($t) => $t->priority === 3);
$titles = array_map(fn($t) => $t->title, $filtered);

// コレクションの場合（メソッドチェーン可能）
$titles = $tasks->filter(fn($t) => $t->priority === 3)->pluck('title');
```

## よく使うコレクションメソッド

### map（各要素を変換）

```php
// タスクタイトルの一覧を取得
$titles = $tasks->map(function ($task) {
    return $task->title;
});

// アロー関数で短く書く
$titles = $tasks->map(fn($task) => $task->title);

// pluckでさらに短く
$titles = $tasks->pluck('title');
```

### filter（条件で絞り込み）

```php
// 優先度「高」のタスクのみ
$highPriorityTasks = $tasks->filter(function ($task) {
    return $task->priority === 3;
});

// アロー関数で短く
$highPriorityTasks = $tasks->filter(fn($task) => $task->priority === 3);
```

### sortBy / sortByDesc（並び替え）

```php
// 優先度の高い順
$sortedTasks = $tasks->sortByDesc('priority');

// タイトルのアルファベット順
$sortedTasks = $tasks->sortBy('title');

// 作成日の新しい順
$sortedTasks = $tasks->sortByDesc('created_at');
```

### groupBy（グループ化）

```php
// カテゴリごとにグループ化
$groupedTasks = $tasks->groupBy('category_id');

// カテゴリ名でグループ化
$groupedTasks = $tasks->groupBy(fn($task) => $task->category?->name ?? '未分類');

// 優先度でグループ化
$groupedTasks = $tasks->groupBy('priority');
```

### sum / avg / count（集計）

```php
// 優先度の合計
$totalPriority = $tasks->sum('priority');

// 優先度の平均
$averagePriority = $tasks->avg('priority');

// タスク数
$taskCount = $tasks->count();
```

### pluck（特定のカラムのみ取得）

```php
// タイトルのみ取得
$titles = $tasks->pluck('title');

// IDをキーにしてタイトルを取得
$titlesById = $tasks->pluck('title', 'id');
// 結果: [1 => 'タスク1', 2 => 'タスク2', ...]
```

### first / last（最初・最後の要素）

```php
// 最初のタスク
$firstTask = $tasks->first();

// 条件に合う最初のタスク
$highPriorityTask = $tasks->first(fn($t) => $t->priority === 3);

// 最後のタスク
$lastTask = $tasks->last();
```

### isEmpty / isNotEmpty（空チェック）

```php
// 空かどうかチェック
if ($tasks->isEmpty()) {
    // タスクがない場合の処理
}

if ($tasks->isNotEmpty()) {
    // タスクがある場合の処理
}
```

## メソッドチェーン

### 複数のメソッドを連結

```php
// 優先度「高」のタスクを、作成日の新しい順に並べ、タイトルのみ取得
$titles = $tasks
    ->filter(fn($task) => $task->priority === 3)
    ->sortByDesc('created_at')
    ->pluck('title');
```

### コードリーディング

| 部分 | 説明 | 戻り値 |
|:---|:---|:---|
| `$tasks` | タスクのCollection | Collection |
| `->filter(...)` | 優先度「高」に絞り込み | Collection |
| `->sortByDesc('created_at')` | 作成日の新しい順にソート | Collection |
| `->pluck('title')` | タイトルのみ取得 | Collection |

> 💡 **ポイント**: 各メソッドがCollectionを返すので、連続してメソッドを呼び出せます。

### foreachとの比較

**Before（foreach）**:

```php
$highPriorityTitles = [];
foreach ($tasks as $task) {
    if ($task->priority === 3) {
        $highPriorityTitles[] = $task->title;
    }
}
usort($highPriorityTitles, fn($a, $b) => $b <=> $a);
```

**After（コレクションメソッド）**:

```php
$highPriorityTitles = $tasks
    ->filter(fn($task) => $task->priority === 3)
    ->sortByDesc('created_at')
    ->pluck('title');
```

## 実践例

### カテゴリ別のタスク数を表示

```php
// コントローラー
public function index()
{
    $tasks = auth()->user()->tasks()->with('category')->get();
    
    // カテゴリ別のタスク数
    $categoryStats = $tasks
        ->groupBy(fn($task) => $task->category?->name ?? '未分類')
        ->map(fn($tasks) => $tasks->count());
    
    return view('tasks.index', compact('tasks', 'categoryStats'));
}
```

```blade
{{-- ビュー --}}
<h3>カテゴリ別タスク数</h3>
<ul>
    @foreach ($categoryStats as $category => $count)
        <li>{{ $category }}: {{ $count }}件</li>
    @endforeach
</ul>
```

### 優先度別のタスク数を表示

```php
// 優先度別のタスク数
$priorityStats = $tasks->groupBy('priority')->map(fn($tasks) => $tasks->count());

// 優先度ラベルに変換
$priorityLabels = [1 => '低', 2 => '中', 3 => '高'];
$priorityStatsWithLabels = $priorityStats->mapWithKeys(
    fn($count, $priority) => [$priorityLabels[$priority] => $count]
);
```

### 完了率を計算

```php
$totalCount = $tasks->count();
$completedCount = $tasks->filter(fn($t) => $t->is_completed)->count();
$completionRate = $totalCount > 0 ? round($completedCount / $totalCount * 100, 1) : 0;
```

## コレクションメソッド一覧

| メソッド | 用途 | 例 |
|:---|:---|:---|
| `map` | 各要素を変換 | `$tasks->map(fn($t) => $t->title)` |
| `filter` | 条件で絞り込み | `$tasks->filter(fn($t) => $t->priority === 3)` |
| `sortBy` | 昇順で並び替え | `$tasks->sortBy('title')` |
| `sortByDesc` | 降順で並び替え | `$tasks->sortByDesc('priority')` |
| `groupBy` | グループ化 | `$tasks->groupBy('category_id')` |
| `sum` | 合計 | `$tasks->sum('priority')` |
| `avg` | 平均 | `$tasks->avg('priority')` |
| `count` | 件数 | `$tasks->count()` |
| `pluck` | 特定のカラムのみ取得 | `$tasks->pluck('title')` |
| `first` | 最初の要素 | `$tasks->first()` |
| `last` | 最後の要素 | `$tasks->last()` |
| `isEmpty` | 空かどうか | `$tasks->isEmpty()` |
| `isNotEmpty` | 空でないかどうか | `$tasks->isNotEmpty()` |

## 🚨 よくある間違い

### 間違い1: getを忘れる

```php
// ❌ getを忘れている（クエリビルダのまま）
$tasks = Task::where('priority', 3);
$tasks->filter(...);  // エラー！

// ✅ getでコレクションに変換
$tasks = Task::where('priority', 3)->get();
$tasks->filter(...);  // OK
```

### 間違い2: 配列とコレクションを混同

```php
// ❌ 配列に対してコレクションメソッドを使おうとする
$array = [1, 2, 3];
$array->filter(...);  // エラー！

// ✅ collectでコレクションに変換
$collection = collect([1, 2, 3]);
$collection->filter(...);  // OK
```

### 間違い3: 元のコレクションが変更されると思い込む

```php
// ❌ 元のコレクションは変更されない
$tasks->filter(fn($t) => $t->priority === 3);
// $tasksは変更されていない！

// ✅ 結果を変数に代入する
$highPriorityTasks = $tasks->filter(fn($t) => $t->priority === 3);
```

このセクションでは、コレクションメソッドについて学びました。
