# 14-1-7: コラム: Claude Code早見表【基本編】

## 🎯 このセクションで学ぶこと

- やりたい操作から、対応するコマンドやキーを引けるようになる。
- 定額の中で使えるものと、追加課金になるものを見分けられるようになる。
- ここに載っていないものを、`/help` と公式ドキュメントで探せるようになる。

---

## 導入

Claude Codeのコマンドとキー操作は数が多く、順番に覚えて進むものではありません。この節は、手が止まったときに引くための表です。ここに並ぶものは、それぞれ使う場面で改めて出てくるので、いまは目次として眺めるだけで構いません。

以下はすべて2026年8月時点のものです。表示や名前が違うときは、入力欄で `/` を打って出る候補と、公式ドキュメントのコマンドリファレンスが正です。

---

## スラッシュコマンド

入力欄の先頭で `/` を打つと候補が出ます。ここに載せたのは、この教材で使うものだけです。「扱う節」が「参考」の行は、教材の手順には出てきません。名前だけ知っておくと、必要になったときに引けます。

**前提を整える**

| コマンド | 何をするか | 扱う節 |
|:--|:--|:--|
| `/help` | 使えるコマンドの一覧を出す | 14-1-2 |
| `/init` | プロジェクトに `CLAUDE.md` の叩き台を作る | 14-1-3 |
| `/memory` | `CLAUDE.md` を編集する | Tutorial 15 |
| `/permissions` | allow・ask・denyの規則を対話画面で管理する | 参考 |

**会話を扱う**

| コマンド | 何をするか | 扱う節 |
|:--|:--|:--|
| `/context` | いま何がコンテキストを埋めているかを、色分けの表で見る | 14-5-2 |
| `/clear` | コンテキストを空にして、新しい会話を始める | 14-5-2 |
| `/compact` | それまでの会話を要約して、コンテキストを空ける | 14-5-2 |
| `/resume` | 会話をIDか名前で再開する（別名 `/continue`） | 14-5-2 |
| `/rename` | いまのセッションに名前を付ける | 14-5-2 |
| `/branch` | いまの会話をその地点で枝分かれさせる。元の会話は残る | 参考 |
| `/exit` | 終える（別名 `/quit`） | 14-1-2 |

**作ったものを見る・戻す**

| コマンド | 何をするか | 扱う節 |
|:--|:--|:--|
| `/diff` | まだコミットしていない変更と、やり取り単位の差分を対話画面で見る | 参考 |
| `/code-review` | いまの差分（または渡したPR・ブランチ・パス）を、間違いと整理の観点で見る | 14-4-2 |
| `/security-review` | いまのブランチの変更を、セキュリティの観点で見る | 14-4-2 |
| `/rewind` | 会話とコードを前の地点へ戻す（別名 `/checkpoint`・`/undo`） | 14-5-1 |

**動かし方を変える**

| コマンド | 何をするか | 扱う節 |
|:--|:--|:--|
| `/plan` | planモードに入る | 14-3-2 |
| `/model` | モデルを切り替える | 14-1-6 |
| `/effort` | エフォート（考える深さ）を設定する | 14-1-6 |
| `/usage` | セッションの費用・プランの使用枠・活動の統計を見る（別名 `/cost`・`/stats`） | 14-1-6 |
| `/mcp` | MCPサーバーの接続を管理する | 14-4-4 |
| `/status` | 版・モデル・アカウント・接続状態を見る | 参考 |
| `/login` `/logout` | サインイン・サインアウト | 参考 |

自分用のコマンドを足すこともできます。作り方はSkill（繰り返す手順に名前を付けて、呼び出せるようにしたもの）として用意する形になります。Tutorial 15で扱うので、ここでは名前だけ知っておいてください。

## 💰 追加課金になるもの

| コマンド | 中身 |
|:--|:--|
| `/fast` | 応答を速くする切り替え。サブスクリプションの枠には含まれず、usage credits（追加で購入する枠）から支払います |
| `/code-review ultra` | クラウドで動く、多数のエージェントによる深いレビュー |
| `/model fable` | プランによっては usage credits から支払う扱いになります。そのときは選択画面の行に「Requires usage credits」と出ます |

どれも定額の外です。**この教材の演習では使いません。**

モデルの選び方とエフォートの段階は、14-1-6にまとめてあります。

## ターミナルから起動するときのフラグ

`claude` の後ろに付けて、起動のしかたを変えるものです。

| フラグ | 何をするか |
|:--|:--|
| `-c, --continue` | いまのフォルダで、最後の会話の続きから始める |
| `-r, --resume [値]` | セッションIDを指定して再開する。値なしで選択画面が開く |
| `--from-pr [値]` | PRの番号やURLに紐づいたセッションを再開する。値なしで選択画面が開く |
| `-n, --name <名前>` | このセッションに表示名を付ける |
| `-w, --worktree [名前]` | このセッション用にgit worktree（同じリポジトリを別のフォルダにもう1つ展開したもの）を作る |
| `-p, --print` | 応答を出力して終了する（パイプでつなぐとき向け） |

全部の一覧は `claude --help` で出ます。

## ショートカット

公式ドキュメントのキーボードショートカット一覧からの抜粋です。端末によって効かないものがあります。

| やりたいこと | キー |
|:--|:--|
| 途中で止める／ダイアログを閉じる | `Esc` |
| 入力の下書きを消す／巻き戻す | `Esc` を2回 |
| 権限モードを切り替える | `Shift+Tab`（Windowsの一部の環境では `Alt+M`） |
| 終える | `Ctrl+D` |
| 割り込む／入力を消す | `Ctrl+C` |
| 入力欄の中身を、いつものエディタで開く | `Ctrl+G`（`Ctrl+X Ctrl+E` も同じ） |
| やり取りの記録を開く・閉じる | `Ctrl+O` |
| 履歴をさかのぼって検索する | `Ctrl+R` |
| クリップボードの画像を貼る（14-2-3で使います） | `Ctrl+V`（iTerm2は `Cmd+V`、WindowsとWSLは `Alt+V`） |
| 改行する | `\` を打ってから `Enter`（どの端末でも動く）。`Shift+Enter` や `Ctrl+J` も使える |

入力欄の先頭に打つ記号にも意味があります。

| 記号 | 意味 |
|:--|:--|
| `/` | コマンドかSkill |
| `!` | シェルのコマンドをその場で実行して、結果を会話に入れる（14-1-2で使います） |
| `@` | ファイルパスの補完（14-2-3で使います） |

## Claude Codeが動く場所

Claude Codeはターミナルの中だけのものではありません。

| 場所 | 入り口 |
|:--|:--|
| VS Codeの拡張 | `/ide` で接続の管理と状態の確認 |
| デスクトップアプリ | `/desktop`（macOSとx64のWindows。Claudeのサブスクリプションが要ります） |
| Web版・モバイルアプリ | `/mobile` でアプリのQRコード、`/web-setup` でGitHubとの接続、`/teleport` でWeb版のセッションをこの端末へ引き寄せる |
| Slack | `/install-slack-app` |
| 別の端末からの遠隔操作 | `/remote-control` |

**この教材は、ターミナルで動くCLI版に統一します。** 手順と画面をひととおり揃えるためで、慣れたら好きな場所で使って構いません。

## つまずいたときの道具

| コマンド | 何をするか |
|:--|:--|
| `/doctor` | 導入と設定の健康診断をして、直せるものは直す |
| `/bug` | 不具合を報告する。何をどこまで送るかは、同意画面で選ぶ |
| `/powerup` | 短い対話レッスンで、Claude Codeの機能を知る |

使い方が分からなくなったときは、そのままClaude Codeに聞いても構いません。「いまの会話を名前を付けて残したいんだけど、どうすればいい？」のように、やりたいことを日本語で書けば、コマンドを教えてくれます。
