# 14-1-6: モデルとエフォートと使用枠

## 🎯 このセクションで学ぶこと

- 何で考えさせるか（モデル）と、どれくらい深く考えさせるか（エフォート）の切り替え方が分かる。
- Proプランの使用枠が2本立てであることを理解し、`/usage` で残りを確かめられるようになる。
- 枠を使い切ったときに何が起きて、どう再開するのかが分かる。

---

## 導入

14-1-5までで、Claude Codeがどこまで確認なしに動くかは決まりました。ここで見るのは、その動き方そのものを決めている設定のほうです。

14-1-4で1本まるごと作らせたとき、画面が流れ続けるあいだ、AIは何度も考えて、何度も手を動かしていました。あれだけ動けば、契約に含まれる枠も減ります。使い続けていると、しばらく依頼を受け付けなくなることがあり、それが枠を使い切った状態です。この節では、枠の見方と、減り方を決めている2つの設定を扱います。

以下はすべて2026年8月時点のものです。表示や名前が違うときは、`/help` と公式ドキュメントが正です。

---

## モデル

Claude Codeが依頼を受けて考えるとき、その中身を担っているのがClaudeのモデルです。モデルは1種類ではありません。賢さ・速さ・枠の減り方の釣り合いが違うものが何種類か用意されていて、切り替えられます。

呼び出すのは `/model` です。引数なしで打つと選ぶ画面が開き、`/model sonnet` のように名前を直接指定することもできます。

モデルには短い呼び名が付いていて、これを指定すると、そのときの最新版が選ばれます。バージョン番号を覚えなくて済みます。

| 呼び名 | どういう用事のためのものか |
|:--|:--|
| `haiku` | 速くて軽い。単純な用事向け |
| `sonnet` | 日々のコーディング向け |
| `opus` | 込み入った判断が要るとき向け |
| `fable` | いちばん能力が高い。1回では終わらない長い仕事向け |
| `opusplan` | 計画のあいだは `opus`、実行に移ると `sonnet` に切り替わる |

選択画面に何が並ぶかは、契約しているプランによって変わります。**画面に出ているものが、いまのアカウントで選べるものです。**

選ぶときのキーが2つあります。`Enter` で選ぶと、そのモデルが**次からの既定**として保存されます。`s` で選ぶと、そのセッションのあいだだけ切り替わります。`/model sonnet` のように名前を直接打った場合は、`Enter` と同じ扱いです。

> ⚠️ **注意**: `fable` は、プランによっては定額の枠ではなく、追加で購入する枠（usage credits）から支払う扱いになります。その場合は、選択画面のその行に「Requires usage credits」と表示されます。**この教材の演習では使いません。**

**この教材は、既定のモデルのままで最後まで進められます。** 切り替えを考えるのは、枠の減りが早いと感じたときと、同じところで何度もうまく作れないときの2つで足ります。

## エフォート

同じモデルでも、どれくらい深く考えさせるかを変えられます。これが**エフォート**です。深く考えさせるほど答えの質は上がりやすく、そのぶん時間がかかり、枠も多く減ります。

段階は次のとおりです。どれが使えるかはモデルによります。

| 段階 | どういうときに使うか |
|:--|:--|
| `low` | 短くて範囲が決まっていて、賢さより速さが欲しい用事 |
| `medium` | 多少の賢さと引き換えに、枠の減りを抑えたいとき |
| `high` | **既定**。枠の減りと賢さの釣り合いが取れている |
| `xhigh` | もっと深く考えさせたいとき。そのぶん多く使う |
| `max` | 難しい用事で伸びることがある。ただし頭打ちも、考えすぎも起きる |
| `ultracode` | Claude Code側の設定。`xhigh` で考えさせたうえで、まとまった用事のたびに段取りを組ませる |

`low` から `xhigh` までは、一度決めるとセッションをまたいで残ります。`max` と `ultracode` が効くのは、**そのセッションのあいだだけ**です。

変えるときは `/effort` です。引数なしで打つとスライダーが出て、`/effort low` のように段階を直接指定することもできます。`/effort auto` と打つと、そのモデルの既定に戻ります。`/model` の選択画面の中でも、左右キーで同じスライダーが動きます。

いまどの段階で動いているかは、画面の上のモデル名の隣に出ています。

> ⚠️ **注意**: 段階の目盛りはモデルごとに引かれていて、`high` が指す深さはモデルによって違います。「`high` ならこれくらい」と量で覚えないでください。

エフォートも、この教材は既定のままで進められます。

## 使用枠

Proプランには、使える量の上限があります。上限は2本立てです。

| 枠 | 戻り方 |
|:--|:--|
| セッションの枠 | 5時間ごとに戻る |
| 週の枠 | 週に1回、決まった曜日・時刻に戻る |

週の枠が戻る曜日と時刻は、アカウントごとに決まっています。いつ使い始めても、いつ契約しても変わりません。

この枠は、Claude Code専用ではありません。**ブラウザのClaudeで会話した分も、同じ枠から減ります。**

減り方は一定ではありません。依頼の長さ、渡したファイルの量、そこまでの会話の長さ、どのモデルで動いているかで変わります。「1日に何回使える」という数え方はできないので、残りは画面で確かめます。

### 使い切ると、こうなります

枠を使い切ると、その旨と**いつ戻るか**が表示されて、依頼を受け付けなくなります。

このとき、`/model` で軽いモデルに切り替えても回復しません。セッションの枠と週の枠は、どのモデルを使っていても共通だからです。ただし、重いモデルには**そのモデルだけの枠**が別にあることがあり、そちらに当たった場合は、軽いモデルへ切り替えれば作業を続けられます。どちらなのかは表示に書かれています。

長い作業の途中でこうなったときは、そこまでの変更をコミットしてから、表示された時刻を過ぎるのを待って再開してください。

### 長く開けたままだと、早く減る

同じ量の作業でも、1つのやり取りを長く続けると枠の減りは早くなります。Claude Codeは依頼のたびに、**そこまでの会話をまるごと**送り直しているためです。半日開けたままのやり取りに1行だけ質問すると、その1行ぶんではなく、半日ぶんの会話に対して枠が減ります。

やり取りの区切り方と、いま何がコンテキストを埋めているのかの見方は、14-5-2で扱います。

## 🏃 いまの設定を見る

3つとも打つだけで、この節では何も変えません。いまどうなっているかを一度見ておきます。

ターミナルで投稿アプリのフォルダ（14-1-3でCLAUDE.mdを作ったフォルダ）へ移動して、Claude Codeを起動します。

```bash
# 投稿アプリのフォルダで実行する
claude
```

### Step 1: いま何で動いているかを見る

```text
/model
```

選択画面が開きます。いま選ばれているものに印が付いていて、左右キーを押すとエフォートのスライダーが動きます。**ここでは変えずに、`Esc` で閉じてください。**

**`/model` の選択画面**

<img alt="14-1-6_1.png" src="">

### Step 2: エフォートを単体で見る

```text
/effort
```

段階の並んだスライダーが出て、いまの段階に印が付いています。これも `Esc` で閉じます。

**`/effort` のスライダー**

<img alt="14-1-6_2.png" src="">

### Step 3: 枠の残りを見る

```text
/usage
```

**`/usage` の画面**

<img alt="14-1-6_3.png" src="">

画面のいちばん上に出るトークンの数と金額は、APIを直接使う人向けの数字で、Proプランの請求には関係しません。見るのはその下の、プランの枠のバーです。内訳は `d` と `w` で、直近24時間と直近7日を切り替えられます。

内訳の数字は、このパソコンに残っているやり取りから計算した概算で、ほかの端末で使った分は入りません。プランの枠のバーのほうは、アカウント全体の使用量を反映します。

見終わったら `/exit` でClaude Codeを閉じます。

ここまでで、次を確かめてください。

- [ ] `/model` で、いま選ばれているモデルが分かった
- [ ] `/effort` で、いまの段階が分かった
- [ ] `/usage` で、プランの枠の残りが分かった

作業に入る前と、大きな依頼を投げる前に `/usage` を一度見る癖をつけておくと、途中で止まる場面を減らせます。

## ✨ まとめ

- `/model` で何に考えさせるかを、`/effort` でどれくらい深く考えさせるかを変える。どちらも既定のままでこの教材は進む。
- `/model` は `Enter` で次からの既定として保存、`s` でそのセッション限り。エフォートは `max` と `ultracode` だけがセッション限り。
- Proプランの枠は、5時間ごとに戻るものと、週に1回戻るものの2本。ブラウザのClaudeと共通。
- `/usage` で見るのはプランの枠のバー。上に出る金額はAPIを直接使う人向けの数字。
- 使い切ると、いつ戻るかが表示される。モデルを軽くしても、セッションの枠と週の枠は戻らない。作業の途中ならコミットしてから待つ。
- 1つのやり取りを長く続けるほど、1回あたりの減りは大きくなる。
