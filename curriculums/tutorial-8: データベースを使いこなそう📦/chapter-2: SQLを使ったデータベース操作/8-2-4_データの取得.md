# 8-2-4: データの取得（SELECT）

## 🎯 このセクションで学ぶこと

*   `SELECT` 文を使って、テーブルからデータを取得できるようになる。
*   特定のカラムだけを選択して取得する方法を理解する。
*   `*`（アスタリスク）を使って全てのカラムを取得する方法を理解する。
*   `AS` を使ってカラムに別名をつける方法を知る。
*   phpMyAdminのGUI操作が内部的に`SELECT` 文を実行していることを理解する。

---

## 導入

これまでに、データベースとテーブルを作成し (`CREATE`)、データを挿入しました (`INSERT`)。しかし、データベースの最も重要な役割は、蓄積した膨大なデータの中から**必要な情報を必要な時に取り出す**ことです。そのための主役となるのが、DQL（データ問い合わせ言語）の **`SELECT`** 文です。

`SELECT` 文は、SQLの中で最もよく使われ、そして最も奥が深いコマンドです。Webアプリケーションが画面に何かを表示する時、その裏側ではほぼ間違いなく`SELECT` 文が実行されています。

このセクションでは、`SELECT` 文の最も基本的な使い方をマスターし、テーブルに格納した情報を自在に取り出す第一歩を踏み出します。

---

## 詳細解説

### 🔍 全てのデータを取得する (`SELECT * FROM ...`)

まず、テーブルに入っている全てのレコードの全てのカラムを取得する、最もシンプルな`SELECT` 文を見てみましょう。

**phpMyAdminでの実行手順**

1.  phpMyAdminで、`practice_db` データベースを選択します。
2.  「SQL」タブをクリックします。
3.  以下のSQL文を実行します。

```sql
SELECT * FROM users;
```

*   `SELECT *`: 全てのカラムを選択します。`*` は「全て」を意味するワイルドカードです。
*   `FROM users`: `users` テーブルからデータを取得します。

このSQL文をphpMyAdminで実行すると、前のセクションで`INSERT` したユーザーの情報が一覧で表示されます。実は、phpMyAdminで「表示」タブをクリックした時に内部的に実行されているのが、この`SELECT * FROM users;` なのです。

<img alt="8-2-4_1.png" src="https://s3.ap-northeast-1.amazonaws.com/coachtech-lms-bucket-dev/curriculums/images/8-2-4_1.png">

### 📌 特定のカラムだけを取得する

全てのカラムが常に必要とは限りません。例えば、ユーザーの名前とメールアドレスの一覧だけが欲しい場合もあります。そのような時は、`*` の代わりに取得したいカラム名をカンマで区切って指定します。

```sql
SELECT name, email FROM users;
```

このSQL文を実行すると、`id` や `password`, `created_at` は含まれず、`name` と `email` の2つのカラムだけが結果として返されます。

<img alt="8-2-4_2.png" src="https://s3.ap-northeast-1.amazonaws.com/coachtech-lms-bucket-dev/curriculums/images/8-2-4_2.png">

このように、必要なデータだけを取得することは、**パフォーマンスの観点からも非常に重要**です。不要なデータを取得しないことで、データベースへの負荷を減らし、アプリケーションの応答速度を向上させることができます。

### 🏷️ カラムに別名をつける (`AS`)

取得したカラム名がそのままだと分かりにくい場合や、他のテーブルのカラムと名前が重複してしまう場合に、`AS` を使って別名をつけることができます。

```sql
SELECT
    name AS user_name,
    email AS user_email,
    created_at AS registration_date
FROM
    users;
```

*   `name AS user_name`: `name` カラムを`user_name` という名前で取得します。
*   `email AS user_email`: `email` カラムを`user_email` という名前で取得します。
*   `created_at AS registration_date`: `created_at` カラムを`registration_date` という名前で取得します。

このSQL文を実行すると、結果のヘッダー部分が`name` や `email` ではなく、`user_name` や `user_email` に変わっていることが確認できます。

<img alt="8-2-4_3.png" src="https://s3.ap-northeast-1.amazonaws.com/coachtech-lms-bucket-dev/curriculums/images/8-2-4_3.png">

`AS` は省略することも可能ですが、可読性のために明記することが推奨されます。

```sql
-- ASを省略した書き方
SELECT name user_name, email user_email FROM users;
```

### ⚙️ phpMyAdminでの操作との関連

phpMyAdminのGUI操作と`SELECT` 文の関係を改めて整理しておきましょう。

*   **「表示」タブをクリック**: `SELECT * FROM table_name;` が実行される。
*   **テーブル名をクリック**: `SELECT * FROM table_name;` が実行される。
*   **カラムのヘッダーをクリックしてソート**: `SELECT * FROM table_name ORDER BY column_name;` のようなSQLが実行される。（`ORDER BY` は後のセクションで学びます）

このように、GUIでの便利な操作も、裏側ではSQL文が組み立てられ、実行されています。このことを意識するだけで、phpMyAdminが単なるツールから、強力なSQL学習支援ツールへと変わります。

## ✨ まとめ

このセクションでは、データベースからデータを取り出すための`SELECT` 文の基本を学びました。

*   テーブルからデータを取得するには、`SELECT ... FROM ...` 文を使う。
*   全てのカラムを取得するには、`*`（アスタリスク）を使う。
*   特定のカラムだけを取得するには、カラム名をカンマで区切って指定する。これはパフォーマンス上重要である。
*   `AS` を使うことで、取得するカラムに分かりやすい別名をつけることができる。
*   phpMyAdminのデータ表示機能は、内部的に`SELECT` 文を実行している。

`SELECT` 文は、これから学ぶ`WHERE`（条件指定）、`JOIN`（テーブル結合）、`GROUP BY`（集計）といった句と組み合わせることで、その真価を発揮します。
