## 導入：「読めそうで読めない」コードの正体

Laravelのコードを読んでいると、以下のような構文に出会うことがあります。

```php
// 9-3-6 ファクトリーで見たコード
return $this->state(fn (array $attributes) => [
    'is_published' => true,
    'published_at' => now(),
]);
```

```php
// 9-3-7 トランザクションで見たコード
DB::transaction(function () use ($validated) {
    $user = User::create([...]);
    Profile::create(['user_id' => $user->id]);
});
```

初学者には「なんとなく意味はわかるけど、構文がよくわからない」と感じるかもしれません。

このコラムでは、Laravelでよく見る4つの構文を整理し、**「慣れる」**ことを目指します。

| 構文 | どこで出てきた？ |
|:---|:---|
| 静的メソッド（`::`）とインスタンスメソッド（`->`） | 全体 |
| メソッドチェーン | 9-3-6 ファクトリー |
| 無名関数（クロージャ）と `use` | 9-3-7 トランザクション |
| アロー関数（`fn`） | 9-3-6 ファクトリー |

> 💡 **このコラムの使い方**
>
> 今すぐ全て覚える必要はありません。
> 「こういう構文があるんだ」と認識し、実際のコードで出会ったときに戻ってきてください。

## 🎯 静的メソッド（`::`）とインスタンスメソッド（`->`）

Laravelのコードでは、`::`と`->`の2種類の演算子が頻繁に登場します。

```php
User::find(1);      // :: を使用
$user->save();      // -> を使用
```

### ざっくり理解

| 演算子 | 読み方 | 対象 |
|:---:|:---|:---|
| `::` | 「**クラスに対して**」 | クラス自体（静的メソッド） |
| `->` | 「**この○○に対して**」 | インスタンス（実体） |

### 🗣️ 日本語で読み解くと

```php
User::find(1);
```
→ 「**Userクラスに対して**、ID=1を探しなさい」

```php
$user->save();
```
→ 「**この$userに対して**、保存しなさい」

> 💡 **詳しくは 9-4-1 で解説**
>
> `::`と`->`の違いは、次のChapter（9-4-1「Eloquent ORMとは」）で詳しく解説します。
> ここでは「2種類の演算子がある」ことを認識しておけばOKです。

## 🔗 メソッドチェーン

### メソッドチェーンとは

**メソッドチェーン**とは、`->`で複数のメソッドを繋げて呼び出す書き方です。

```php
// 9-3-6 で見たコード
Post::factory()->count(10)->published()->create();
```

### なぜ繋げられるのか？

各メソッドが「次のメソッドを呼び出せるオブジェクト」を返しているからです。

```
Post::factory()  →  ファクトリーインスタンスを返す
     ↓
->count(10)      →  ファクトリーインスタンスを返す
     ↓
->published()    →  ファクトリーインスタンスを返す
     ↓
->create()       →  作成されたモデルを返す
```

### 🗣️ 処理の流れを日本語にすると

```php
Post::factory()->count(10)->published()->create();
```

1. **Postクラスに対して**、ファクトリーを取得しなさい
2. **そのファクトリーに対して**、10件分の設定をしなさい
3. **その設定に対して**、「公開済み」の状態を適用しなさい
4. **その状態で**、実際にデータベースに作成しなさい

### 💡 比喩：「加工ライン」のイメージ

メソッドチェーンは、工場の**加工ライン**に似ています。

```
[材料] → [加工1] → [加工2] → [加工3] → [完成品]

Post::factory() → count(10) → published() → create() → 10件のPost
```

データという「材料」を、メソッドという「加工機」に次々と通して、最終的な「完成品」を得るイメージです。

## 📦 無名関数（クロージャ）と `use`

### 無名関数とは

**無名関数（クロージャ）**とは、名前を持たない関数のことです。変数に代入したり、他の関数の引数として渡したりできます。

```php
// 通常の関数
function greet($name) {
    return "Hello, {$name}!";
}

// 無名関数
$greet = function ($name) {
    return "Hello, {$name}!";
};
```

### Laravelでの使用例（9-3-7 トランザクション）

```php
DB::transaction(function () {
    $user = User::create([...]);
    Profile::create(['user_id' => $user->id]);
});
```

`DB::transaction()`は、引数として「実行したい処理」を受け取ります。その「処理」を無名関数として渡しています。

### `use` キーワード：外部の変数を使う

無名関数の中で、外側の変数を使いたい場合は、`use`キーワードを使います。

```php
DB::transaction(function () use ($validated) {
    // $validated を使える
    $user = User::create([
        'name' => $validated['name'],
        'email' => $validated['email'],
    ]);
});
```

### 🗣️ 日本語で読み解くと

```php
DB::transaction(function () use ($validated) {
    $user = User::create([...]);
    Profile::create(['user_id' => $user->id]);
});
```

1. **DBクラスに対して**、トランザクションを開始しなさい
2. **$validatedを使って**、以下の処理を実行しなさい：
   - ユーザーを作成する
   - プロフィールを作成する
3. 全て成功したらコミット、失敗したらロールバック

### なぜ `use` が必要なのか？

無名関数は独自の**スコープ（変数の有効範囲）**を持っています。外側の変数を使うには、明示的に`use`で渡す必要があります。

```php
$amount = 1000;

// ❌ NG: $amount にアクセスできない
DB::transaction(function () {
    echo $amount; // エラー！
});

// ✅ OK: use で渡す
DB::transaction(function () use ($amount) {
    echo $amount; // 1000
});
```

## ⚡ アロー関数（`fn`）

### アロー関数とは

**アロー関数**は、PHP 7.4から導入された、無名関数の**省略記法**です。

```php
// 無名関数（従来の書き方）
$double = function ($x) {
    return $x * 2;
};

// アロー関数（省略記法）
$double = fn ($x) => $x * 2;
```

### Laravelでの使用例（9-3-6 ファクトリー）

```php
public function published(): static
{
    return $this->state(fn (array $attributes) => [
        'is_published' => true,
        'published_at' => now(),
    ]);
}
```

### 🗣️ 日本語で読み解くと

```php
fn (array $attributes) => [
    'is_published' => true,
    'published_at' => now(),
]
```

→ 「**$attributesを受け取って**、`['is_published' => true, ...]`という配列を返しなさい」

### 無名関数との違い

| 項目 | 無名関数 | アロー関数 |
|:---|:---|:---|
| **書き方** | `function () { return ...; }` | `fn () => ...` |
| **複数行** | ✅ 書ける | ❌ 1行のみ |
| **外部変数** | `use`が必要 | **自動でキャプチャ** |
| **return** | 必要 | **不要（暗黙的に返す）** |

### アロー関数は `use` が不要

アロー関数は、外部の変数を**自動的にキャプチャ**します。

```php
$multiplier = 3;

// 無名関数：use が必要
$multiply = function ($x) use ($multiplier) {
    return $x * $multiplier;
};

// アロー関数：use は不要
$multiply = fn ($x) => $x * $multiplier;
```

### 使い分けの指針

| 状況 | 推奨 |
|:---|:---|
| 1行で済む簡単な処理 | アロー関数 `fn () => ...` |
| 複数行の処理が必要 | 無名関数 `function () { ... }` |
| 外部変数を明示したい | 無名関数 + `use` |

## 💡 なぜこの書き方をするのか

初学者は「なぜわざわざ複雑に書くの？」と思うかもしれません。これらの構文には、以下のメリットがあります。

| メリット | 説明 |
|:---|:---|
| **可読性** | 処理の流れが上から下に読める |
| **簡潔さ** | 少ないコードで多くの処理を表現できる |
| **再利用性** | 処理を関数として渡せるので、柔軟な設計ができる |
| **慣習** | Laravel/PHPの標準的な書き方なので、チームで共通理解しやすい |

最初は複雑に見えても、**慣れると「読みやすい」**と感じるようになります。

## 🚨 よくある間違い

### 間違い1: アロー関数で複数行を書こうとする

**問題**: アロー関数は1行しか書けない

```php
// ❌ NG: アロー関数は1行のみ
fn ($x) => {
    $result = $x * 2;
    return $result;
}

// ✅ OK: 複数行が必要なら無名関数を使う
function ($x) {
    $result = $x * 2;
    return $result;
}
```

---

### 間違い2: 無名関数で`use`を忘れる

**問題**: 外部変数にアクセスできずエラーになる

```php
$user = User::find(1);

// ❌ NG: $userにアクセスできない
DB::transaction(function () {
    $user->save(); // エラー！
});

// ✅ OK: useで渡す
DB::transaction(function () use ($user) {
    $user->save();
});
```

## 🏋️ 練習：コードを日本語で説明してみよう

以下のコードを、日本語で説明してみましょう。

### 問題1

```php
User::factory()->count(5)->create();
```

<details>
<summary>答えを見る</summary>

1. **Userクラスに対して**、ファクトリーを取得しなさい
2. **そのファクトリーに対して**、5件分の設定をしなさい
3. **その設定で**、実際にデータベースに作成しなさい

</details>

### 問題2

```php
DB::transaction(function () use ($user, $amount) {
    $user->decrement('balance', $amount);
});
```

<details>
<summary>答えを見る</summary>

1. **DBクラスに対して**、トランザクションを開始しなさい
2. **$userと$amountを使って**、以下の処理を実行しなさい：
   - この$userに対して、balanceを$amount分減らしなさい
3. 成功したらコミット、失敗したらロールバック

</details>

### 問題3

```php
$this->state(fn (array $attributes) => [
    'status' => 'active',
]);
```

<details>
<summary>答えを見る</summary>

1. **このインスタンスに対して**、状態（state）を設定しなさい
2. 設定内容：**$attributesを受け取って**、`['status' => 'active']`を返しなさい

</details>

## 📋 クイックリファレンス

よく使う構文の早見表です。迷ったときに参照してください。

| 構文 | 読み方 | 例 |
|:---|:---|:---|
| `Class::method()` | クラスに対して〜しなさい | `User::find(1)` |
| `$obj->method()` | この○○に対して〜しなさい | `$user->save()` |
| `->method1()->method2()` | 〜して、その結果に〜しなさい | `factory()->count(5)->create()` |
| `function () use ($x) { }` | $xを使って処理しなさい | `function () use ($user) { ... }` |
| `fn ($x) => ...` | $xを受け取って〜を返しなさい | `fn ($x) => $x * 2` |

## ✨ まとめ

このコラムでは、Laravelでよく見る4つのPHP構文を学びました。

| 構文 | ポイント |
|:---|:---|
| **`::`と`->`** | クラスに対して / このインスタンスに対して |
| **メソッドチェーン** | 処理を繋げて、加工ラインのように流す |
| **無名関数 + `use`** | 処理を関数として渡す、外部変数は`use`で |

**コードを読むコツ**：

1. メソッドチェーンを**分解**する
2. 各ステップを**日本語にする**
3. 全体の**流れをイメージ**する

最初は複雑に見えても、繰り返し読むことで「慣れて」きます。この先のTutorialでも、これらの構文は何度も登場するので、少しずつ慣れていきましょう。
