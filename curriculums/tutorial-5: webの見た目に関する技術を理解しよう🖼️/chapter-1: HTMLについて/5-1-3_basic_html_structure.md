---

## 導入

前のセクションで、HTMLがタグを使ってテキストに意味付けをする言語であることを学びました。しかし、`<h1>` や `<p>` といったタグをただ闇雲に書き始めるわけではありません。

HTML文書には、「**これはHTML文書ですよ**」と宣言し、文書全体を正しく構成するためのお決まりの「型」や「作法」が存在します。これは、手紙を書くときに、「拝啓」で始まり、「敬具」で終わる、といった作法があるのと似ています。

このセクションでは、全てのHTML文書の土台となるその基本的な構造を学びます。この構造は、いわばWebページという「建物」の**設計図のテンプレート**のようなものです。一度覚えてしまえば、どんなWebページを作るときにも、このテンプレートから始めることになります。

## 詳細解説

### 📜 HTML文書のテンプレート

早速ですが、これがHTML文書の最も基本的な構造です。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>ページのタイトル</title>
</head>
<body>
    <!-- ここに、実際に画面に表示したい内容を書く -->
    <h1>見出し</h1>
    <p>段落</p>
</body>
</html>
```

一見複雑に見えるかもしれませんが、一つ一つの要素は非常にシンプルな役割を持っています。上から順番に見ていきましょう。

#### 1. `<!DOCTYPE html>`

*   これはHTML文書の**一番最初**に必ず書かなければならない特別な宣言です。
*   これはタグではありません。
*   その役割は、この文書が「**HTML5という最新のルールに従って書かれていますよ**」とブラウザに伝えることです。
*   この宣言があることで、ブラウザは「HTML5モード」で動作し、私たちが書いたHTMLを正しく解釈してくれます。
*   おまじないのようなものだと考えて、常に最初に書く、と覚えておきましょう。

#### 2. `<html>` タグ

*   `<!DOCTYPE html>` の次に登場するのが、`<html>` タグです。これは文書の**一番外側**を囲む最も大きなタグです。
*   「ここからここまでが、HTML文書の本体ですよ」という巨大なコンテナの役割を果たします。
*   `lang="ja"` という部分は、**属性 (Attribute)** と呼ばれるもので、タグに追加の情報を与えるために使われます。ここでは、`lang`（languageの略）属性を使ってこの文書が**日本語 (ja)** で書かれていることを示しています。これにより、ブラウザが翻訳機能を提供したり、音声読み上げソフトが正しい発音で読み上げたりするのに役立ちます。

#### 3. `<head>` タグ

*   `<html>` タグの中は、大きく分けて、`<head>` と `<body>` の2つのセクションに分かれます。
*   `<head>` セクションは、そのWebページの「**裏方の情報**」を記述する場所です。ここに書かれた内容は、**直接Webページの画面上には表示されません。**
*   レストランの例えで言うなら、厨房の壁に貼ってあるレシピやスタッフのシフト表のようなものです。お客さんの目には触れませんが、お店を運営するために必要な情報です。
*   `<head>` の中には、主に以下のようなタグを記述します。
    *   **`<meta charset="UTF-8">`**: 文字コードを指定します。`UTF-8` は世界中のほとんどの言語を文字化けせずに表示できる標準的な文字コードです。これもおまじないとして必ず書いておきましょう。
    *   **`<title>`**: このページの**タイトル**を指定します。ここに書いたテキストは、ブラウザの**タブ**や、ブックマークした時の名前、検索エンジンの結果などで使用されます。

#### 4. `<body>` タグ

*   `<body>` セクションこそが、Webページの「**本体**」です。ここに書かれた内容が、**実際にブラウザの画面に表示される**部分になります。
*   `<h1>` や `<p>`、画像、リンクなど、ユーザーに見せたい全てのコンテンツは、この `<body>` タグの中に記述します。
*   レストランで言えば、お客さんのテーブルに運ばれてくる料理そのものです。

### ⚡ VSCodeで雛形を生成する

このHTMLの基本構造は、毎回手で入力するのは大変です。幸いなことに、VSCodeには、この雛形を一瞬で生成してくれる便利な機能が備わっています。

1.  新しいファイルを作成し、`index.html` という名前で保存します。（`.html` という拡張子が重要です）
2.  ファイルの1行目に、`!`（エクスクラメーションマーク）を半角で入力します。
3.  すると、入力候補（Emmet）が表示されるので、そのまま `Enter` キーか `Tab` キーを押します。

たったこれだけで、先ほど説明したHTMLの基本構造が自動的に挿入されます。これはWeb開発において非常によく使うショートカットなので、必ず覚えておきましょう。

## ✨ まとめ

このセクションでは、全てのHTML文書の土台となる基本的な構造について学びました。

*   **HTMLの基本構造**: `<!DOCTYPE html>` 宣言で始まり、`<html>` タグが全体を囲み、その中に `<head>` と `<body>` が入る、という入れ子構造になっている。
*   **`<!DOCTYPE html>`**: 文書がHTML5であることを宣言するおまじない。
*   **`<html>`**: 文書全体のルート（根っこ）となる要素。
*   **`<head>`**: ページのタイトルや文字コードなど、画面には表示されない「裏方の情報」を記述する場所。
*   **`<body>`**: 見出しや段落など、実際に画面に表示される「本体」のコンテンツを記述する場所。
*   **VSCodeのショートカット**: `!` + `Enter` で、HTMLの雛形を一瞬で生成できる。

このテンプレート構造を理解したことで、あなたはいつでも新しいWebページの制作を正しい作法でスタートできるようになりました。
